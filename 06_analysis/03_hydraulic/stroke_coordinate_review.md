## 4. H-2 내부 누설·온도가 피스톤을 움직이는 크기

잠긴 다리에서 이 효과는 실기 피스톤 $s_p$와 실기 기름 부피를 함께 바꾼다. 시뮬레이션의 잠긴 `s_ref`는 일정하다. 그래서 시뮬레이션과 실기 판독 사이의 차이로 나타난다.

### 4.1 피스톤 내부 누설(헤드 → 로드, 시험 기준값 기반)

$G$ = 4 cm³/min / 70 bar = 9.52×10⁻¹⁵ m³/(s·Pa). 단일 다리, 일정 하중 $F$(4점 지지에서는 하중이 다른 다리로 옮겨 실제 이동은 이보다 작다).

- 로드측이 바닥(공동, 기체 공간): 헤드 압력은 하중이 붙잡고, 새는 기름이 로드측 빈 공간을 채운다. 수축 속도 $\dot x = G p_h / A_p$.
- 로드측이 맞물림(빈 공간이 다 차면): $\dot x = G\Delta p\,(1/L_h + 1/L_r)/(A_p/L_h + A_{ann}/L_r)$.
- 끝 상태: 두 챔버 압력이 $p_{eq} = F/(A_p - A_{ann})$로 같아질 때까지(플런저처럼 로드 단면적으로 하중을 받음). β 1 GPa에서 시정수 $\tau = 1/(G\,\partial\Delta p/\partial V)$.

|---|---|---|---|---|---|---|---|---|

- 레벨링 한 번(약 100 s) 동안 상계는 약 1.4 mm(전방 119 kN, s 0.68)다. 실제 새 실린더의 내부 누설은 대개 이보다 훨씬 작다. 표는 시험 기준값(≤ 4 cm³/min @ 70 bar, 제조사 미확인)으로 잡은 **상계**다.
- 기름 부피 좌표로 보면 헤드 기름이 빠지므로 실기 $s_{ref}$도 같이 줄어든다(실기 $\hat s_{ref}$는 이것을 따라간다. 시뮬레이션 `s_ref`는 따라가지 않는다).
- POC 시트 누설(헤드 → 라인)은 포핏형이면 사실상 0이다. 5방울/min(약 0.25 cm³/min, **가정**)이면 전방 0.019 mm/min, 끝없이 계속된다(평형 없음).

| 후방 | 0.40 | 0.28~0.30 | 0.13~0.14 | 3.3~3.4 |
| 후방 | 0.68 | 0.46~0.48 | 0.07 | 5.3~5.4 |

- 식: 로드측 바닥 $\Delta s = \alpha L_h\Delta T$, 맞물림 $\Delta s = \alpha\Delta T (A_p - A_{ann})/(A_p/L_h + A_{ann}/L_r)$. 가열 = 신장 쪽, 냉각 = 수축 쪽. 범위는 $L_{0h}$ 0.05~0.08 m.
- 피스톤이 끝 정지에 기대어 못 움직이면 $\Delta p = \beta_e\alpha\Delta T$ = **4.3 / 6.3 / 10.0 bar/K**(β 0.69 / 1.0 / 1.6 GPa)다(5절).
- WRP-A 자체 온도 계수 ≤ 0.01 % FS/°C = **0.07 mm/K**(700 mm 모델). 유온 20 K 변화면 1.4 mm다. 끝 판독 694.8 mm를 교정한 온도와 운전 온도가 다르면 끝 여유에 직접 들어간다.
- 레벨링 직후 유온이 내려가는 운용이면 냉각 수축(전방 s 0.68, 로드측 바닥 0.46 mm/K)이 우세하다. 3 K 냉각이면 약 1.4 mm 수축이다.

## 6. H-4 $\hat s_{ref}$ 오차 예산(WIKA A-10 normal 등급)

### 6.1 추정식

$$\hat s_{ref} = s_p + \frac{\hat p_h A_p}{k_h(s_p)}\qquad(\text{헤드 기름 부피 좌표})$$

- 헤드 압력만 쓰는 꼴이 물리적으로 맞다. 헤드 기름의 압축량은 헤드 압력이 정한다. 순 힘 $\hat F$를 쓰면 $p_r A_{ann}/k_h$만큼 다르다: 잠긴 부하 다리(p_r ≈ 0~3 bar)에서 ≤ 0.06~0.07 mm로 무시할 만하다. 수축 뒤 갇힌 로드측 31 bar(S2r)면 0.64 / 0.75 mm(전방 / 후방)다. D-3 맞춤과 시뮬레이션 `s_ref` 재현에는 $\hat F$ 꼴이 맞는다. 두 꼴의 차는 위 크기다.
- **실 마찰은 들어가지 않는다.** 압력은 기름 힘이고, 마찰은 피스톤과 관 사이에서 작용해 기름 압축과 무관하다(L2b 마찰 경로 $k_{out}(s_p - s) = G(s_{ref} - s_p) + f$에서 센서 압력 = $G(\cdot)$). D-3이 물은 "마찰 동원 2.4~5.2 kN 산포"는 패드 하중 ↔ 압력 관계의 오차다. $\hat s_{ref}$의 오차가 아니다.

### 6.2 예산(s 0.68, 한 표본)

| 오차원 | 전방 119 kN($p_h$ 89.7 bar) | 후방 80 kN($p_h$ 84.2 bar) | 근거 |

## 9. control-expert에 넘길 것

1. **좌표 선택(C-1)**: 실기에는 피스톤 판독뿐이다. 선택지는 (a) 행정 끝·예산류 문턱을 피스톤 판독에 그대로 둔다, (b) $\hat s_{ref} = s_p + \hat p_h A_p/\underline k_h(s_p)$로 지금 좌표를 재현한다. (b)는 시뮬레이션 거동과 가깝고 보수 쪽이다. 대가는 예산 손실 ≤ 5.8 mm(전방 119 kN)이고, 공기가 있으면 상계가 아니다. 현장 $k_h$ 동정을 넣으면 손실이 ±0.65 mm 수준으로 준다.
2. **기계 끝 694.8 가능성**: (a)를 고르면 FAULT 693.8·절단 694.7은 끝 정지에서 1.0 / 0.1 mm다(5.2 표). 이 경우 문턱 재설정이 필요한지 판단해야 한다. HX-1 답 전까지는 두 경우를 다 본다.
3. **증분 기능은 영향이 작다**: LOC 10 mm 평탄 창(하중 변화 ≤ 2 kN)에서 두 좌표의 증분 차는 $\Delta F/k_h$ ≤ 0.11~0.17 mm다. 영향이 큰 것은 하중이 크게 바뀌는 구간의 절대값과 이동량이다: 들어 올림 0 → 120 kN 동안 0 → 6.5 mm(하한 $k_h$면 9.9 mm), 앞뒤 다리 차 약 2.7 mm, 행정 예산 가드, 크롤러 틈 ĉ(이미 `rod_stroke` 기하를 씀), READY 꼬리 0.5 mm, CHECK 복귀 ≤ 0.5 mm.
4. **잠긴 창의 실기 드리프트**: 누설 상계 ≤ 1.1~1.3 mm/min(s 0.68), 온도 0.07~0.48 mm/K + WRP-A 0.07 mm/K. 레벨링 한 번(약 100 s)에서 누설 ≤ 1.4 mm, 유온 3 K 냉각 약 1.4 mm다. READY 장시간 유지, 0.5 mm 판정(꼬리·CHECK 복귀), 재레벨 트리거에 들어간다. 시뮬레이션에는 없다(누설 0, 등온).
5. **L1과 L2b의 피스톤 정의 차**: L1 `stroke_corrected_m`은 운전점 $k_{oil}$ 상수(전방 119 kN 4.0 mm), L2b는 $k_h(s)$(6.5 mm)다. 피스톤 기준 숫자를 L1에서 정하면 L2b·실기와 약 2.5 mm 다르다.
6. **쿠션 구간**: 판독 약 645 mm부터 로드측 압력이 40~191 bar로 오른다(단품). 642.8 mm 문턱 부근이다. R6-P 로드측 진단·M2에 이 압력이 들어가는지 확인한다. 플랜트에 쿠션이 없다.

- $\beta_e$ 0.69~1.6 GPa(공기 0), $L_{0h}$ 0.05~0.08 m, $L_{0r}$ 0.05 m, $\alpha_v$ 6.5×10⁻⁴ K⁻¹: 모두 프로젝트 가정값이다.
- 누설 계산: 단일 다리, 일정 하중, β 1 GPa, 로드측 기체 공간 0(맞물림 상계), 선형 누설 $Q = G\Delta p$. 4점 지지의 하중 재분배는 넣지 않았다(이동 상계).
- 온도 계산: 기름 온도가 균일하게 바뀌고 하중이 일정하다. 강 관의 면적 팽창만 넣었다. 축 방향 강재 팽창(0.0084 mm/K, 700 mm)은 무시했다.
- 자유 공기: 등온, 1 bar abs 기준 체적비, 용해는 무시했다.
- 압력 예산: normal 등급 경계의 선형합(상계)과 균등분포 RSS. 영점 오프셋은 CHECK 교정으로 제거된다고 보았다. 로드측 1 bar g로 두었다.
- 릴리프 오버슈트 +10~15 %는 대표값(가정)이다.
- 이동 중 호스 등가 체적 5.9×10⁻⁴ m³는 옛 치수 값이다.
