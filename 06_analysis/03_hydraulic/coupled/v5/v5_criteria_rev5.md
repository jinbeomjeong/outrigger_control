## 3. M2 법칙 r4와 단위 시험

### 3.1 식 (P-1)

M2는 잠금 앵커 압력 $p_{r0}$에서 이동 목표 $p^*$까지의 변화만 $s_{ref}$로 옮긴다. 잠긴 동안 쌓인 몫($p_{r,rel}-p_{r0}$)은 기본 L1-R 해제가 맡는다.

$$\Delta_i = p_{r0,i} - p_{r,rel,i} = \frac{G_{r,i}(t_{rel})}{A_{ann,i}},\qquad \hat p_i^k = p_i^k + \Delta_i\,w_i^k,\qquad \delta s_{ref,i}^k = \frac{A_{ann,i}\,(\hat p_i^{k-1}-\hat p_i^k)}{k_{h,i}}$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $p_i^k$ | r3 유량 제한 로드 압력. 출발은 진짜 $p_{r,rel}$이고, 판독·진값에는 이 값을 그대로 쓴다 | Pa(게이지) |
| $w_i^k$ | 기본 법칙 해제 감쇠 가중치 $e^{-(t_k-t_{rel})/\tau_{rel}}$. 하네스는 RodSidePlant $\tau$ 0.05 s, L2b는 `_release_decay()` | - |
| $G_{r,i}(t_{rel})$ | 해제 순간 기본 법칙의 잠김 로드 힘 $r_0$. 해제 순간 한 번 정하고, 잠기면 지운다 | N |
| $A_{ann,i}$, $k_{h,i}$ | 로드측 환형 면적, 헤드 기름 강성 | m², N/m |

- 잠긴 다리는 $\hat p = p_{r0}$다.
- 한 해제 구간의 M2 이동 합은 아래 식이다. 시드가 없으면 $p_{start} = p_{rel}$이므로 $\hat p_{start} = p_{r0}$다. 구간 끝에서 $w_{end} \to 0$이면 이동 합은 $A_{ann}(p_{r0}-p_{end})/k_h$가 된다.

$$S_{M2} = \frac{A_{ann}\,(\hat p_{start}-\hat p_{end})}{k_h},\qquad \hat p_{start} = p_{start}+\Delta,\qquad \hat p_{end} = p_{end}+\Delta\,w_{end}$$

| 기호 | 뜻 |
|---|---|
| $p_{start}$ | 해제 구간의 r3 지연 출발 압력. M1c 시드가 있으면 시드 압력, 없으면 $p_{rel}$ |
| $p_{end}$, $w_{end}$ | 구간 끝의 r3 압력과 해제 감쇠 가중치 |
- 하네스에서는 $\Delta_i w_i^k = G_{r,i}^k/A_{ann,i}$와 같다. 기본 이동 가지가 정확히 $r_0 e^{-(t-t_{rel})/\tau}$이기 때문이다. 구현 실측 차는 최대 9.3×10⁻¹⁰ Pa다. P-1 패치 진단 3행의 명령 해시가 r4 구현과 비트 동일하다.
- **L2b 구현 차이(명세와 다른 점)**: L2b의 $\hat p$ 시작값은 훅 1스텝 지연 규약 때문에 $p_{r0}$과 정확히 같지 않다. $\Delta$를 해제 압축 때의 잠김 $p_r$에서 정하기 때문이다(`L2bRodSide.releases_of_last_call`). 하네스는 정확하다. M2-12($\hat p$ 동일성)는 같은 $\Delta$·입력열 기준이라 통과한다. 이 차이는 3단계(Chrono L2b) 기록 항목이며 2단계 판정과는 무관하다.
- 진단(프로세스 안 패치, `stage2_judgement.md` 9.1절): 뜬 다리 재접근 때 사건 다리 M2 이동이 +1.02~1.06 mm에서 −0.04 mm로 바뀌었다(14위상 모두).

## 5. H-10 위상 분포 규칙 (계열 $\mathcal F$)

### 5.1 계열 정의

$\mathcal F$ = 격자 키 `screen|top|0.0|ready|FR`와 `screen|top|0.0|ready|FL`의 **사건 FS24** 행이다. 조건은 강체 상단, $F_s$ 0, READY 시점, 사건 다리 FR·FL, R12 r67 분기다.
- 격자 768 안에서는 `grid_r67_main`(위상 0, 0.05)과 `grid_r67_top`(위상 0, 0.025, 0.05, 0.075)이 겹친다. 그래서 행 12개(고유 위상 4 × 2키)다.
- **이 계열에서 위상 분포 규칙이 대신하는 것은 `Fmin_after_W`와 `U57_outside` 두 관문뿐이다.** 둘 다 인접 다리 골·부상이라는 같은 증상이다. 같은 행의 `fault0`, `end_att`, `recurrence`, `U832_pair_union`, `U832_last_touch`, `U57_sum`, `U57_gap`은 행 단위 그대로다.

**왜 이 두 키·한 사건뿐인가(다른 계열을 느슨하게 하지 않는다는 확인)**
- 저장 V0 격자와 VB r3 격자를 계열별로 셌다(`ctrl_v5s2\diag\grid_family.py` → `grid_family.json`, 64건 전에 실행).
- V0에서 `Fmin_after_W` 실패가 있는 계열은 10개다: 상단 $F_s$ 0의 FS24·RE1bF × LEVEL·READY × FL·FR 8개, 상단 $F_s$ 2 LEVEL FL FS24, FR RE1bF.

- **r4 재실행에서 이 8계열(또는 다른 어떤 계열)에 통과→실패가 나오면 H-10은 앞 판대로 걸린다.** 계열을 사후에 넓히지 않고 멈추고 묻는다.

### 5.2 규칙

같은 키에서 위상 16개($\delta$ = 0, 0.00625, …, 0.09375 s. 결과는 $T_s$ 0.1 s 주기로 반복된다, `k1soil/sweep` 확인)를 V0와 VB로 돌린다. 키마다 실패 위상 수 $k$를 센다. 실패 = `Fmin_after_W` 또는 `U57_outside` 실패다.

| # | 조건 | 값 |
|---|---|---|
| R-1 | 키마다 $k_{VB} \le k_{V0} + m$ | **$m$ = 4**(FR, FL 각각) |
| R-2 | 두 키 합 $k_{VB}^{FR}+k_{VB}^{FL} \le k_{V0}^{FR}+k_{V0}^{FL} + m_\Sigma$ | **$m_\Sigma$ = 6** |
| R-3 | 32 VB 실행 모두 FAULT 0, 끝 READY | 위반 1건이면 실패 |
| R-4 | 32 VB 실행에서 `Fmin_after_W`·`U57_outside` 밖 관문의 실패가 같은 위상 V0에 없던 것 0 | 위반 1건이면 실패 |
| 통과 | R-1~R-4 모두 | 격자의 $\mathcal F$ 12행은 이 두 관문에 대해 H-10 계산에서 뺀다 |
| 실패 | 하나라도 | H-10, 멈추고 묻는다 |

### 5.3 $m$의 근거 (64건 전에 정함, `ctrl_v5s2\diag\m_prereg.py` → `m_prereg.json`)

- **영 모형**: 키마다 V0와 VB의 16위상 결과를 같은 확률 $p$의 독립 베르누이로 본다. $m$은 $P(k_{VB}-k_{V0} > m) \le$ 0.05(단측)를 만족하는 가장 작은 정수다(이항 두 개 차의 정확 분포).
- **$p$의 근거 자료**(모두 64건 전에 있던 V0 결과): `ctrl_v5s2\diag\diag2.jsonl`의 V0 7위상(0~0.075 s, 12.5 ms 간격). FR 1/7, FL 4/7, 합쳐서 5/14다. 같은 행의 저장 V0 격자(`acceptance/c4g2_only/grid`, 위상 4개)는 이 7위상의 부분집합이고 값이 같아(7.1절 재현) 따로 세지 않았다.
- **계산 결과**

| $p$ | 키당 $m$(n 16) | 꼬리 $P(D>m)$ | 합 $m_\Sigma$(n 32) |
|---|---|---|---|
| 5/14(합침, **채택**) | **4** | 0.048 | **6**(0.045) |
| 1/7(FR) | 3 | 0.037 | 5 |
| 4/7(FL) | 5 | 0.024 | 6 |
| 0.5(최악) | 5 | 0.025 | 7 |

- 합친 $p$를 쓴 이유: 키별 7위상 추정은 너무 거칠다(표본 7개). 최악 $p$ 0.5는 규칙을 가장 느슨하게 만드므로 쓰지 않았다.
- 채택한 $m$ = 4의 거짓 경보율: FR $p$ 1/7에서 1.1 %, FL $p$ 4/7에서 5.3 %, $p$ 0.5에서 5.5 %다.
- **검출력**(같은 영 모형): 알려진 양성 대조인 VB r3 FR(V0 1/7 → 6/7)은 99.9 %로 걸린다. $p$가 +2/7 오르면 52 %, +1/7 오르면 21 %로 걸린다. **작은 악화(위상 실패율 +15 % 안팎)는 이 규칙으로 가려지지 않는다.** 한계로 적는다(8절).
- **영 모형의 한계**: 위상 결과는 독립 시행이 아니다. 같은 결정론적 계에서 위상만 바꾼 것이라 이웃 위상끼리 상관이 있다. 상관이 양이면 실제 분산이 더 커지므로 $m$ = 4는 거짓 경보 쪽으로 엄격하다. 이 근사를 알고 쓴다.
