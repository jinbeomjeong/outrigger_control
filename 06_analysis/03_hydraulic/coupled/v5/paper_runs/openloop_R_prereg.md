# V5-OPENLOOP-R 사전 예측 (결과 보기 전 봉인)

- 작성: dynamics-expert, 2026-11-08. 대상: `openloop_R_sensitivity_rows.md`의 3행(V0 J1 열린 루프, `damping_R` 887,600 / 600,000 / 300,000 Pa·s/m; 기준 992,000). 이 문서를 쓸 때 세 행은 실행되지 않았다.
- 근거 자료: `prop_dip_mechanism.json`·`prop_dip_crawler.json`·`prop_dip_timebase.json`(V0 대 VB proportional), `openloop_fb_compare.json`(F-6, V0_FB·VB_FB), 판정서 1.6·1.7절.
- 기호: λ = R / 9.92×10⁵, r = 신장 속도 / v_max(이 3행은 r = 1). 단위 kN, mm, s. 힘은 실린더 힘 F_cyl(신장 +).

## 1. 가설

- **H-Ru(곱 스케일링)**: 후방만 닿은 구간의 후방 힘은 크롤러 앞쪽(항복 가지)의 SCM 점성 반력 R·ż가 지배한다. 따라서 이륙 전 후방 골은 근사적으로 λ·r의 함수다. 2점 직선: $F_{a,min} \approx 11.70 - 23.4\,(1-\lambda r)$, 후방 평탄부 $\approx 0.9 + 18.0\,\lambda r$.
- **H-C(크리프 기구)**: R을 낮추면 같은 시간에 크롤러 앞끝이 더 많이 가라앉고 기체가 더 숙는다. 그래서 후방 힘이 낮아진다(단조).
- 알려진 산포: 같은 속도 두 행(F-6 V0_FB·VB_FB)의 후방 골 차 0.18~0.44 kN, 접지 행정 차 ±0.4 mm(원인 미확정). 아래 허용폭은 이 산포를 넣었다.

## 3. 판정 기준 (결과 뒤 바꾸지 않음)

- **H-Ru 확인**: R888k에서 세 조건이 모두 맞는다. ① R-1 RL·RR가 각각 VB proportional 값(9.28 / 9.17)의 ±0.4 kN 안이다. ② R-4c의 V0 대비 비가 0.895 ± 0.03이다. ③ R-3이 V0의 ±0.5 kN 안이다.
- **H-Ru 기각**: R888k R-1이 10.5 kN 이상(속도만 효과)이거나 8.0 kN 이하다.
- 그 밖이면 **부분 확인**으로 쓰고 어느 조건이 빠졌는지 적는다.
- **H-C 확인**: R이 내려갈수록(992k → 888k → 600k → 300k) R-4 |+0.14 s 침하|가 증가하고 R-4c·R-2가 감소한다(단조). 하나라도 역전하면 H-C를 **기각**하고 다른 기구를 찾는다. 역전 폭이 F-6 산포(0.44 kN, 0.4 mm) 안이면 "판정 불가"로 쓴다.
- **직선 외삽 오차**(가설 시험 아님, 기록만): R600k·R300k R-1과 직선값(2.4 / −4.7)의 차.
- **R-5**: (a)는 R-1 값으로, (b)는 SCM 패드 법선 힘 ≤ 0 표본의 시각과 길이로 기록한다.

## 4. 판정 창 함정 (계산 규칙)

- 저장 규칙(`p3a.P3a-9 before_liftoff`)은 1.4 F_min(13.18 kN)을 처음 넘은 뒤부터 최솟값을 찾는다. R600k·R300k는 후방 피크가 13.18 kN 미만으로 예상된다. 그러면 창이 전방 하중 이동 뒤(후방이 다시 오르는 때)에 열린다. 그 경우 저장값은 골을 놓치고 높게 나온다.
- 그래서 R-1은 두 정의로 다 낸다. ① 저장 규칙 값과 `t_first_above_s`. ② **후방 접지(swivel 사건)부터 크롤러 이륙까지의 최솟값**. 판정에는 ②를 쓴다. 저장 규칙이 골을 놓쳤으면 그것을 기록한다.
- 단위: `prop_dip_timebase.json`의 `F_rear_*_kN` 두 키는 N으로 저장돼 있다. 새 비교 스크립트는 kN으로 맞춘다.
