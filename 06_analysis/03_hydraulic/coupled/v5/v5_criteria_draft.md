## 6. S8 F-5 처리

저장 근거: 유량 켬 5건 조항 실패, 끔 5건 통과, 정지 위상과 분리하지 못함, 효율에 단조가 아님(`decision_log` 2026-11-05). 조항 = 정지 뒤 크롤러 하중 ≤ 정지 때 + 0.01 W. 이 판정은 Chrono이고, 하네스에서 같은 조항을 잰 저장 값은 확인하지 못했다.

| 경우 | 처리 |
|---|---|
| 유량 켬 설정(V2, V3, VB, V4~V8, LS1~LS4)에서 **조항만** 실패 | 새 실패로 세지 않고 `F-5 기록`으로 표에 적는다 |
| 유량 끔 설정(V0, V1, L1)에서 조항 실패 | F-5가 아니다. **멈춤** |
| 그 밖의 SA-4(같은 주기 WARN → FAULT:soil, `FAULT_STROKE_END` 0, READY 0, 정지 뒤 네 다리 ≥ $F_{min}$, 부상 0, 이동 압력 ≤ 180 bar, 포화 차단 0) 실패 | 어떤 설정이든 실패 |
| 분류가 `stroke_limited_stop` 또는 사전 분류에서 벗어남 | J1 실패 |
| VB 조항 여유 < −6.92 kN(저장 최악) 또는 정지 뒤 최대 > 14.21 kN(저장 켬의 정지 전 1 s 최대 상한, **가정**) | F-5 범위를 넘음. **멈춤** |

조항의 "정지 때" 값은 1 ms 한 표본이라 불안정하다(`s8off` 물리 판정). 정지 전 1 s 최대 대비 값과 정지 시각 ± 0.1 s 표본 값을 **기록**으로 함께 적는다. S8의 위상·유량 분리는 이번에도 하지 않는다.

## 9. 대체 경로 표시

새 창은 대체 다리의 $\hat p_r$에만 듣는다(`two_pressure.py:2149-2223`, `:2603-2610`, `:2483`은 `online`일 때만).

| 근거 | 시점 | 상태 |
|---|---|---|
| T7 합성(새 $\delta_{ol}$, $t_c$), W-1 | 커밋 7 | 판정 가능 |
| 하네스 재생 T4h: VB·LS 행 기록(10 Hz 헤드·로드·행정·명령, 1 ms 진값·`plant.locked`)에 대체를 강제해 하한 ≤ 진값 + 0.6 kN | 1,200건과 함께 | `잠정`. 법칙이 L2b와 같은 계열이고 하네스 이동 중 로드 판독에 배압이 없다 |
| Chrono T4·T5(L2b, 새 플랜트 기록) | D-3 결정 뒤 | `미판정` |

- **Chrono T4·T5 전까지 표기**: VB 표에 `대체 경로 미판정(Chrono 전)` 열을 둔다. 대체 다리가 나온 행은 `fallback_unverified`로 표시하고 그 행의 값은 적되 대체 경로 합격 근거로 세지 않는다. 종합 판정 문구는 "로드 센서 정상 경로 합격, 대체 경로 미판정"으로 쓴다.
- CB 6건과 11.2 시험, T3는 LC가 CB를 거부하므로 대상이 아니다.
- **W-2 예상의 정정**: 진단 실행(`lock_window_eps_m_s` = 2 % $v_{max}$, $t_c$ 항 없음, $\varepsilon$ 플랜트, 유량 끔, final_C4G2. 금지 조합이라 힘 값은 판정 안 함)에서 R12, R14, R15, R16, S1, S7, R2, R7, S8 해시가 켬·끔 같았다. 다만 "대체 없는 행"은 아니다. R12·R14는 재READY 때 네 다리가 D6으로 대체에 들어간다(67.7 s, 69.3 s). M1c VN을 더한 R15·R16은 FR이 사건 뒤 0.4~1.2 s에 D1으로 대체에 들어가도 해시가 같았다(하한이 명령을 바꾸지 않음). W-2가 달라지면 먼저 대체 다리와 그 시각을 본다. 대체 다리 없이 다르면 구현 결함으로 멈추고, 대체 다리가 있으면 값과 함께 묻는다.
- `true_lock_time`(`h_s8_2_lock_ratio.py:276`, `s_motor` 50 ms 정지)은 LC에서 잠금이 아니라 **유량 차단** 시각을 준다. T4·T5와 $n_{late}$는 법칙의 잠금 상태 기록을 쓴다.
