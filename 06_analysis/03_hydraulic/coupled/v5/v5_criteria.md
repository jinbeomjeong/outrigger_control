# v5 유압 연성 인수 기준 (확정판)

작성: control-expert, 2026-11-06. 기준 코드 master e747d8c(`final_C4G2`). 초안 `v5_criteria_draft.md`에 사용자 결정(2026-11-06: Q-4 (가), 미룬 8개 전부 넣음, ⑦ (가), 복귀 60 s·14.21 kN 채택, 창 식 (가))을 반영했다. SHA-256은 같은 폴더의 `v5_criteria.sha256`에 있다.

**봉인 규칙**: 이 파일은 v5 결과(LC·M2·VB, 추가 묶음, Chrono)를 보기 전에 봉인한다. 봉인 뒤에는 고치지 않는다. 바꿔야 하면 사용자 결정과 사유를 적은 개정 절을 새 파일로 덧붙이고 그 SHA-256을 따로 적는다.

**봉인 때까지 본 것**: 저장 결과(`pressure_review/m1`, `m1c`, `verdict`, `chrono/final_c4g2`, `acceptance/c4g2_only`, `h_s8_3_window.json`)와 진단 실행 26행(LC 플랜트 없음, 9절). LC·M2·VB 결과는 보지 않았다.

범위: 축소 하네스(1단계·2단계)와 Chrono(3단계, D-3), 음되먹임, $T_s$ 0.1 s, $d$ = 1. 힘 [kN], 시각 [s], 압력 게이지.

## 6. S8 F-5 처리

조항 = 정지 뒤 크롤러 하중 ≤ 정지 때 + 0.01 W.

| 경우 | 처리 |
|---|---|
| 유량 켬 설정(V2, V3, VB, V4~V8, LS1~LS4)에서 조항만 실패 | `F-5 기록`, 새 실패로 세지 않음 |
| 유량 끔 설정(V0, V1, L1)에서 조항 실패 | F-5 아님. **멈춤** |
| 그 밖의 SA-4(같은 주기 WARN → FAULT:soil, `FAULT_STROKE_END` 0, READY 0, 정지 뒤 네 다리 ≥ $F_{min}$, 부상 0, 이동 압력 ≤ 180 bar, 포화 차단 0) 실패 | 어떤 설정이든 실패 |
| 분류가 `stroke_limited_stop`에서 벗어남 | J1 실패 |
| VB 조항 여유 < −6.92 kN, 또는 정지 뒤 최대 > 14.21 kN | **멈춤**(사용자 채택값) |

"정지 때" 값은 1 ms 한 표본이라 불안정하다. 정지 전 1 s 최대 대비 값과 정지 시각 ± 0.1 s 표본 값을 기록으로 함께 적는다.
