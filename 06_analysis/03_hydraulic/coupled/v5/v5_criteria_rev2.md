### 2.1 잘림 계수의 정의 (#1, #2)

| 항목 | 정의 |
|---|---|
| 잘림 스텝 | `RodReleaseShift.shift_m`에서 원하는 이동이 행정 범위로 잘린 1 ms 내부 스텝. 다리마다 센다. 지금 `m2_clipped_steps`가 세는 것과 같다 |
| $t_{lift}$ | 실행 하나에 하나인 **상부체(크롤러) 첫 이륙 시각** [s]. 하네스는 기존 J2·항목 3과 같은 값을 쓴다: `verdict_metrics._first_lift_index`가 고른 1 ms 행의 시각, 결과 키 `values.forces.t_lift_s`. 그 행은 단계가 `idle`·`check`·`TOUCH`가 아니고 크롤러 수직력(리미터 1 ms 행 `crawler` 열)이 0.0인 첫 행이다 |
| "다리별" | 계수를 다리마다 따로 낸다는 뜻이다. 이륙 시각은 네 다리에 공통이다(크롤러를 다리마다 나눌 수 없다) |
| `m2_clipped_steps_pre_lift` | 다리별로 내부 스텝 시각 $t < t_{lift}$인 잘림 스텝 수 [건]. **기록만** |
| `m2_clipped_steps_post_lift` | 다리별로 $t \ge t_{lift}$인 잘림 스텝 수 [건]. **J9·H-9 판정** |
| 이륙이 없는 실행 | $t_{lift}$가 없으면(`t_lift_s` null) 모든 잘림을 `post_lift`로 센다(보수 쪽). 이륙 없는 실행은 J1·J3·J4에서도 따로 드러난다 |
| `m2_clipped_steps` | 합계(pre + post)로 그대로 남긴다. 판정에는 쓰지 않는다 |
| Chrono(3단계) | 같은 정의를 엔진의 크롤러 수직력 기록에 적용한다. 기록 필드는 D-3 결정 때 명세에 적는다 |
