**L2 문턱 표**(단측 Clopper–Pearson 95 % 상계 ≤ 3 %를 만족하는 최대 실패 수):

| n | 허용 최대 실패 수 | 그 수에서 상계 | 한 건 더일 때 상계 | 적용 |
|---|---|---|---|---|
| 855 | 17 | 2.968 % | 3.106 % | 앞 판 문구(쓰지 않음) |
| **835** | **16** | 2.896 % | 3.038 % | **이 판** |
| 501 | 8 | 2.863 % | 3.114 % | L3(기록만, 판정 아님) |

- 두 경로로 같은 값을 얻었다: `scipy.stats.beta.ppf(0.95, k+1, n-k)`와, `binom.cdf(k, n, p) = 0.05`의 근(`brentq`). 스크립트는 `scratchpad/ctrl_v5x/cp_n.py`다.
- 판정 규칙의 기준은 상계 ≤ 3 %이고, 괄호 안 건수는 그 규칙을 n에 대해 계산한 값이다. 실제 판정 n이 835와 다르면(오류 행 제외 등) 같은 규칙으로 다시 계산한 값을 쓴다.
