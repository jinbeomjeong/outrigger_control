## 1. 결론

1. **두 챔버 전체를 넣을 이유는 찾지 못했다.** 정지, 비틀림 하중 이동, 급침하 피크, 펌프 공유에서 현재 법칙은 두 챔버 모델과 하중 2.4 % 안, 압력 피크 2 % 안에서 맞았다.
2. **가설 목록 밖에 더 큰 항목이 있다. 체크 밸브가 "닫힐 때"가 아니라 "열릴 때"다.** 명령이 시작돼도 라인과 로드 챔버를 체크 개방 압력까지 채울 동안 피스톤이 움직이지 않는다. 지금 플랜트에는 이 지연이 없다.
   - 지연: 0.05 $v_{max}$에서 수축 +0.76 s, 신장 +0.37 s. 체적으로는 신장 약 0.39 mm, 수축 약 1.2 mm(순 지연 약 0.8 mm).
   - 환산 하중: 약 2~4 kN(**추정**). 비틀림 데드밴드 2 kN과 같은 크기다.
   - 저장 실행에서 강체 앞내림 행의 접지 다리 이동량 중 약 24 %가 이 체적 안에 있고, 토양 J1 행은 수축 13회 중 6회가 체적보다 짧다.
   - 단품 시험에도 수축 지연이 있다(헤드 해제까지 0.30~0.61 s, 계단 조작·공중·200 bar 조건).
3. **수축 뒤 해제의 힘 항이 빠져 있다.** 로드 34.8 bar g로 잠긴 다리를 다시 신장하면 두 챔버는 2 bar g에서 시작한 경우보다 최대 하중 이동이 3.9~4.2 kN 크고, 현재 법칙은 차이가 0이다. 고치는 비용은 작다.
4. **S8 조항 실패는 압력 동역학으로 설명되지 않는다(추정).** 저장 실행에서 유량 제한은 정지 약 21 s 전에 이미 끝났고, 정지 때 네 다리 힘은 켬·끔이 0.5 kN 안에서 같다.
5. **저속 수축 리밋 사이클이 두 모델 모두에서 나온다(7.8~8.7 Hz, 힘 진폭 17~22 kN).** 체크 밸브 내부 자료가 없어 실제 크기는 말할 수 없다. 넣기 전에 실측이 먼저다.

### 3.2 체크 밸브 열림(`poc_reversal.json`, `poc_numpy.json`, `poc_checks.json`)

단일 다리 FL(현재 치수, 89.5 bar g, 질량 = 정하중/g), 3/8" × 4 m 라인 285 cm³, 유량원 + 미터아웃 오리피스, 중립 A·B→T. 시작 지연은 피스톤이 0.2 mm 움직일 때까지의 시간이다. 괄호는 체크 없는 이상 응답(0.1 s 스풀 지연 포함)이다.

| 명령 | 수축 Hopsan [s] | 수축 numpy [s] | 수축 이상 [s] | 신장 Hopsan [s] | 신장 numpy [s] | 신장 이상 [s] |
|---|---|---|---|---|---|---|
| 0.05 $v_{max}$ | 1.043 | 1.043 | 0.285 | 0.658 | 0.662 | 0.286 |
| 0.1 $v_{max}$ | 0.571 | 0.572 | 0.179 | 0.361 | 0.371 | 0.180 |
| 0.25 $v_{max}$ | 0.284 | 0.284 | 0.103 | 0.214 | 0.218 | 0.103 |
| $v_{max}$ | 0.114 | 0.115 | 0.047 | 0.062 | 0.113 | 0.048 |

- $v_{max}$ 신장의 Hopsan 0.062 s와 numpy 0.113 s는 앞 수축의 울림이 남은 상태라 다르다. 나중 값(0.101, 0.106 s)은 맞는다.
- **수계산**($V$ = 라인 충전 + 로드 챔버 압축, FL, $\beta_{hose}$ 0.5 GPa):

$$\Delta s_{ext}=\frac{V_{line}(p_h+p_{cr}-p_T)}{\beta_{hose}A_h}=0.389\text{ mm},\quad p_{open}=\frac{p_h-p_T+p_{cr}}{\psi}=25.9\text{ bar g},\quad \Delta s_{ret}=\frac{V_{line}(p_{open}-p_T)/\beta_{hose}+V_r(p_{open}-p_{r0})/\beta}{A_r}=1.19\text{ mm}$$

| 기호 | 뜻 | 값 |
|---|---|---|
| $V_{line}$ | MCV~체크 라인 체적 | 285 cm³(**가정**) |
| $\beta_{hose}$ | 호스 유효 체적탄성계수 | 0.5 GPa(**가정**, 1.0 감도) |
| $\psi$, $p_{cr}$ | 파일럿 비, 크래킹 | 3.5, 3 bar(**가정**) |
| $p_T$, $p_{r0}$ | 탱크 배압, 신장 뒤 로드 압력 | 2, 2 bar g(**가정**) |
| $V_r$ | 로드 챔버 체적 $A_r(L_{0r}+s_{max}-s)$ | 1,315 cm³ |

- 비교: 신장 0.05 $v_{max}$ 수계산 0.286 + 0.372 = 0.658 s, Hopsan 0.658 s(**일치**). 수축은 1.14 + 약 0.1 s로 Hopsan 1.043 s보다 약 16 % 길다(**허용 초과**). 크래킹만큼 로드 챔버가 덜 차는 몫(약 0.1 mm)으로 일부만 설명되며 나머지는 미규명이다. 순 지연은 수계산 0.82 mm, Hopsan 0.84 mm다.
- 후방 RL 수계산: 신장 0.465 mm, 수축 1.09 mm, 순 지연 0.64 mm. $\beta_{hose}$ 1 GPa이면 FL 신장 0.19 mm, 수축 1.01 mm.
- **순 지연은 $\psi$와 체크 특성에 민감하다.** 0.1 $v_{max}$ 수축의 정지 뒤 행정 지연은 Hopsan 0.75 mm, numpy 0.37 mm(파일럿 τ 20 ms, 대역 10 bar), 0.67 mm(τ 5 ms, 대역 2 bar)다. 사이클 평균이 끼어 있어 시작 지연보다 불확실하다.
- **중립이 A·B 차단이면** 같은 방향 재출발 지연은 거의 사라진다(0.1 $v_{max}$ 신장 재출발 0.184 s, 이상 0.180 s). 방향이 바뀌는 첫 동작은 남는다. V-6 답이 값을 정한다.
- 시험 대조: `unit_test_noload_analysis.md` 5.2절은 헤드 해제까지 0.30~0.61 s로, 모델의 $v_{max}$ 값(+0.067 s)보다 길다. 조건이 다르다(공중, 200 bar, On/Off). 문서는 로드 초기 상승이 느린 원인을 모른다고 적었다(공기 또는 밸브 전환 후보). 공기가 있으면 체적은 더 커진다(**추정**).

## 4. 최소안

**M1 체크 개방 체적**(항목 5b). 다리별 "채울 체적" 상태를 두고, 유량 적분이 그 체적을 채우기 전에는 $s_{ref}$ 속도를 0으로 둔다(법칙은 잠김 유지).

$$V_{dead}=\begin{cases}V_{line}(p_h+p_{cr}-p_T)/\beta_{hose}&\text{신장}\\ V_{line}(p_{open}-p_T)/\beta_{hose}+V_r\max(p_{open}-p_r,0)/\beta&\text{수축}\end{cases}$$

- 수축 개방 순간 헤드 방출 $V_{line}(p_h-p_T)/(\beta_{hose}A_h)$는 기존 `SpeedReference.shift_reference`로 준다(C-4 경로 재사용).
- 중립 형식 옵션: A·B→T면 잠길 때마다 초기화, 차단이면 방향이 바뀔 때만 초기화.
- 위치: `actuation.SpeedReference`의 flow limit 앞. L1 `L1SpeedActuator`에도 같은 규칙이 필요하다. 축소 하네스 경로도 같다.
- **가정 전부 미확인**: $V_{line}$, $\beta_{hose}$, $\psi$, $p_{cr}$, 중립 형식. 감도 격자는 체적 ×0.5 / ×1 / ×2, 중립 2종.

**M2 로드측 압력 힘 항**(항목 2b, `L2bRodSide._moving_force`). 해제 또는 방향 전환 때 이동 목표 $p^*$와 현재 로드 압력의 차가 헤드 기름 기둥에 남긴 힘을 넣는다.

$$F_{move}=k_2c+R_0e^{-\Delta t/\tau}+\frac{k_2}{k_h}A_{ann}\,(p_{r,rel}-p^*)\big(1-e^{-\Delta t/\tau}\big)$$

- 계수 $k_2/k_h$와 C2 재현은 구현 뒤 확인이 필요한 **제안**이다. C2 대 C3 3.9~4.2 kN을 ±1 kN으로 맞추지 못하면 식을 다시 본다.
- $\tau$는 일단 현행 0.05 s를 쓴다.

### 12.4 M2 기준값

규칙(제안, `m2_check.py` 임시 래퍼에서만 시험): 이동 중 다리는 매 스텝 s_ref += A_ann (p_r,prev − p_r) / k_h(s_ref). 그러면 힘이 (k₂/k_h) A_ann Δp만큼 변한다. 4절의 "R₀ 옆에 항을 더하는 식" 대신 이 형태를 권한다. 재잠금·재해제 때 R₀가 이 몫까지 지워 버리는 문제가 없고, 기존 `shift_reference`를 쓴다.

|---|---|---|---|---|---|
| 몸체 고정, 끝 힘 차(로드 34.818 대 2 bar g) [kN] | 수계산 10.89(계수 0.8804) | 10.88 | 10.70 | 0 | 8.46(**제외**) |
| 자유 몸체 C2 − C3, 끝 힘 FL [kN] | | 4.20 | 4.25 | 0 | 4.13 |
| C2 ΔF 최대 FL / RR [kN] | | 21.15 / 21.89 | 19.79 / 21.16 | 16.65 / 17.95 | 21.51 / 22.21 |
| C2 순 힘 10 Hz 최대 차(대 Hopsan) [kN] | | | 2.67 | 5.61 | |
| C3 순 힘 10 Hz 최대 차 [kN] | | | 1.80 | 1.27 | |
| 비틀림 순 힘 10 Hz 최대 차 [kN] | | | 3.24 | 2.97 | |
| 네 다리 정지 | 변화 없음 | | ΔF 변화 ≤ 0.01 kN | | |

- **Hopsan 제외 이유**: 몸체를 잡으면 질량 Position 편차(약 0.7 mm)가 k_st로 바로 힘이 된다. 끝 힘이 numpy보다 약 20 kN 낮고 끝 p_r도 5.84 / 4.78 bar g로 다르다. 원인을 분리하지는 않았다(**추정**). 자유 몸체 값은 4.13 kN으로 맞는다.
- 비용: C3·비틀림은 약간 나빠진다(최대 +0.5 kN). 이동 배압 목표 5 bar g가 두 챔버의 3 bar g 수준보다 높기 때문으로 보이나 시험하지 않았다.
- 피크가 6~8 % 작은 이유는 τ 0.05 s와 실제 배수 형태의 차이로 추정한다(미시험).
- **제안 허용**: 몸체 고정 ±0.3 kN, C2−C3 끝 힘 ±0.5 kN, 네 다리 정지 변화 ≤ 0.05 kN, 옵션 끔 비트 동일.
- **미시험**: 실 마찰 경로, CB 경로, 신장 뒤 수축 시작(네 다리 회로에 체크 없음). 하네스·L1에 넣을지는 control-expert 판단이다. 스냅숏에 직전 로드 압력이 필요하다.
