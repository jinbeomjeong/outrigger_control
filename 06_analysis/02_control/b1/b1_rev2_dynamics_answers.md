## 결론

1. **D-1.** 초안 1.3 표의 "+2.0~2.7 %"는 실행 전체의 LOC 뒤 최대이고, 거의 전부(**+3.0~3.5 kN**) **탐침·REANCHOR가 만든 비틀림 래칫**이다. 이 최대는 모두 첫 LEVEL이 끝난 뒤의 탐침 단계에서 나온다. 예측 대상 $s^G_{\max}$에 들어가는 **가드 창 안의 초과는 +0.44 / +1.22 / +0.69 %(+0.53 / +1.45 / +0.83 kN)**뿐이다. 그 몫은 크롤러 잔여 하중의 인계 0.05~0.29 kN, 상하 관성 −0.09~+0.20 kN, 비틀림 증가 +0.20~+0.59 kN, 정적 자세로 설명되지 않는 압력 중심 이동(롤 과도) +0.04~+0.69 kN이다. 자세 보정 몫은 +0.05~−0.35 kN로, 예산 다리 쪽에서는 하중을 덜어 주는 방향이다. 실 마찰 부호는 패드 참 하중을 거의 바꾸지 않는다(가드 창에서 추정 ≤ 0.1 kN). 바꾸는 것은 판독 하중과 참 하중의 차이다(창 안에서 2.4~4.1 kN, 폭 1.7 kN).
2. **D-2.** 그렇다. 4점 지지 하중 분배로 설명된다. 다만 $\hat W$가 쓰는 **정정(3식) 분배의 끝 상태**가 아니라 **부정정 비틀림 모드와 과도**로 설명된다. $\hat W$는 "자세 0, $D$ = 0"인 끝 상태를 가정한다. 실제 가드 창 최대는 LOC 뒤 0.6~2.9 s, 자세 보정이 끝나기 전에 나오고, 그때 $D$는 2→4~5 kN로 커져 있다. **P-DL 꼴은 "가산 하중 여유 + 침하 등가 적합"을 권고한다**(3절 꼴 (a), 확인 계산 값 $\Delta F_0$ ≈ 1.73 kN). 자세 비례 항은 적합 행에서 산포를 줄이지 못해 권고하지 않는다(기록만).
3. **D-3.** **시뮬레이션 안에서는 판독 좌표(`s_ref`)에 둔 문턱이 기계 끝에 대해 보수 쪽이다.** 압축 하중이 실 마찰 + 가동부 무게보다 크면 늘 피스톤 ≤ `s_ref`이기 때문이다. **같은 숫자를 실기의 피스톤 판독에 두면 보수 쪽이 아니다.** 기계 여유가 $F/k_h$(모델 6.6 mm @ 119 kN, 실기 $k_h$가 더 무르면 더 큼)만큼 줄어, 피스톤 끝까지 남는 여유가 가드 17.2 mm, FAULT 6.2 mm, 절단 5.3 mm가 된다. 대신 SGS는 실기에서 더 늦게 걸리므로, 시뮬레이션의 SGS·B1 통계는 실기 가용성에 대해 보수 쪽이다. 실기로 옮길 때 문턱을 어느 좌표에 둘지는 결정 사항이다(3절). 유압 쪽 질문은 4절에 적었다. 덧붙여, 모델 규약("행정 센서 = 피스톤")과 L2b 제어기 입력(`meas.stroke` = `s_ref` + 잡음)이 서로 다르다. 이 차이는 control-expert에 확인을 넘긴다.

## 1. D-1 단계별 하중 수지

### 1.1 분해 방법 (정확한 항등식)

네 패드 법선력 벡터 $\mathbf F$를 정정 3식 몫과 비틀림 몫으로 나눈다.

$$\mathbf F = S\,\mathbf g(\mathbf c;\mathbf P) + \frac{\mathbf t\,(\mathbf t\cdot\mathbf F)}{\mathbf t\cdot\mathbf t},\qquad \mathbf g = M^{-1}[1,\ c_v,\ c_u,\ 0]^T,\qquad M = \begin{bmatrix}\mathbf 1^T\\ \mathbf v^T\\ \mathbf u^T\\ \mathbf t^T\end{bmatrix}$$

| 기호 | 정의 | 단위 |
|---|---|---|
| $S = \sum_i F_i$ | 패드 법선력 합 | N |
| $\mathbf c = (c_u, c_v)$ | 법선력 압력 중심(평면 좌표) | m |
| $\mathbf t$ | $[\mathbf 1; \mathbf v; \mathbf u]$의 영공간 벡터(비틀림 모드), $t_{FL} > 0$. 실측 ≈ (0.476, −0.476, −0.523, 0.523) | — |
| $\mathbf c^{st}$ | 정적 압력 중심 = 무게중심을 **연직선**으로 패드 평면에 내린 점(가동부 질량 포함). 경사면 위 강체에서 접선 반력이 패드 평면에 있으면 법선력 압력 중심은 이 점과 같다 | m |

두 시각 $a$(LOC 전 최대), $b$(창 최대) 사이의 $\Delta F_b$를 아래 다섯 몫으로 나눈다. 다섯 몫의 합은 $\Delta F_b$와 4×10⁻¹¹ N 안에서 같다(검산).

| 몫 | 식 | 물리 |
|---|---|---|
| $\Delta S$ | $\Delta S\,\bar g_b$ | 크롤러 잔여 하중 인계 + 상하 관성 $m\,a_n$ |
| 정적 자세 | $\bar S\,[M_b^{-1}(0,\Delta c^{st}_v,\Delta c^{st}_u,0)]_b$ | 자세(roll·pitch) 변화에 따른 무게중심 연직 사영 이동 |
| 압력 중심 나머지 | $\bar S\,[M_b^{-1}(0,\Delta c_v-\Delta c^{st}_v,\Delta c_u-\Delta c^{st}_u,0)]_b$ | 회전 관성, 패드 깊이 차 × 접선력 모멘트, 보간 오차 |
| 패드 위치 | $\mathbf g(\mathbf c_a;\mathbf P_b)-\mathbf g(\mathbf c_a;\mathbf P_a)$ | 패드 평면 위치 변화(≤ 0.01 kN) |
| 비틀림 | $\Delta F^{tw}_b$ | 부정정 모드: 비틀림 루프, 탐침, REANCHOR, 차등 침하, 실 마찰 고착 |

- **REANCHOR**: 반대칭 비틀림 명령(FL·RR −, FR·RL +, 약 7 mm 왕복, 끝 $\Delta s_{ref}$ ≤ 0.45 mm) 한 번에 $D$가 +14.6~+17.5 kN 남는다(FL +3.5~+4.0 kN). 같은 소성/탄성 비대칭 때문이다. 이 단계에서 뒤 패드가 11~23 mm 침하했다(RL 15.9~22.6, RR 11.1~17.6 mm).
- 이 래칫은 **4점 지지(부정정) × SCM 하중·제하 비대칭**의 결과다. 비대칭의 소스 쪽 확인은 terramechanics T-3 답 소관이다.

## 2. D-2 $\hat W$가 음인데 LEVEL 중 하중이 오르는 이유

### 2.1 답

4점 지지 하중 분배로 설명된다. 다만 정정 몫이 아니라 **부정정(비틀림) 몫과 과도**로 설명된다.

- rev1 R1-1 $\hat W_i = r_i\sum_j F_j(n_L) - F_i(n_L)$는 "자세 0, $D$ = 0, 크롤러 몫 인계 끝"인 **끝 상태**의 재분배다. 예산 다리 FL에서 이 값이 음인 것은 맞다. 참 하중으로 다시 재도 $r_{FL} S(t_L) - F_{FL}(t_L)$ = −0.76 / −0.56 / −1.46 kN이다(판독 하중 기준 초안 값 −1,005 / +228 / −1,555 N, C2 부호 차이는 판독 마찰 차이).
- LOC 때 FL이 정적 몫보다 큰 이유는 두 가지다.
  - 남은 앞내림 자세(θ_L = −0.02 / +0.23 / +0.51°, 끝까지 보정하면 −0.29 / −0.58 / −1.39 kN)
  - LOC 때 비틀림($D_L$ = +2.7 / +1.8 / +2.2 kN, FL 몫 +0.59 / +0.40 / +0.48 kN)
- 가드 창 최대는 끝 상태가 아니라 LOC 뒤 0.6~2.9 s의 **과도 상태**에서 나온다. 이때 자세 보정은 아직 덜 됐고(덜어 주는 몫이 아직 작음), 다음 셋이 더해진다(1.2).
  - 크롤러 잔여 인계
  - 비틀림 증가($D$ → +4~5 kN)
  - 롤 과도의 압력 중심 이동
- $\hat W$는 이 셋을 하나도 담지 않는다. 특히 비틀림 몫은 다리·토양 컴플라이언스와 제어기 동작이 정하므로 정정 분배식으로는 원리상 나오지 않는다.
- 첫 LEVEL 뒤 최대(2~2.7 %)는 탐침·REANCHOR 래칫이다(1.3). 이것도 비틀림 몫이다.

### 2.2 제안 P-DL 꼴 ($\rho_{dyn}$ 정의 후보)

모든 후보는 LOC 주기 정보만 쓴다. 예측 대상은 가드 창의 예산 다리 침하 ①이다.

**(a) 권고: 가산 하중 여유 + 침하 등가 적합**

$$\Delta\hat z^{dyn}_i = z_{J2}\big(F^{pad}_{L,i} + \Delta F_0\big) - z_{J2}\big(F^{pad}_{L,i}\big)$$

$$\Delta F_0 = \max_{r}\ \Big[F^{pad}_{L,b}(r)\,\Big(\big(1 + \Delta z^G_r / z_{J2}(F^{pad}_{L,b}(r))\big)^{n} - 1\Big)\Big]^+$$

| 기호 | 정의 | 단위 |
|---|---|---|
| $F^{pad}_{L,i}$ | 초안 R2-3 그대로($F^{pk}_{L,i} - F^{nom}_{s,i}$, 판독 하중) | N |
| $z_{J2}$, $n$ | 초안 R2-3 그대로(J2 연속 Bekker, $n$ = 0.2) | m, — |
| $\Delta F_0$ | 가산 하중 여유(상수, 적합 자료에서만) | N |
| $\Delta z^G_r$ | 적합 행 $r$의 $b^G$ 기하 침하 증가 `pad_sinkage_geometric_m`($t_L$ → $n^G_{\max}T_s$, 1 ms 표본의 가장 가까운 값) | m |
| $r$ | 적합 행 C1~C4·C6(초안 4.3 $\rho_{dyn}$ 행 집합 그대로, C5 제외) | — |

- 꼴이 초안과 다른 점은 둘이다.
  1. **비(×) 대신 가산(+)**: 가드 창 초과의 몫(크롤러 잔여, 비틀림, 롤 과도)은 다리 하중 크기에 비례하지 않는다. 비틀림 모드 모양은 네 다리가 거의 같은 크기(|t| = 0.476 / 0.523)다. 비 꼴은 후방 예산 다리(약 72 kN)에서 여유를 40 % 줄인다. 전방 예산 다리(약 120 kN)에서는 두 꼴이 같은 값이다(아래 표).
  2. **힘이 아니라 침하로 적합**: LOC 때 예산 다리는 아직 침하 중이다($dz/dt$ = 4.6 / 2.3 / 1.9 mm/s). 점성 지연(terramechanics T-1: τ ≈ 0.44 s, 0.5~1.4 mm)이 창 안에서 풀린다. 힘 적합(초안 4.3)은 이 몫을 담지 못해 C2 ①을 1.07 mm 모자라게 예측한다. 침하 등가 적합은 지연을 상수 안에 흡수한다(terramechanics T-2 (ii)의 "상수가 흡수" 선택과 같은 처리).
- 적합 규칙의 "적합에만 참 값" 원칙은 그대로 지킨다. $\Delta z^G$는 참(기하 침하)이고, 하중은 예측자가 쓰는 판독 값 $F^{pad}_L$이다. 그래서 예측자와 같은 공간에서 맞춘다.

**(b) 대안: 초안 그대로(비, 힘 적합)**: $\rho_{dyn} = \max_r[F^{true}_{\max}(\text{창})/F^{true}_{\max}(\le t_L) - 1]^+$.

**(c) 기록만: 자세 항 추가**: $\Delta F^{att}_b = S_L\big[g^u_b\,H_L(-\theta_L) + g^v_b\,H_L\,\phi_L\big]$

| 기호 | 정의 | 단위 |
|---|---|---|
| $S_L$ | $n_L$ 판독 하중 합 − 공칭 $F_s$ 합 | N |
| $g^u_b, g^v_b$ | $M^{-1}$의 $(b, u)$, $(b, v)$ 원소($\approx \sigma^x_b/2L_x$, $\sigma^y_b/2L_y$) | 1/m |
| $H_L$ | $n_L$에서 무게중심의 패드 평면 위 높이(YAML `com_m` + 몸체 자세, 오거 단계별 1.97~3.35 m) | m |
| $\theta_L, \phi_L$ | $n_L$ `att_raw_rad`(목표 0으로 가는 남은 보정량) | rad |

- 적합 행에서 이 항은 READY 예산 다리에서 음이다(−0.29 / −0.58 / −1.39 kN). 넣어도 남는 상수의 산포가 넓어진다(판독 하중 공간에서 자세 항 없이 0.73~1.73 kN, 부호 그대로 빼면 0.42~2.34 kN). 창 최대가 자세 보정이 끝나기 전에 나오기 때문이다. **권고하지 않는다.** 검증 행에서 예산 다리가 LOC 때 오르막 쪽으로 기울어 있으면(과보정) 양이 되므로, 기록으로만 낸다.

| 예외 | 하중이 거의 없는 다리(공중, TOUCH 전, $F < F_s + mg$)는 피스톤이 `s_ref`보다 최대 $(F_s + mg)/k_h$ ≈ 0.28 mm 클 수 있다. 문턱 여유(≥ 5 mm)에 비해 무시할 만하다 | 계산 |

| 제하 때 피스톤 이동 | 유량 없이 하중이 빠지면 피스톤이 `s_ref` 쪽으로 $\Delta F/k_h$ 올라간다. 탐침·비틀림 래칫($\Delta F$ ≈ 6 kN)이면 0.33 mm, 완전 제하(패드 들림)이면 6.6 mm다. 완전 제하에서는 피스톤이 끝에 닿아도 하중이 없어 구조 문제는 아니다(끝 쿠션은 4절 H-3) | 계산 |

- **결론**: "판독 좌표에 문턱을 둔다"는 지금 규약은 **시뮬레이션 안에서는 보수 쪽**이다. 실기로 옮길 때는 둘 중 하나를 정해야 한다(설계 결정, control-expert·사용자).
  1. **피스톤 판독에 같은 숫자**: 하중과 무관하고 피스톤 끝에 대한 여유가 정확하다. 그러나 시뮬레이션이 보인 것보다 기계 여유가 $F/k_h$ 작고, 제어 거동(가드 시점)이 시뮬레이션과 다르다. 피스톤 기준 최소 여유 5.3 mm(절단)·6.2 mm(FAULT)가 실린더 끝 쿠션·끝 정지 설계에 비춰 충분한지는 제조사·hydraulics 확인 사항이다.
  2. **기름 좌표 추정 $\hat s_{ref} = s_p + \hat F/\underline{k}_h$**: $\underline k_h$는 실기 $k_h$의 **하한**(가장 무른 값)이다. 하한을 쓰면 $\hat s_{ref} \ge s_{ref}$라 시뮬레이션보다 먼저 멈추고(보수 쪽), 제어 거동이 시뮬레이션과 가깝다. 대가는 행정 예산 손실 $\hat F(1/\underline k_h - 1/k_h)$다. $\hat F$는 압력 센서 순 힘(normal 등급 오차)이라 그 오차가 문턱에 $\delta F/\underline k_h$로 들어간다(예: 1 kN → 0.06 mm, 무시할 만함).
- **모델 규약 차이(확인 넘김)**: CLAUDE.md 모델 규약은 "행정 센서는 실린더 내장형, `stroke_true = s_motor − F_cyl/k_oil`"(피스톤)인데, L2b 제어기 입력 `Measurements.stroke_m`은 `s_ref`(`l2b_engine.py` 212행)다. 영향을 받을 수 있는 것은 다음과 같다(이 답에서 평가하지 않음).
  - 행정으로 계산하는 크롤러 틈 추정 ĉ
  - LOC 10 mm 평탄 창
  - 행정 변화량 평면 맞춤
  - READY 꼬리
  - 행정 예산 가드

  앞뒤 다리 차(약 2.7 mm), 들어 올림 중 하중이 0 → 120 kN으로 바뀌는 동안의 판독 차(0 → 6.6 mm)가 이 기능들에 들어간다. 제어기가 실기에서 어느 좌표를 볼지 control-expert에 확인을 넘긴다(4절).

## 5. 가정

- 다리 가동부 질량을 패드 위치의 점질량으로 두었다(정적 압력 중심 계산). 무게중심은 YAML 상부체 값(크롤러 포함)이고, 실제 Chrono 몸체 분할과의 차이(일정 오프셋 약 4 mm)는 차분에서 지워진다.
- 상하 관성은 `z_origin_m`의 두 번 미분(21 ms 상자 2회)이다. 회전 관성은 따로 계산하지 않고 "압력 중심 나머지"에 남겼다.
- 실 마찰 부호의 패드 하중 영향(≤ 0.1 / ≤ 1.1 kN)은 강성 추정에서 낸 값이고, 자료에서 떼어 낸 값이 아니다.
- `att_raw_rad`의 열 순서를 [roll, pitch]로 가정했다(`step_series` `roll_pitch_deg`와 LOC 때 값이 맞음: C3 −0.052 / +0.516° 대 −0.061 / +0.514°).
- 실기 $k_h$는 모름. 3절의 6.6 mm는 모델 값이다.
