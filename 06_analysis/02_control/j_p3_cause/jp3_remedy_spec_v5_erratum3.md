## 3-1. 정오 2 2-10의 적용 범위
- 2-10의 "실패"는 **판정 항목의 실패**만 가리킨다.
- **기록 실패는 닫힌 목록이다.** 원판 6.2가 "판정·멈춤 조건이 아니다"라고 정한 T-JR-12a의 13.9 지표만 기록 실패다.
  - 그 지표: 새 FAULT, 첫 READY(+30 s 초과·상실), L2 등급(전이 포함), 지배 읽기 감소율
  - 이 지표의 실패는 2-10의 실패로 세지 않는다.
  - 이 목록에 없는 문제는 모두 입력 결함(`setting_defect`·`not_judgeable`)으로 본다. 예: 실행 기록 정합 실패(lock window 불일치로 짝 비교 전에 끝남), 짝 수·판정 행 수 불일치, 입력 sha 불일치, 키 없음.
- 기록 도구 보고(T-JR-12a VBH·VBJ, `base-judge-compare`)는 다음 순서로 처리한다.
  1. 보고 안의 판정 항목이 H-7이면 종료 1로 멈춘다(2-10 우선). 해당 판정 항목은 VBJ 묶음의 J-P3다(원판 6.2·6.1). 같은 보고에 있는 결함 사유도 함께 기록한다.
     - 1의 H-7은 정오 2 2-10.1 (5)대로 판정 행에서 직접 읽는다. 결합 상태 하나에 기대지 않는다.
  2. 1에 해당하지 않고 `setting_defect`나 `not_judgeable`이 있으면 종료 2로 멈춘다(입력 결함).
     - **VBJ 보고에 J-P3 판정(판정 행 수와 상태)이 없으면 판정 불가로 보고 종료 2로 멈춘다.** 짝 비교 전에 끝난 보고(예: lock window 불일치)는 J-P3가 계산되지 않았으므로 여기에 해당한다. 판정 행 0도 판정 불가다(통과가 아니다).
     - lock window 불일치(실행 기록 정합 실패)는 기록 실패가 아니라 입력 결함으로 보고 이 2번 순서(종료 2)를 따른다.
  3. 1·2 어느 쪽도 아니면 13.9 지표의 기록 실패가 있어도 단계를 계속한다. 기록 값은 판정서에 공개한다.
