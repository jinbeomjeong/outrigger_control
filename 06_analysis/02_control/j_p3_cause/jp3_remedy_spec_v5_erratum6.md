- 판정서에는 머리말 공개 목록과 멈춘 이유를 적는다.

## 6-6. 판정 도구 건식 확인(D-6, 실행 전)
- 새 실행 커밋의 준비 전에, 실데이터로 돈 적이 없는 판정 경로를 합성 입력으로 끝까지 돌린다. 판 5 판정 출력은 입력으로 쓰지 않는다.
- 합성 입력: 저장 기준선 줄(판 4a 기준선 221456d, 저장 H-6, `main.jsonl` 등)을 복사해, 설정 이름·태그·③ 정체성만 판 5 꼴로 바꾼다(rev 6 봉인 정체성, VBG6, VBK·VBK0, VBJ·LSJ).
- 대상
  - `jp3_baseline_compare main`(A~E, VBG4·VBG6, `case_bd_conditions`)
  - `jp3_case_judge`(x11, case-f)
  - `jp3_tjr_judge`(t8, t12 VBH·VBJ와 `jp3_outcome`, records의 T-JR-13~15)
  - `jp3_12b_judge`(decide·judge·grade-judge)
  - `jp3_j9main_judge`
  - ckdrop 기록, P5-1, P5-2·P5-4 대조
- 단언
  - (가) 짝 수가 기대와 같다.
  - (나) 문제 분류 전부(실패·`setting_defect`·`not_judgeable`·기록)가 기대와 같다.
  - (다) 종료 코드가 정확히 기대값이다("0/1/2 가운데 하나" 같은 넓은 단언은 쓰지 않는다).
  - (라) 부정 단언: 판정 항목마다 합성 실패 사례를 하나씩 넣었을 때 그 항목이 실패(종료 1)로 잡혀야 한다. 대상은 다음과 같다.
    - E의 P4-1·P4-3a
    - A·C의 P4 전 항목
    - B·D의 6-2A 조건: B J-P3a, B J-P3b, D (D-가), D (D-나) 덮음 실패(간격 ≤ 0), 같은 순서일 때의 D (D-다)
    - X11(P4-5a)
    - P5-2 대조
    - 12b (1)~(4)
    - j9_main의 J 항목·LS 조건
  - (마) 6-2A 판정 불가 경우마다 종료 2가 나와야 한다: C 위반 0, C 건수 ≥ 2, `first_breach_t_s` 없음, 같은 시각의 VBG6 읽기 없음.
  - (바) 6-2 대상 항목(P4-2·P4-4·P4-9)은 합성 위반을 넣어도 기록으로 분류되고 종료 코드를 바꾸지 않아야 한다.
- 이 확인은 판정이 아니다. 하나라도 실패하면 도구를 고치고 다시 확인한 뒤에 준비로 넘어간다. 6-2 범위를 벗어나는 같은 꼴 항목이 나오면 멈추고 정오 7로 간다. 통과한 시험 목록과 sha는 실행 전 감사에 넘긴다.
