## 2. 선정 출력에 남길 것과 키 생성 규칙

- `select` 출력에 아래를 더한다.
  - 제외 경로 문자열(`02_control/j_p3_cause/j9_runs/`)
  - 제외한 파일 수
  - 제외한 파일마다: 상대 경로, sha256, r79 키 수, 생성 키를 담고 있는지(참/거짓)
- 기존 스캔 증거도 제외 밖 기준으로 남긴다: 스캔 파일 수, 파일별 sha256·키 수, seed 최댓값.
- 4a-4 2절 키 생성 규칙은 그대로다. 기본 키의 seed 토큰만 `s25`부터 올리고, 생성 키가 **제외 밖 스캔**의 키와 같으면 하나씩 올린다.
- 고정 키 파일(정오 1, sha256 `1a79e02f…`, `L2|s25|g6|0|g6|G1+J1@FL|top|Fs0`)과 맞으려면 생성 키가 $n$ = 25여야 한다. 그러므로 **s25 키는 제외 밖 스캔 어디에도 없어야 한다**. 있으면 $n$ ≥ 26이 되어 키 파일 sha가 맞지 않으므로, 그대로 멈추고(판정 불가) 사용자에게 다시 묻는다.
