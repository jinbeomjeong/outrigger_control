## 2. r79 건식 확인 키 생성 규칙(D1)

- 기본 키: 4a-3 5.1절 선정 규칙의 r79 후보를 그대로 쓴다. 저장 `h8_noise_VB.json`의 L2 키 가운데 파일 순서상 첫 번째로 Dg-3 135키에 없는 키이고, `738a09f`에서는 `L2|s0|g6|0|g6|G1+J1@FL|top|Fs0`이다.
- **seed 토큰만 바꾼다**: 두 번째 토큰 `s<n>`을 `s25`로 바꾼다. 나머지 토큰(레벨 `L2`, 계열·사례·바닥·오거·$F_s$ 토큰)은 기본 키 그대로 둔다. 바뀐 키가 1절 스캔의 어떤 키와도 같으면 $n$을 1씩 올린다(26, 27, …).
- 실행기가 그 seed를 받는지 확인하고, 아래 가운데 하나라도 아니면 **멈추고 사용자에게 다시 묻는다**. 판정 집합 안의 키로 대신하지 않는다.
  - 실행이 오류 없이 끝났다.
  - 출력 줄의 `key`(접두를 뗀 값)가 생성한 키와 같다.
  - 출력 줄의 seed 기록(`seed_index` 또는 같은 뜻의 필드)이 $n$이다.
- 선정 출력에 남길 것: 기본 키, 생성 키, $n$, "1절 스캔에 없음"의 증거(스캔 파일 수와 seed 최댓값), Dg-3 135키에 없음.
