## 8. 경로 2에 넘길 정의(이 절만 넘긴다)

8.1 **B2 증거**
- 줄마다 `rod_reading_truth_calls`(①)와 `two_pressure_reads`(②)를 읽는다. 키가 없으면 0으로 읽지 않고 설정 결함이다.
- P4를 켠 줄(`v5_setting` VBJ·VBJ0·LSJ*, P4 사례 줄)은 ① = k·② > 0이다.
  - key가 `L<n>|s<m>|…` 꼴이고(앞의 `cand=…#`는 뗌) 셋째 토큰이 `g8`이면 k = 2, 그 밖은 k = 1이다.
- P4를 끈 줄은 ① = 0이고 ② > 0이다. 헤드 전용 선언 줄은 ① = ② = 0이다.
- 어기면 그 묶음은 `setting_defect`(판정 불가)다.

8.2 **r79 등급 판정의 L1 참조**
- 등급 줄은 (`harness`, `inner`, `rod_model`, `candidate`)가 같은 L1 줄과 짝짓는다.
- VBH 줄의 참조: 저장 잡음 VB 파일(sha `2219ab97…`)의 L1 줄 167개(`rod_model` = `dyn_map`).
- VBJ 줄의 참조는 `v5_setting` = VBJ, VBJ0 줄의 참조는 `v5_setting` = VBJ0인 새 L1 줄이다. 둘 다 `rod_model` = `plant_truth`다.
- 새 L1 줄 집합:
  - 저장 H-6(sha `ea0ab94c…`) 135줄의 서로 다른 (`harness`, `inner`) 102개마다 key `L1|s0|<harness>|<case_index>|<inner>` 한 줄씩.
  - 오류 줄 0, `level` = L1, `candidate` = `current`.
  - 하나라도 어기면 판정 불가다.

8.3 **판정 행 수**
- 묶음마다 등급이 매겨진 줄 = 135(입력 키 135와 같은 집합)다. 짝 없는 줄·오류 줄이 1 이상이거나 판정 행이 0이면 판정 불가다.

8.4 **VBJ 재판정 입력**
- 실행 커밋 `78fd5d2d…`의 VBJ·VBJ0 Dg-3 출력(sha `603e4b81…`, `c1201b2d…`)과 8.2절 새 L1 줄로 판정한다. T-JR-12 판정 문장(13.9절)은 그대로다.
- VBH 묶음은 판정이 끝났다(실패). 다시 판정하지 않는다.

8.5 **건식 확인 계열**
