# 판 5 control 통합 판단(2026-11-21) — 관문 플랜트 VBK(가) 권고

control-expert hand-back 원문 요지. 초안 `jp3_remedy_spec_v5_draft.md` 0~10절 교체본 제안과 12절을 담는다. 사용자 답을 받은 뒤 초안에 반영한다(초안 11절 "메인 기록"은 그대로 둔다).

## 권고
- T-JR-12b 합격 관문 플랜트: VBH형(11-21 사용자 결정)을 **VBK(가)로 바꾼다**. VBK(가) = P1~P4 + 지정 다리 로드 센서 고장 주입(대체 래치)이고, 짝은 VBK0(같은 플랜트·seed·주입, ③ 끔)이다. 판정은 13.9절 0 건수를 그대로 쓴다.
- 근거
  - F7·F8: VBH 지배 비용의 77 %는 VB 플랜트 산물이다.
  - 판 4a 6.1·6.4절이 이미 VBH·LSH의 J-P3를 "플랜트 산물"로 보고 판정에서 뺐다. 판 4a가 같은 플랜트를 비용 관문으로 쓴 것은 자기 정의와 어긋난다.
  - VBJ형(자연 대체 약 3 %)은 대체 기회가 너무 적다.

| 관문 후보 | 대체 기회 | 물리 대표성 | R5-9 건전성(A7) | 판단 |
|---|---|---|---|---|
| VBH형 | 약 140/504짝 | 낮음(H-4) | A7 밖 | 비권고 |
| VBJ형 | 약 15 | 높음 | 성립 | 비권고(m이 수십 배 필요) |
| **VBK(가)** | 주입한 짝 전부 | 높음 | 성립 | **권고** |

- 통계 설계는 **다시 해야 한다**. 기회 구조가 주입 설계(다리·시각·고장 종류)로 바뀌기 때문이다. 다음은 그대로 쓸 수 있다: 0 건수 판정, 12a 공개 원칙, seed 30+j, "+30 s" 반올림, 통과 문장 꼴.
- 12a(VBH 135키): 멈춤 조건에서 **기록**으로 바꾼다. 기록 항목은 지배 읽기 감소율이고, 기대치는 약 23 %다.
- 공개: 관문을 옮긴 것은 결과를 본 뒤의 결정이다. 동기는 물리 근거와 VBH 관문의 재실패 추정 두 가지다.

## 유압 확인 항목
control은 아래 항목에 모두 동의한다.
- CARRY 읽기에서만 목격한다.
- 문턱은 명령 방향으로 1.0 mm, 기준은 운반 직전 읽기다.
- **R5-10**: R5-9 뒤 수축 HOLD의 R5-2 후보에 $\hat p+\delta_m$을 넣는다.
- 수축 끝 가드는 `stroke_m` 판독 ≤ 15.2 mm다.
- 재잠김 $M_j$는 창 표본 시각의 $\hat p(t_j)+\delta_m$이다.
- VBK(나)(P4 끔)는 비권고다. `fallback_false_high_reads`는 VBH 기록에 남긴다.

## 남은 질문의 답
- **j9_main 0 건수 기준**: 있다. v5 기준 12절 "VB J1~J11 실패 0"이다(J3 READY 절대 한계, J7 새 FAULT·WARN·대체 사유, V0 대비). 대체가 드물어 대체 경로 비용은 12b가 맡는다.
- **c 사전 추정**
  - VBH형: 0.1~0.2(판 4a에서 대체 행 133 중 20)
  - VBK형: 0.3~0.8(넓다)
  - 건식 확인으로 정한다. c ≥ 0.5면 규칙을 다시 묻는다.
