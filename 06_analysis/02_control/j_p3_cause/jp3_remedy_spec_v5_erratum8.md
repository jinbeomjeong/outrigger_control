## 8-5. 12b 관문 전체의 결합 거짓 실패율(기록)
- 관문 실패 = (1) 새 FAULT ≥ 1, 또는 $n_{23}>k_{allow}$, 또는 (4) J-P3 H-7.
- (4)는 VBK 줄에만 정의되어(VBK0는 ③ 끔) VBK0 자료로 추정할 수 없다. 아래 표의 범위는 **(1)과 (2)+(3)만의 결합, b1·b2(판정 짝 334)**다.
- $P_1$: 고장 주입 VBK0 494줄에서 FAULT 줄이 0이다(관측 0/494). 줄당 비율 $q$에 명령이 갈린 짝 비율 c와 판정 짝 334를 곱해 Poisson으로 $P_1 = 1-e^{-c\cdot334\cdot q}$를 계산했다. $q$는 셋을 쓴다.
  - Jeffreys 중심 추정: $q$ = 0.5/495 = 0.10 %
  - 줄 단위 단측 95 % 상한: $q = 1-0.05^{1/494}$ = 0.60 %
  - 사례 단위 단측 95 % 상한: $q = 1-0.05^{1/167}$ = 1.78 %
  - 줄 단위 상한은 사례 안 상관(같은 사례의 줄끼리 FAULT가 함께 나기 쉬움) 때문에 비보수다. 사례 단위 상한이 그 반대쪽 끝이다.
- 결합: (1)과 (2)+(3)은 같은 짝에서 함께 나기 쉽다(FAULT가 READY 상실을 동반). 그래서 결합 거짓 실패는 $\max(P_1, P_{23})$ 이상, $P_1+P_{23}$ 이하로 적는다. 독립식 $1-(1-P_1)(1-P_{23})$은 그 사이의 위쪽 근사다.

**표: 0/494로는 배제할 수 없는 거짓 실패 확률**(출처 `stats_e8_review/e8_review_check.json`, sha256 `78fe972488b086c03c7877089fe7d89fc7a099d9f974f82f9ccc7f2d027a3bef`; 스크립트 `e8_review_check.py` `ab2b0764d7d677c2acff245e3709840f936e532cb1cb96cee2fafc9c5e0fd553`)

| F0(c 0.127) | 0.00 % | 0 | 4.2 % | 22.6 % | 53 % | 22.6 % / 22.6 % / 22.6 % |
| F2u(c 0.189) | 0.35 % | 0 | 6.2 % | 31.7 % | 67 % | 31.7 % / 32.0 % / 32.1 % |
| F3(c = 1) | 2.06 % | 0 | 28.6 % | 86.7 % | 99.7 % | 86.7 % / 87.0 % / 88.8 % |

- 해석: **(1)의 바닥 때문에, 해가 없는 rev 6이 c 건식 기준으로 최대 약 23 %(사례 단위 53 %) 실패할 수 있다는 가능성을 0/494로는 배제하지 못한다.** 중심 추정은 4~6 %(c 건식), c = 1이면 29 %다. 따라서 관문 전체의 거짓 실패 위험은 (2)+(3)보다 (1)에서 더 클 수 있다. 관측된 바닥은 0이고, 이 표의 $P_1$ 값은 모두 표본 크기 494(사례 167)에서 오는 불확실성이다.
- b4를 더하면 $P_{23}$은 F3 2.6 %, F2u 0.48 %다($k_{allow}$ = 9). (1)의 판정 짝은 약 500으로 늘어 $P_1$이 커진다($\lambda$ × 약 1.5).
