## 2-3. 고정 입력 목록에서 코드·run steps를 뺀 것 — **인정(조건 넷)**

  4. 판정서는 실행 커밋 sha와 run steps 경로(실행 커밋 안의 경로)를 인용한다. 메인 checkout의 같은 이름 파일은 인용하지 않는다.
