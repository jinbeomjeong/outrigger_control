## 2. B2 증거 규칙 정정: ① = k·②(결과 전)

4a-2 4절 B2 행, 4a-3 3.2절, 4a-4 3절 표 4행, 4a-5 2절 표·3.1절의 "① = ②"를 아래로 바꾼다. P4를 끈 줄(① = 0, ② > 0)과 헤드 전용 선언 줄(① = ② = 0)은 그대로다.

| 줄 | k | P4 켬 줄(VBJ·VBJ0·LSJ·E 군 등)의 기대 |
|---|---|---|
| r79 줄, key 셋째 토큰 = `g8` | 2 | ① = 2·② > 0 |
| r79 줄, 셋째 토큰 = `g6`·`ref` | 1 | ① = ② > 0 |
| r79가 아닌 줄(run_v5 배치 `j9_t8`·`j9_cases`·`j9_case_f` 등) | 1 | ① = ② > 0 |

- r79 줄은 key가 `L<레벨>|s<seed>|…` 꼴인 줄이다. `cand=…#` 접두는 떼고 읽는다.
- k는 관측 비율에서 정하지 않고 실행 경로에서 정한다. G8 경로는 제어 주기마다 P4 판독(순수 함수: 같은 입력이면 같은 값)을 두 번 거친다. 한 번은 사례 진행 단계, 한 번은 센서 전달 단계다. 그래서 판독 값과 명령은 같고 ①만 두 배다.
  - 경로 1 위치: `r79_sensor_screen.py:844`(G8 주기의 `r64.with_two_pressures`, P4에서는 `harness_hydraulics.with_plant_truth_pressures`로 바뀜)와 `:277`(rod 판독 함수).
- 공개: 이 정정은 실행 중 기록(`dg3_a1` VBJ·VBJ0 g8 40줄에서 ① = 2·②, 나머지 95줄에서 ① = ②)을 보고 찾았다. VBJ 판정 값을 보기 전이다.
- 영향 범위: 78fd5d2d 실행에서 정정으로 판정이 달라지는 줄은 VBJ·VBJ0 Dg-3의 g8 40줄뿐이다.
