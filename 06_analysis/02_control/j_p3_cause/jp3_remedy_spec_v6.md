### 3.1 A(i) 적응형 LEVEL 불감대 보상
- **적용 단계**: LEVEL(재레벨 포함). PROBE·TOUCH·READY·DONE·FAULT·FAULT_REGROUND에서는 끈다.
- **목격 추정(E3, stats 채택)**: 구간의 행정 변화는 끝점마다 **3읽기 평균**의 차다. $\Delta s=\bar s_{[k-2,k]}-\bar s_{[k_s,k_s+2]}$이고, 명령 방향 부호를 곱한다. 단일 읽기 차(E1)는 쓰지 않는다. 같은 문턱에서 거짓 목격이 8배 크고 거짓 끝이 5~30 %이기 때문이다(stats 설계안 1).
- **정지 목격(트리거)**: 다리 $i$에서 다음을 모두 만족하면 "명령은 있는데 움직이지 않음"으로 본다.
  1. 연속 구간 동안 작용 명령의 부호가 같고 $\lvert u\rvert>u_{hold}$
  2. 구간 길이 ≥ $N_{trig}$ = **10** 주기
  3. 명령 누적 변위 $D_{cmd}=\sum\lvert u\rvert T_s\ge D_{trig}$ = **0.5 mm**
  4. E3 행정 변화 $\Delta s<\eta D_{cmd}$, $\eta$ = **0.25**
  - 거짓 목격(움직이는 다리를 정지로 봄)은 연속 구간당 최대 2.1 %다(유량 계수 f 0.7, u 0.25 mm/s). f 0.85에서 0.14 %다.
  - 진짜 교착 검출은 u 0.22 / 0.4 / 0.75 mm/s에서 중앙 2.3 / 1.3 / 1.0 s다(stats s10).
  - η 0.5는 쓰지 않는다(f 0.7 다리를 정지로 봄).
- **동작**: 트리거 뒤 매 주기 그 다리 명령의 크기를 $\lvert u\rvert\leftarrow\max(\lvert u\rvert,\,u_{k})$, $u_{k}=\min(u_{k-1}+\Delta u_{step},\,u_{cap})$로 올린다.
  - 시작값 $u_{0}=\max(\lvert u\rvert,\,u_{hold})$
  - $\Delta u_{step}$ = **0.2 mm/s/주기**
  - $u_{cap}$ = **1.05 mm/s**(0.05 $v_{max}$). $c_v$ 0.04 문턱의 점근값 $c_vv_{max}$ = 0.837 mm/s, 350 bar 수축 문턱 0.81 mm/s를 넘는다(hydraulics 5절). 앞 판의 "0.8 이상 제안"은 모서리에서 모자라 바꿨다.
  - 값의 출처: stats 1차 권고(Δu 0.05, $u_{cap}$ 1.0, $N_{cap}$ 30)와 hydraulics 권고가 달랐다. hydraulics 값을 쓰고 stats가 다시 확인해 수용했다(`ed6_design/stats_v6/s21_recheck_h6.txt`·json, 사용자 결정 2026-11-23).
    - E3 거짓 끝 ≤ 0.06 %
    - 과이동 p95 0.85~0.97 mm($d$ = 1 포함, 약 0.011°)
- **끝**: 다음 가운데 하나다.
  - 움직임 목격: 같은 방향 E3 $\Delta s\ge s_{w,A}$ = **0.4 mm**. 열린 뒤 과이동은 $s_{w,A}$ + 약 0.21 mm다(hydraulics 5절).
  - 명령 부호 바뀜
  - $\lvert u\rvert\le u_{hold}$
  - 단계가 바뀜
  - 상한에서 $N_{cap}$ = **50** 주기 지남. 이때 끝내고 `INFO_LSB_CAP:<leg>` 사건을 남긴다.
    - A(i) 단독 수축은 하중 수축 need 3.1 mm에서 열림까지 3.4 s(Δu 0.2, cap 1.05)가 걸린다(hydraulics 5절).
    - R12 need 최대 4.14 mm에서는 40주기로 부족하다. 그래서 50으로 정했다(stats 재확인 `s21_recheck_h6`).
- **부호**: A(i)는 명령 부호를 바꾸지 않는다. 펄스 p95 0.73 mm(stats 권고값 Δu 0.05·cap 1.0 기준, 채택값에서는 재확인)는 축간 4.85 m에서 약 0.009°로 완료 데드밴드 0.03° 아래다. $n_{rev}$(L-c)는 probe에서 실측한다.
- **우선순위**: 행정 끝 감속, 들림 가드, 크롤러 구역 규칙, FAULT 정지, 증분 제한이 A(i)보다 우선한다.
- **완료 조건**: LEVEL 완료 조건(`_update_completion`)은 바꾸지 않는다(Q6-10 닫힘). A(i)만으로 교착을 푼다.
- 기록: 다리별 트리거 수, 상한 도달 수, 첫 목격까지 주기.

### 3.2 A(ii) 잠김 출발 충전 바닥
- **적용**: 모든 단계. 다리가 "잠김 추정" 상태에서 $\lvert u\rvert>u_{hold}$로 출발하는 주기부터다.
  - 잠김 추정 = 직전 $N_{lock}$ = **2** 주기 동안 작용 명령이 $\lvert u\rvert\le u_{hold}$였거나, 방향이 바뀐 첫 주기(선 비움)
    - 근거(stats `[추정]`): 체크 닫힘 $t_c$ 50 ms, 라인 배수 수십 ms~0.2 s
  - ③ 분류의 LOCK·HOLD → CARRY 전환과 같은 시점이다.
- **수축 충전 하한** $x_{lb}$(hydraulics 1절, 강건 하한 세트, $\kappa_{fill}$ = **1.0**)
  - $x_{lb}(k)=x_{need}(p_{h,k},p_{r,k},s_k,\text{void}_k)$를 **매 주기 다시 계산**한다. 충전 중 하중이 정점을 지나면 need가 줄기 때문이다.
  - void 복원식(두 챔버 판독, 잠김 시작 읽기 $k_0$를 앵커로)
    $$\text{void}_k=\max\!\Big(0,\ \frac{(L_{0h}+s_0)(p_{h,k}-p_{h,0})}{\beta_{hi}}+\frac{(L_{0r}+s_{max}-s_0)(p_{r,k}-p_{r,0})}{\beta_{lo}}\Big)$$
    - β는 헤드 항 상한 1.6 GPa, 로드 항 하한 0.69 GPa다. 같은 센서의 차라 오프셋이 지워지고 바닥 검출이 필요 없다.
    - 장시간 잠김에서 POC가 새어 음수가 되면 0으로 자른다(보수).
    - 플랜트 기록과의 차는 +0.023~+0.030 mm(64건)이다.
  - $x_{need}$의 나머지 항은 `check_open_delay.retract_dead`와 같은 식이다. 고정값은 **강건 하한 세트**다.
    - ψ 6, β 1.6 GPa, $V_{line}$×0.5, $L_{0r}$ 0.02 m, $\beta_{hose}$ 1.0 GPa, $p_{cr}$ 1 bar
    - band 2·$F_{s,max}$(전방 16 / 후방 13.3 kN)
    - 판독 여유 ±4 bar
  - 하한 보장(hydraulics 하한 보장 표): 같은 읽기 기준 κ_max 1.644, 그 뒤 need 최소 기준 1.188이다. 그래서 κ 1.0의 여유는 19 %다.
  - stats 재확인(`s21_recheck_h6`): 하한 초과 충전은 0.003 %(최대 0.08 mm)다.
  - **κ 1.0은 강건 하한의 마찰 band 항(2·$F_{s,max}$)을 포함한 $x_{need}$를 매 주기 다시 계산할 때만 성립한다.** band 항을 빼거나 잠김 시작 값으로 고정하면 성립하지 않는다. 그 경우 명세 하한 세트와 κ ≤ 0.85로 돌아간다.
  - 크기: $x_{lb}$ 시작값 0.42 / 0.94 / 1.40 mm(최소/중앙/최대), need의 26~40 %다.
  - **정정**: 앞 판의 "공칭 예 약 1.7 mm"는 void 공칭을 넣은 범위 상단이라 하한이 아니다(stats 지적 2, hydraulics 1절).
- **신장 충전 하한**(hydraulics 2절 권고 식으로 교체)
  $$p_{A,lb}=\max\big(p_T+(p_r-e+p_{cr}-p_T)/\psi,\ p_h-e+p_{cr}-\psi(p_r+e)\big),\qquad x_{lb}=(p_{A,lb}-p_T)\,V_{line}\times0.5/(A_h\beta_{hose})$$
  - 고정값: ψ 6, $p_{cr}$ 1 bar, $\beta_{hose}$ 1.0 GPa, e 4 bar. 값은 0~0.21 mm다.
  - 앞 판 식($p_B=p_T$ 가정)은 체적 0.5 플랜트에서 하한이 아니었다(로드 30 bar에서 5.5배).
  - **신장 A(ii)는 정의만 두고 probe와 봉인 범위에서 뺀다.** 1증분 1주기 0.52 mm보다 작아 효과가 작고, LEVEL 신장 정지는 A(i)가 맡는다. 옵션 이름은 남기고 기본 꺼짐이다.
- **동작(미리보기, 증분 제한 대칭)**: 매 주기 다음 출력 후보 $u^{+}$를 고를 때, **지금 $u^{+}$를 낸 뒤 증분 제한으로 내림 램프를 끝까지 탔을 때의 총 명령 변위**를 계산한다.
  $$X^{pv}=X+\lvert u^{+}\rvert T_s+\text{내림 램프 몫}(\lvert u^{+}\rvert)$$
  - $X^{pv}\le x_{lb}$인 가장 큰 후보(증분 제한 안, $\le v_{max}$)를 낸다.
  - 증분 제한(`c2.py` `_limited_increment`)은 올림·내림 모두 0.25 $v_{max}$/주기다. 내림 몫을 빼면 "X ≥ $x_{lb}$ 뒤 원래 명령으로"가 넘쳐 과이동한다(체적 0.5에서 1.40 mm, hydraulics 추가 항목).
  - 원래 명령이 후보보다 크면 원래 명령을 쓴다. A(ii)는 바닥이고 원래 명령을 깎지 않는다.
- **끝**: 다음 가운데 하나다.
  - 미리보기 내림 램프를 마쳐 $X\ge x_{lb}$
  - 수축 열림 목격: **로드 압력 상승** $w_r(k)=p_{r,read}(k)-\min_{[k_s,k]}p_{r,read}\ \ge\ \max\big(3\ \text{bar},\ 0.5(p_{open,lb}-p_{r,read}(k_s))\big)$(1읽기), 또는 잠김 출발 읽기 대비 **단일 읽기 차** $\Delta s\ge$ **1.0 mm**(개정 13: 구현 `lock_start_b.py` 892~896과 hydraulics 근거 $\sigma_\Delta$ 0.14 mm의 7σ에 맞춤. A(i)의 E3와 다르다)
    - 헤드 압력 신호는 쓰지 않는다. 하네스에서 열림 전에 64건 중 61건이 거짓 발동했다(hydraulics 3절).
    - 하네스(게이트 모드)에는 열림 전 로드 상승이 없다. 그래서 로드 목격은 열림 다음 읽기의 M2 seed 점프(+36~43 bar)로만 발동한다. 시험 기대값에 반영한다.
  - 신장 목격: 잠김 출발 읽기 대비 단일 읽기 차 $\Delta s\ge$ **1.0 mm**(신장 A(ii)는 꺼짐이라 기록용)
  - 부호 바뀜, 명령 $\lvert u\rvert\le u_{hold}$, FAULT 정지
  - 0.3 mm 목격은 쓰지 않는다(기어감 0.15~0.53 mm, F6-7).
- **안전**
  - 미리보기로 낸 명령 변위는 하한 $x_{lb}$를 넘지 않는다.
  - 하한 보장이 깨지는 경우(κ_max < 1)에만 넘친 만큼 과이동한다. 이 경우는 강건 하한 세트 표에서 0건이다(64건 × 40추첨 × 체적 3값).
  - 펌프 포화 위험은 없다. $\sum A_hv_{max}$ = 57.19 L/min = 0.95 × 60.2 L/min이고, 다리별 상한이 $v_{max}$다(hydraulics 6절).
  - 행정 끝·들림 가드·FAULT 정지가 우선한다.
- **G2 벡터 램프와의 관계(개정 5, 구현 승인)**: G2(`_vector_ramp_increment`)는 LEVEL 시작에서 증분 제한이 비틀림을 지우지 않도록 공통비를 쓴다. 그런데 A(ii)·A(i)가 올린 다리의 요구가 깎이면, 가장 작은 비가 모든 다리에 적용되어 다른 다리를 늦춘다(hydraulics 지적).
  - 구현 `_vector_ramp_outside_lock_start`를 승인한다. 공통비 계산에서는 A가 올린 다리를 "규칙 적용 전 명령"으로 보고, 그 다리에는 다리별 증분 제한만 건다.
  - 조건
    - (가) A가 올린 다리도 다리별 증분 제한(대칭 0.25 $v_{max}$/주기)은 그대로 받는다.
    - (나) A가 꺼진 줄은 G2 결과가 606f8713과 비트 동일하다(P6-0에 포함).
    - (다) A가 올린 다리의 출력은 "규칙 적용 전 명령에 G2 공통비를 곱한 값" 이상 크기여야 한다(A는 바닥이므로 줄이지 않음).
    - (라) G2가 작동한 주기에 A가 올린 다리가 있었는지 기록한다(`lsb_g2_split` 수).
  - 이유: A의 목적은 잠긴 다리의 출발 지연을 줄이는 것이다. G2가 그 요구를 다른 다리에 퍼뜨리면 비틀림 보존이 아니라 전체 지연이 된다. 비틀림 분해는 A가 올리지 않은 다리끼리 지킨다.
- **probe 변형(7번째 팔)**: "하한 뒤 1증분 속도 바닥 유지" — $X\ge x_{lb}$ 뒤 로드 목격까지(최대 1 s, 가정) 명령 크기를 1증분(5.23 mm/s) 이상으로 둔다. hydraulics 개루프 모의에서 단축 −0.20 s, 열린 뒤 초과 이동 최대 0 / 0.15 / 0.33 mm(체적 공칭 / 0.5 / 1.5)다.
- 기록: 다리별 충전 바닥 적용 수, 매 주기 $x_{lb}$·void, 끝 사유, 열림까지 주기.
