## 0. 요약
- **추천: (나) P8-5를 판정 불가로 둔 채 5단계로 간다.** 결정 D-2 3·5를 그대로 따릅니다.
  - 5단계는 V0만 돌리므로 PSW와 무관합니다(규칙 210행).
  - census·G′는 PSW를 포함한 VBN 구성 전체를 결과로 판정합니다. 그래서 P8-5가 비어도 결과 판정은 그대로 성립합니다. 잃는 것은 귀속 주장 하나입니다("PSW가 명령에 닿는 길이 하나뿐"을 관문으로 확인했다는 주장).
- **(가) 쌍 보충**은 규칙상 가능합니다. 조건은 셋입니다: 정오로 하고, 결과를 본 뒤의 결정으로 공개하고, D-2 3("키 추가 재실행은 하지 않는다")을 사용자가 뒤집는 것.

- 새로 드러난 설계 결함이 하나 있습니다(5.1). 관측 비율 14/23으로 거꾸로 계산하면, 23쌍에서 문턱 15를 넘을 확률은 점추정 약 42 %입니다. 봉인 전에 예상 쌍 수를 같은 모델 경로로 계산하지 않은 공백이고, 판정 후 감사 M-2가 지적한 것과 같습니다.

## 4. 처리안

### (가) 정오로 판정 쌍을 보충하는 실행
- **규칙상 가능 여부**
  - 규칙은 보충을 막지도, 정하지도 않습니다. 정오로 하면 가능합니다.
  - 단 D-2 3("키 추가 재실행은 하지 않는다")은 사용자 결정이므로, 사용자가 그 결정을 바꿔야 합니다.
  - 결과를 본 뒤의 결정이므로 공개 항목이 필요합니다. 공개할 것: 14/23을 본 뒤 정함, 9쌍 사유 분포를 본 뒤 정함.
- **쌍을 늘릴 수 있는 곳과 분리 조건**
  - 같은 23키를 다시 돌리면 결정적 하네스라 같은 결과가 나옵니다. 쌍이 늘지 않습니다.
  - P8-16의 판 5 r79 4키(27키 중 나머지): 이미 P8-16·P8-15에서 결과를 본 키입니다. 또 r79 경로에는 3.8 기록 키가 없었던 전례가 있습니다(P8-15 기록 실패 (1)). PSW 스케일 기록이 있는지는 jsonl을 열어야 알 수 있어 확인하지 않았습니다. 겹침·기록 둘 다 위험합니다.
  - **census 키(1043, 5.1)는 쓰면 안 됩니다.** a8 팔은 판 8 구성(VBN)과 같으므로, census 키로 돌리면 6단계 판정 대상 줄을 미리 만들고 보게 됩니다(본 집합 오염).
  - **held-out G′ 키(339)는 쓰면 안 됩니다.** 210행 "G′ VBN은 8단계 전에 돌지 않는다"에 직접 걸립니다.
  - 쓸 수 있는 풀: 위 셋(23 + 4, census 1043, G′ 339)과 서로소인 새 키. 키 파일로 서로소를 증명하고, 생성 규칙(원천 파일·seed)을 정오에 봉인해야 합니다.
    - 원천 후보: 판 5~7 저장 V0 격자 가운데 census·G′에 들지 않은 줄.
    - 이 서로소 판별에 쓸 원천 목록은 아직 만들지 않았습니다(분석 범위 밖).
  - 실행 경로: `ed8_probe.py`에 `--part file --jobs-file <json>`이 있습니다(ed8-impl `04_scripts/04_hydraulic/coupled/ed8_probe.py` 87·545·590행). C8을 바꾸지 않고 외부 jobs 파일로 a8·a8_psw_off 두 팔을 돌릴 수 있어 보입니다. [추정] 판 8 팔과 `file` 파트가 함께 동작하는지는 python-expert 확인이 필요합니다.
  - 판정 도구: `jp3_ed8_gate_judge.py`(ed8-judge4) p85는 키 집합을 고정하지 않고 (plant, row)로 짝을 짓습니다. `MIN_SAME_PAIRS["p85"] = 15`(104행), 판 짝 `("a8","a8_psw_off")`(101행).
    - 새 행 파일 하나를 `--rows`·`--step-done`으로 판정하는 꼴이면 도구를 바꾸지 않아도 될 수 있습니다([추정]).
    - 23 + 새 키를 합쳐 판정하려면 행 파일을 합치거나 도구를 바꿔야 합니다. 도구를 바꾸면 새 판정 커밋이 생기고, 4단계 관문 전부를 다시 판정해야 합니다(판정서 3절 "T8⁗를 다시 바꾸면 4단계 관문 전부를 새 판정 커밋으로 다시 판정").
- **판정 정의 선택지(정오에서 하나를 봉인)**
  - (가-1) 새 키만 따로 판정하고 문턱 15를 그대로 씁니다. 23키 결과(판정 불가)는 그대로 둡니다.
    - 장점: 본 집합과 분리됩니다.
    - 필요한 새 키 수(아래 5.1): 점추정 p ≈ 0.61이면 32키, Jeffreys 하한 0.41이면 50키에서 "15 이상"일 확률이 95 %에 닿습니다.
  - (가-2) 23 + 새 키를 합쳐 15를 봅니다.
    - 1쌍만 더 같으면 넘으므로 4~6키로 충분합니다.
    - 그러나 "넘을 때까지 더한다"는 꼴(선택적 중단)으로 읽히고, 이미 본 14쌍을 판정에 다시 씁니다. **권하지 않습니다.**
  - (가-3) 문턱을 14로 낮춥니다. 관측값에 맞춘 사후 변경이고 D-2 3과 정면으로 어긋납니다. **권하지 않습니다.**
    - 굳이 넣는다면 위험을 적어야 합니다: 문턱의 뜻(사전 등록 최소 적용 범위)이 없어지고, 같은 꼴(P8-8 6/5, P8-15 21/20)의 다른 관문과 일관성이 깨집니다.

## 5. stats-design-expert에게 물을 통계 질문

### 5.1 계산 근거 (control 계획용 수치, 판정에 쓰지 않음)
- 실행: dynamics-dev scipy, 입력은 판정서 건수 14/23뿐입니다.
- 같은 쌍 비율 $\hat p$ = 14/23 = 0.609, Jeffreys 95 % 구간 (0.406, 0.786).
- 23쌍에서 $n_{same} \ge 15$일 확률: p = 0.406이면 0.015, 0.609이면 0.422, 0.786이면 0.959.
- 새 서로소 키만으로 15 이상일 확률이 0.95에 닿는 키 수: p = 0.609이면 32, p = 0.406이면 50.
- 합치는 경우 1쌍 이상 더 같을 확률 0.95: 4키(0.609), 6키(0.406). 선택적 중단 위험 때문에 권하지 않습니다.
- 기호
  - $n_{pair}$: 두 팔이 다 있는 (plant, row) 짝 수
  - $n_{same}$: 라운드 수가 같고 라운드별 스케일이 비트 단위로 같은 짝 수
  - $p$: 짝당 "같음" 확률
- 가정: 짝이 서로 독립이고, 새 키에서도 p가 같습니다. 새 키의 플랜트·사례 구성이 23키와 다르면 p가 달라집니다.
