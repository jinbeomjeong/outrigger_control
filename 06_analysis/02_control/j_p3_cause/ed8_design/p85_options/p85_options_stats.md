## 지적과 답

### 질문 1. 문턱 15의 뜻
**답: control의 읽기가 맞습니다. 문턱 15는 오류율 통제가 아니라 최소 적용 범위입니다.**

근거
- 하네스는 결정적이고(F8-10) 판정 쌍마다 차이 0을 요구합니다. 그래서 거짓 실패는 0입니다.
- 오류는 "누출을 놓침" 하나이고, 그 확률은 판정 쌍 n에 대해 $(1-q_{eff})^n$입니다. 여기서 $q_{eff}=q(1-\mu)$입니다.
- 문턱 n은 "0/n이면 $q_{eff}$ ≤ 1 − 0.05^{1/n}"이라는 보장에 대응합니다(Clopper-Pearson 단측 상한과 일치, 스크립트에서 단언).
- 14 대 15의 차이는 상한 0.193 대 0.181로 1.2 %p입니다. 통계적으로는 의미가 없습니다. 그래도 결과를 본 뒤 문턱을 바꾸면 안 됩니다(원칙 4, D-2 3). (가-3)과 (라-3)을 권하지 않는다는 control 판단에 동의합니다.

적절한 기준(판 9 이후 설계용)
1. **기회 단위로 센다.**
   - 같은 쌍 가운데 PSW 코드가 실제로 다른 값을 낸 쌍만 셉니다. 예: 스케일 mid가 지금 mid와 다른 다리가 있는 라운드, $K1_{sc}$가 계산된 라운드.
   - 새 경로가 돌지 않은 쌍은 정보가 없는데도 상한을 좁게 보이게 합니다(같은 꼴: 메모리 함정 10).
2. **플랜트별 최소 수와 분기별 덮기를 둔다.**
   - 플랜트 3개 각각에 최소 수를 둡니다.
   - 분기별로도 덮습니다: 클램프 1.5에 걸린 라운드, 스케일 다리 3개 미만으로 이전 스케일을 쓴 라운드, 클램프 밖인데 값이 같은 라운드(`c2.py` 7721~7734·9892~9925의 분기, 규칙 365).
3. **목표 상한 $q_0$를 먼저 적고 n을 정한다.**
   - $q_0$ = 0.2이면 n ≥ 14, 0.15이면 n ≥ 19입니다.
   - 플랜트 3개가 사례를 공유하면 $n_{eff}=n/(1+2\rho)$로 보정합니다.
4. **판정 가능 확률을 같은 모델 경로로 계산해 적는다**(질문 2).

추가 지적(원칙 3·5): 가림
- "같음"은 켬 팔의 출력(라운드별 스케일의 비트 일치)으로 정하는 처리 후 분류입니다.
- PSW가 스케일 아닌 길로 명령을 바꾸면 다음 판독이 달라지고, 클램프에 걸리지 않은 라운드에서는 뒤 라운드 스케일이 비트 단위로 달라집니다. 그러면 그 쌍은 "판정 안 함"으로 빠집니다.
- 그래서 P8-5는 스케일로 되먹임되지 않는 누출만 잡습니다. 예: 마지막 스케일 갱신 뒤에 작동하는 누출, 클램프 라운드에서의 누출.
- 판정되지 않은 9쌍이 "설계대로 바뀐 쌍"인지 "가려진 누출"인지를 이 관문으로는 가를 수 없습니다.
- 시뮬레이션: q = 0.1에서 봉인 규칙의 거짓 통과는 μ = 0이면 0.076, μ = 0.9이면 0.20입니다.
- μ의 실제 값은 control 해석 질문으로 넘깁니다. [추정] 클램프에 걸리지 않은 라운드에서는 1에 가깝고, 클램프 라운드에서는 0에 가깝습니다.

### 질문 3. (가) 보충

**(가-1)과 (가-2)의 성질 비교**
- 두 안 모두 "실패는 최종, 판정 쌍마다 차이 0"인 단조 규칙입니다. 쌍을 더하면 검출 기회만 늘어납니다.
- 통과했을 때의 보장은 같습니다: 판정 쌍 ≥ 15 → 상한 0.181. 단 (가-2)는 새 키와 23키가 교환 가능할 때만 그렇습니다.
- **선택적 중단 해석**
  - 고전적 의미의 α 부풀림은 "유의할 때까지 다시 보고, 유의하면 멈춤"에서 생깁니다. 여기서 멈춤 조건은 결정 통계(명령 차이)가 아니라 기회 수(같은 쌍 수)입니다. 실패 뒤 다시 하는 경로도 없습니다.
  - 그래서 m을 미리 고정하고 m개를 모두 판정하면, (가-2)도 통과 때 보장이 명목값 $(1-q)^{15}$보다 나빠지지 않습니다.
  - 가림이 있으면 누출이 같은 쌍 수를 줄여 표본이 길어지는데, 이는 보수적인 방향입니다.
- **설계 시작부터 본 무조건 비교**(q = 0.1)
  - 봉인 규칙은 판정 불가로 끝났을 경우를 "통과"로 바꾸므로, 두 안 모두 거짓 통과를 조금 늘립니다.
  - μ = 0: 봉인 0.076 → (가-1) 0.095, (가-2) 0.143
  - μ = 0.9: 0.20 → 0.68, 0.49
- **(가-2)를 권하지 않는 진짜 이유**는 α가 아니라 정보량입니다.
  - 새로 보태는 정보가 같은 쌍 1~2개뿐입니다. 조건부 거짓 통과는 q = 0.1에서 0.76이고, 한 키씩 더하는 판은 0.90입니다.
  - m = 4라는 숫자는 "14를 봤다"를 전제로만 나옵니다. 통과의 근거는 대부분 이미 본 14쌍입니다.
  - P8-14에서 고른 23키와 새 키의 교환 가능성은 확인되지 않았습니다.

**m 사전 등록 기준**
- 검정력 대신 "판정 가능 확률 ≥ 0.95"(문턱 도달 보장)를 쓰는 것이 맞습니다. 결정적 시험이라 검정력에 해당하는 양은 위의 q 상한이고, m은 판정 불가 위험을 정하기 때문입니다.
- p를 점값으로 넣지 말고 예측 분포(베타-이항)로 계산합니다.

| p의 근거 | (가-1) 새 키 15쌍 도달에 필요한 m | (가-2) 1쌍 도달에 필요한 m |
|---|---|---|
| 점추정 0.609 | 32 | 4 |
| Jeffreys 하한 0.406 | 50 | 6 |
| 예측 분포 Beta(14.5, 9.5) | **38** | 4 |
| 할인 사전(a₀ 0.5) Beta(7.5, 5.0) | 43 | 4 |
| 결과 없이, 봉인 전 재생 방향 A Beta(10.5, 1.5) | 23 | 2 |
| 결과 없이, 무정보 Beta(1, 1) | 299 | 19 |
| 사례 × 플랜트 3, 점추정, ρ 0 / 0.3 / 0.6 | 33 / 36 / 36 키 | – |
| 사례 × 플랜트 3, 하한 0.406, ρ 0 / 0.3 / 0.6 | 51 / 54 / 60 키 | – |

- 권고(만약 (가-1)을 고른다면)
  - 층별로 미리 고정한 m을 씁니다. 총 38~50키, 플랜트 3 × F_s 계열 층.
  - m개를 모두 판정하고, 도중에 멈추지 않습니다.
  - 층별 같은 쌍 수를 기록합니다.
- 결과 정보 없이 쓸 수 있는 사전 분포는 쓸모가 없거나(무정보, 299키) 이미 틀린 것으로 드러났습니다(재생, 23키). 그래서 실용적인 m은 어떻게 정하든 결과를 씁니다.

**p를 14/23에서 가져오는 것이 결과 사용인가**
- **예, 결과 사용입니다.** 관문 출력($n_{same}$)을 본 뒤의 정보이므로 공개해야 합니다.
- 다만 성격은 결정 통계(명령 차이)가 아니라 장애 모수(기회 비율)입니다. 그래서 장애 모수 기반 표본 수 재추정(blinded sample-size re-estimation)과 같은 범주입니다. m을 고정하고 모두 판정하면 누출 판정을 편향시키지 않습니다.
- 단서: 가림이 있으면 $n_{same}$은 순수한 장애 모수가 아닙니다(누출이 $n_{same}$을 줄임). 그래도 낮은 $n_{same}$은 m을 키우는 보수적인 방향입니다.
- 공개 문안: "새 키 수 m은 4단계 P8-5의 같은 쌍 비율 14/23(결과를 본 뒤의 정보)에서 Jeffreys 사후 예측 분포 Beta(14.5, 9.5)로 '새 키만으로 15쌍에 닿을 확률 ≥ 0.95'가 되게 정했다. 이 비율은 기회의 크기(장애 모수)이며, 판정 통계(명령 차이)는 m을 정하는 데 쓰지 않았다. 다만 판정한 14쌍의 차이가 0이었다는 사실은 보충을 결정하기 전에 알고 있었다."
