## 6. 단위, 중복 병합, 층

### 6.1 단위
- 단위 = (설정, 행, 위상). 단위 판정 = 기준 통과 ∧ 처리 실패. 기준 실패 단위는 세지 않는다(기록).

### 6.2 중복 병합(census 전체, 한 번에)
- (가) 해시 병합: 처리 줄 `commands_sha256`이 같은 단위들은 단계·설정을 가리지 않고 한 병합 단위다(판 7 저장 줄 39쌍: 같은 조건의 다른 인코딩, 설정 별칭).
- (나) eps 병합: 같은 (설정, 행)의 eps 0과 0.001 단위는 해시와 관계없이 한 병합 단위다.
- (다) 소속 단계는 C-J → C-S → C-D → C-G 순서의 첫 단계. 한 번만 센다.
- (라) 기회 = 구성원 하나라도 기준 통과. 실패 = 구성원 하나라도 (기준 통과 ∧ 처리 실패). 구성원 판정이 다르면 실패 쪽.
- (마) 병합 단위의 층 = 구성원 V0 중 하나라도 E면 E.
- (바) 해시가 없는 오류 줄은 병합하지 않고 그 단계 판정 불가.
- J-P3·FAULT는 병합하지 않고 줄 단위로 판정한다.

### 6.3 층(조기 인계 층 E, 나머지 층 N)
- **층 E**(사용자 결정 4): 사건 행 단위 가운데 V0 짝 줄이 빠른 사건(`event_output.fast` 참; 저장 격자 run은 같은 정의의 run 최상위 필드, Y8-6)이고, V0 짝의 재접근 시작 목록에 **사건 다리의 대각 다리** 시작이 있으며, 그 가운데 $0\le t$이고 `round(t, 3)` ≤ 0.450 s인 시작이 하나라도 있는 단위.
  - $t$는 사건 시작 기준 상대 시각이다. 저장값은 0.01 s로 반올림돼 있다. 사건 전(음수) 시작은 보지 않는다.
  - 사건 다리 = job twin의 `leg`, 없으면 사례 기본값(R12·R14 RR, R15·R16 FL; `verdict_cases.py` 153~171).
- **층 N**: 그 밖의 모든 단위. **정상 행(`SteadyTwin`)은 정의상 N**이고 키 요구가 없다. 빠른 사건이 아닌 사건 행(FS24 등)도 N이다.
- 키 경로: main.jsonl 줄 `event_output.reapproach_starts`, 저장 격자 run `runs[int(run_id)].reapproach_starts`.
- 결측: 사건 행의 V0 짝에 키가 없으면 그 단계 `setting_defect`(입력 결함). 빈 목록은 N. 0c에서 봉인 전에 키 존재를 확인한다.
- 층은 처리 전 공변량(V0)으로만 정한다.
- 공개: 층 정의는 판 6·7 결과를 본 뒤 정했다(O8-4). FS24 단위를 N으로 둔 것은 사용자 결정이다(판 6 FS24 o0.05 `end_att` 2건이 다른 정의에서는 E 실패였음, stats 문항 4).

### 7.2 추출과 seed
- 정렬: (원천 표지, 슬롯 키) 문자열 오름차순.
- 난수: `numpy.random.default_rng(<S8R_HO_SEED>)`. 슬롯마다 조건 $o$를 뽑고, 이어서 A/A 짝 후보 순서(같은 슬롯 후보의 나머지를 seed 순서로 섞은 목록)를 정한다.

### 7.3 별칭 확인과 층 배정
- 1차(5단계, V0만): V0 단위 해시가 저장 V0의 같은 군집 본 위상 run 해시와 같으면 별칭, 빼고 기록. 그 뒤 층 E/N 배정(6.3).
- 2차(8단계 뒤): **해시 같음만으로, 판정 계산 전에** 정한다. VBN 단위 해시가 census 처리 줄 해시와 같으면 본 단위 별칭, 수에서 빼고 기록. 그 뒤 G′ 안 병합(6.2 (가)(라)(마)).
- 판정 가능성($n_{min}$)은 **5단계에서만** 본다: 1차 별칭 뒤 V0 통과 기회가 N 200 이상, E 16 이상. 미달이면 그 층은 판정 불가(멈추고 묻는다). 2차 뒤 수가 줄어도 판정 가능성은 다시 보지 않는다.
- 한 층의 기회가 0이면 해당 없음, 판정 불가는 G′ 전체 기회가 0일 때.

### 7.4 V0 A/A 바닥
- 5단계에서 V0($o''$)를 돌려 V0($o''$)를 처리, V0($o$)를 기준으로 C-J (i) 항목 전부로 판정한다.
- **A/A 짝은 V0($o''$)의 층이 V0($o$)와 같을 때만 기회로 센다.** 다르면 같은 슬롯 후보의 seed 순서에서 다음 $o''$를 쓴다(최대 3회). 엇갈린 짝은 기록한다. 두 해시가 같은 쌍은 A/A 기회에서 빼고 기록.
- $x_{AA}$·$n_{AA}$(층별)는 **5단계 값으로 동결**하고 S8-C에 봉인한다. 2차 별칭으로 빠진 단위의 A/A 쌍도 그대로 둔다.
- 멈춤: N층 단측 95 % Clopper–Pearson 상한 > 0.025면 멈추고 묻는다. E층 A/A 실패가 2 이상이면 멈추고 묻는다.
- 공개: A/A는 처리 팔 귀무 바닥의 하한이다(섭동이 작음). 참 바닥이 A/A의 3배면 권고 N 규칙 거짓 실패는 $p_0^{AA}$ 0.002에서 3.2~11.4 %, 0.005에서 17~30 %다(stats 3·5절).

### 7.5 허용 수 k
- N층: $k_N$ = P(BetaBin($n_N$, $x_{AA}$ + 0.5, $n_{AA}$ − $x_{AA}$ + 0.5) > $k_N$) ≤ 0.025인 최소 정수(Jeffreys 사후 예측). 2차 뒤에는 $n_N$만 바꿔 다시 계산한다.
- E층: $k_E$ = 1(고정).
- 산출물 `ho_k_selection.json`(sha256 `<S8C_HO_K_SELECTION_SHA256>`): 층별 $n$, $x_{AA}$, $n_{AA}$, CP95, $k$, MDE80.
- 공개 MDE80(해석식, 독립 단위): N $n$ 200에서 2.7 / 4.5 / 5.6 %($x_{AA}$ 0/1/2), 300에서 1.8 / 3.0 / 3.8 %. E($k$ 1) $n$ 16에서 17.6 %, 28에서 10.3 %. E는 통계적 확인이 아니라 기전 시험이다.
- 예측 문장(기록): 층별 귀무 기대 실패 수(`<S8C_HO_PREDICTION>`).
