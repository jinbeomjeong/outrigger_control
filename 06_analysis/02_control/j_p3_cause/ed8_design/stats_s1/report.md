## 설계안 또는 지적

### S-1a. 판 7 감도 군집 규칙은 "고정 표 실패 1 + 같은 행 미관측 위상의 결정적 계통 이동"을 반영했는가 — **반영하지 않았다**

깨진 가정은 다섯 곳입니다.

1. **위상 상관 ρ_e = 0.5 가정**(원칙 2·3)
   - 감도 모형은 "단위 실패 ⇔ c + √ρ_e·z_(설정,행) + √(1−ρ_e)·ε_위상 < 0, ρ_e 0.5"입니다(`stats_v7_summary.md`:186, `handback_stats_stopcond.md`:125).
   - 봉인 때 이미 더 높은 상관 근거가 있었습니다.
     - V0 실패의 오프셋 간 ICC 0.95(`stats_v7_summary.md`:147)
     - 436.8 H-1 D-1의 READY eps 간 ICC 0.996~0.9995(에이전트 메모리 기록 2026-11-22, 출처 `v5/resume_k1/h1_d1.jsonl` sha 412e5b36; 이번에 출처 파일을 다시 열지는 않았다)
   - 판 7 공개값(`cause_analysis.md`:77~84)에서 새 제어기 계열은 S7 e0와 e0.001이 같은 값입니다.
     - VBM 84.4/84.4, LSM3 84.4/84.4, VBMslow 102.9/102.9, VBMh15 99.6/99.6
     - 다른 것은 VBMh05(82.8/96.7) 하나뿐이고, V0는 76.4/77.1로 다르다
   - 즉 e0와 e0.001은 이 제어기에서 사실상 같은 궤적, 곧 별칭(alias)입니다.
   - 이 규칙의 무조건 거짓 실패는 ρ에 강하게 의존합니다(c 2.8σ: ρ 0.5 3.1 % → 0.95 12.6 % → 1.0 15.3 %).
     - ρ가 1에 가까우면 2위상 행에서 한 번의 여유 넘김이 곧 "실패 위상 2개"가 됩니다.
     - 그러면 "≥ 2위상 = 재현된 실패, 1위상 = 산포"라는 규칙의 구분이 사라지고, 단독 허용 k = 4도 그런 행에서는 작동하지 않습니다.
2. **"위상 = 교환 가능한 반복"이라는 가정 자체**(원칙 3)
   - 이 하네스에서 위상 손잡이(eps, 오프셋)는 결정적인 조건 변수입니다. 두 방향으로 어긋납니다.
     - 별칭: S7 e0 ≡ e0.001
     - 위상 고정 기전 [판 7 결과 반영]: G1 실패 3줄이 **모두 o0.0**이다. G1의 o0.0 줄은 48/171이고, 실패가 무작위라면 셋 다 o0.0일 초기하 확률은 2.2 %다.

   - 둘 다 단일 ρ를 쓰는 여유 모형으로는 표현되지 않습니다.
3. **귀무 모형이 다룬 사건과 실제 사건이 다르다**(원칙 5)
   - σ 여유 모형의 귀무는 "변경이 무해하고, 무작위 산포로 문턱을 넘는다"입니다.
   - 실제 S7 실패는 (i-b)가 만든 계통 이동입니다(기저 +5.5 s + 재레벨 긴 갈래 +14~31 s, `cause_analysis.md`:121~135). 이것은 대립가설 쪽의 **올바른 검출**이고 거짓 실패가 아닙니다.
   - 봉인 문면의 "거짓 실패 3.3 %"는 이 경우와 관계가 없는 숫자였습니다. 빠진 것은 다음 4번의 조건부 확률입니다.
4. **봉인 관문이 무조건 확률만 봤다**(원칙 5, 판 6 Q6-15와 같은 꼴)
   - 봉인 조건 "고정 표만으로 규칙이 이미 실패이면 봉인하지 않는다"(명세 692행)는 고정 표 하나만 셉니다.
   - 고정 표에 VBMslow S7 e0.001 실패가 나온 뒤 중요한 양은 P(단계 실패 | 고정 표)입니다. 그런데 이것은 계산·공개되지 않았습니다.
     - 설계 자기 모형(ρ 0.5, c 2.8σ)으로도 20 %입니다. 같은 행의 미관측 3위상 중 하나가 실패할 확률 18.8 %가 대부분을 차지합니다.
     - 근거 상관(ρ ≥ 0.95)에서는 83~100 %입니다.
   - 하네스가 결정적이므로, 이 단계의 결과는 봉인 때 사실상 정해져 있었습니다.
5. **바닥 상한의 표본 수**(원칙 3)
   - c ≥ 2.8σ는 "판 6 788단위에 기전 아닌 실패 0"에서 나왔습니다(`stats_v7_summary.md`:135, 상한 0.0024).

### S-1b. 전수 기록 probe를 봉인 전에 돌릴 때의 재설계

대안은 셋이고 권고는 그 조합입니다.

**대안 1. 봉인 전 전수 계산(census) → 실행은 재현 확인만**
- **거짓 채택률·검출의 의미**
  - 정의되지 않습니다. 판정은 (코드, 키 집합)의 결정적 함수이고 봉인 때 0 또는 1로 정해집니다.
  - 통계적 의미는 키 집합 밖의 조건 모집단에 대해서만 있습니다. 그런데 이 키 집합은 설계자가 판 5~7에 걸쳐 반복해서 쓰고 결과를 본 집합이라 **표본 내**입니다.
  - 그래서 census 통과의 뜻은 "회귀 시험 통과"이고 확인 증거가 아닙니다.
  - 판 8 probe에서 팔을 고르면(a2 − (i-b) 등) 최대값 선택 편향도 더해집니다. 공개 대상입니다.
- **표본 수**
  - 줄은 j9_main 388 + 감도 460 + D 24 = 872줄입니다(G1 171을 넣으면 1043).
  - 다만 별칭을 합친 고유 단위 수는 그보다 적습니다. 실행 전에 `commands_sha256`이 같은 단위를 한 단위로 합치는 규칙을 둬야 합니다. 판 7 J7 14단위도 독립 사건 2~3개가 복제된 것이었습니다(`cause_analysis.md`:59~61).
- **오염 처리**
  - 이 집합 전체가 "결과 본 뒤"입니다. 그래서 규칙을 2단계로 봉인하기를 권합니다.
    - **S8-R(규칙 봉인)**: census probe 전에 봉인한다. 판정 문면, 문턱·허용 수, 단위 정의(중복 병합, o0.0 층), 키 목록, held-out 추출 규칙과 seed가 들어간다.
    - census probe를 돌리고 고정 표를 만든다.
    - **S8-C(구성 봉인)**: 제어기 커밋과 고정 표 sha를 봉인한다.
  - census에서 어느 단계든 실패하면 봉인하지 않고 다음 판으로 넘깁니다. 이때 규칙은 바꾸지 않습니다. 결과를 본 뒤 예외를 만드는 경로(Q6-15·판 7)가 이것으로 막힙니다.
  - 봉인 뒤에는 양방향 재현만 봅니다. 불일치는 `setting_defect`입니다(판 7 6.1 그대로).

**대안 2. 보지 않은 확인 집합을 남김(새 키·seed)**
- **거짓 채택률·검출의 의미**
  - 거짓 실패 = P(held-out 실패 수 > k | 변경이 V0 대비 무해, 줄당 바닥 p0)
  - 검출 = P(> k | 결함 비율 π)
  - 이 판에서 통계적 주장이 성립하는 유일한 단계입니다. 판 7의 12b(P-pred, 미사용 seed 50~53)는 이미 이런 꼴입니다. 유지를 권합니다.
- **표본 수**(독립 군집 1줄씩, 이항 정확, 거짓 실패 ≤ 5 %가 되는 최소 k)

| 140 | k 1 / 2.0 % | k 2 / 2.7 % | k 3 / 3.3 % | k 4 / 3.7 % | k 5 / 3.8 % |

- MDE80은 q = 1(결함이 있는 줄은 늘 실패)일 때 검출력 80 %가 되는 결함 비율입니다.
- 바닥에는 V0 여유 몫 0.24/168줄을 더했습니다.
- **원천**
