### 질문 1: MDE80
- **재현**(T8 함수 = scipy 독립 구현 = 공개 값):

| 경우 | k | T8 MDE80 | 공개 |
|---|---|---|---|
| N n 200, $x_{AA}$ 0/1/2 ($n_{AA}$ = 200) | 3 / 6 / 8 | 2.740 / 4.503 / 5.642 % | 2.7 / 4.5 / 5.6 % |
| N n 300, $x_{AA}$ 0/1/2 ($n_{AA}$ = 300) | 3 / 6 / 8 | 1.831 / 3.010 / 3.772 % | 1.8 / 3.0 / 3.8 % |
| E n 16 / 28 (k 1) | 1 | 17.583 / 10.320 % | 17.6 / 10.3 % |

- 따라서 공개 수치는 "Jeffreys k를 거친 값"이고, **MDE 식 자체는 T8 구현과 같습니다**. 차이는 k에 넣는 $n_{AA}$뿐입니다. 공개 표는 계획값 $n_{AA}$ = $n_N$을 썼고, T8 `ho_k_selection`은 실제 $n_{AA}$를 씁니다. 명세 7.5는 레코드의 MDE80 필드를 실제 k로 요구하는 것으로 읽히므로 T8이 맞습니다. 근거: 명세 314~315행, f4_checks.py 43~44행, T8 `jp3_ed8_rules.py` 301~314·418~436행.
- **$n_{AA}$ < $n_N$일 때 공개 표와 달라지는 정도**(`q1_naa_dependence`):
  - $n_N$ 200: $n_{AA}$ 180이면 $x_{AA}$ 0에서 k 4, MDE80 3.34 %. $x_{AA}$ ≥ 1은 멈춤.
  - $n_N$ 300: $n_{AA}$ 270이면 $x_{AA}$ 0/1/2에서 k 4/7/9, MDE80 2.23/3.39/4.15 %.
- **권고 Q1-a**(python-expert): docstring의 "the reading of the spec 7.5 MDE80 used here"를 정의 출처로 고칩니다. 예: "spec 7.5 MDE80: least p with P(Bin(n, p) > k) ≥ 0.8, independent units, k the frozen layer k; published table used n_AA = n_N (f4_checks.py:43-44)". 아울러 `ho_k_selection` 레코드에 `mde80_definition` 문자열을 넣습니다.
- **권고 Q1-b**(python-expert): 8단계 `heldout_judgement`(443~491행)는 k를 다시 계산하지만 MDE80은 내지 않습니다. 최종 (n, k)의 `mde80`도 층별로 기록하게 합니다. 7.5는 k_frozen과 최종 k를 둘 다 적게 하므로 MDE도 짝으로 냅니다.
- **권고 Q1-c**(공개 주석, 원칙 5):
  - $n_{AA}$ ≤ $n_N$이고, CP95 멈춤에 필요한 $n_{AA}$는 $x_{AA}$ 0/1/2/3에서 119/188/250/308입니다.
  - 그래서 **"n 200, $x_{AA}$ 2 → 5.6 %" 칸은 항상 멈춤**입니다(CP95(2/200) = 0.031 > 0.025).
  - n 200, $x_{AA}$ 1은 $n_{AA}$ ≥ 188(짝 비율 94 % 이상)일 때만, n 300, $x_{AA}$ 2는 $n_{AA}$ ≥ 250일 때만 도달합니다.
  - 판정서에 "공개 표의 일부 칸은 멈춤 규칙 때문에 동결될 수 없음"을 주석으로 달 것을 권합니다. 규칙은 바꾸지 않습니다.

### 질문 2: A/A 같은 층 대조
- **2a(합친 뒤에도 원래 층)**: 명세와 맞습니다.
  - 근거: 7.3-2 "(A/A 기회·실패도 합친다)", 7.4 첫 문장, 6.3 "층은 처리 전 공변량으로만 정한다".
  - 통계: G′ 처리 단위는 VBN($o$) 대 V0($o$)로 같은 $o$를 비교하므로 층이 엇갈리지 않습니다. A/A 바닥도 같은 층 짝이어야 같은 잡음을 잽니다.
  - 다른 해석과의 차이: 엇갈림은 원래 E 슬롯(RE1bF 군집)에서만 생기고, 합침 조건이 $n_E$ < 16이라 최대 15쌍입니다.
  - 그 한도에서 k 변화는 0 또는 −1입니다. 멈춤이 뒤집히는 경우는 경계 칸뿐입니다($n_N$ 200·$n_{AA}$ 185·$x_{AA}$ 1, $n_N$ 260·$n_{AA}$ 245·$x_{AA}$ 2; `q2_merged_reading_bound`).
- **2b(같은 해시 → 기회 제외, 넘어가지 않음)**: 문면과 맞습니다.
  - 통계 영향은 h(같은 층 첫 짝이 같은 해시인 슬롯 비율)에 달려 있습니다. h는 [추정]이고, 결과가 없어 관측값도 없습니다.

| h | T8 $n_{AA}$ | 넘어감, 별칭이 체계적 | 넘어감, 별칭이 우연(최대) |

| 2 % | 294 | 294 | 300 |
| 5 % | 285 | 285 | 300 |

  - h가 클 가능성은 낮다고 봅니다. 위상이 체계적으로 무효인 슬롯은 V0($o$) 해시가 저장 본 위상 해시와 같아져 1차 별칭으로 먼저 빠집니다.
  - 같은 해시 쌍을 빼는 방향은 바닥 추정을 위상에 민감한 슬롯 쪽으로 올립니다. 그러면 k가 커지거나 같아지고, 거짓 실패는 늘지 않습니다.
- **권고 Q2-c**(python-expert, T8 완성 전 반영 권장, 원칙 3·5):
  - `aa_pair_of`(337~358행)는 받은 후보 목록만 봅니다. 그래서 러너가 aa2·aa3을 돌리지 않아 목록이 짧으면 `none_in_layer`(기회 없음)로 **조용히** 끝납니다.
  - 고칠 것: 필요한 시도 수 = min(3, len(aa_order))보다 적게 제공됐고 제공된 후보가 모두 엇갈렸으면 `RuleInputError`(→ setting_defect)로 둡니다.
  - 후보 층은 러너가 넘긴 값을 믿지 말고, 판정 도구가 V0($o''$) 줄의 `reapproach_starts`로 6.3 함수를 다시 적용해 정합니다. 그 결과가 러너의 aa2·aa3 실행 결정과 같은지도 대조합니다.
  - 같은 해시 뒤에 러너가 후보를 더 돌렸다면 무시하고 기록만 합니다.
- **권고 Q2-d**(기록): 같은 해시 슬롯 수, 그 슬롯에 남은 같은 층 후보가 있었는지(키 순서만), 엇갈린 짝 수를 `ho_k_selection`에 층별 건수로 둡니다. 판정서가 $n_{AA}$ 손실을 공개할 수 있게 하려는 것입니다. T8은 이미 슬롯별 `state`·`crossed`를 남기니 건수 요약만 더하면 됩니다.

## 시뮬레이션
- 시뮬레이션은 없습니다. 모두 해석식(scipy `betabinom`·`binom`·`beta.ppf`, $x_{AA}$ ~ Bin($n_{AA}$, $p_0$)에 대한 정확 합)이라 몬테카를로 표준오차도 없습니다.
- 모형:
  - 독립 단위
  - G′ 처리 실패 ~ Bin($n_N$, p)
  - A/A 실패 ~ Bin($n_{AA}$, $p_0$)
  - 멈춤: CP95 > 0.025
  - k: Jeffreys 예측 α 0.025
- 모수: $n_N$ 300(stats_final_review.md 34행의 "$n_{AA,N}$ 약 300"), $p_0$ 0.001/0.002/0.005, 3배 오지정, δ +2 %p는 명세 7.4 공개와 같은 틀입니다.
- 민감도: $n_{AA}$ 300 → 210, h 0 ~ 20 %, 합침 해석 +15쌍.
- 자체 확인:
  - 공개 8개 값 재현
  - T8 ↔ scipy 격자 1,539개(k 불일치 0, MDE 최대 차 4.6×10⁻¹⁵)
  - CP 상한 84개 불일치 0
