## 1. 요지

1. **L1(L1-R)·L2b·축소 하네스는 모두 같은 두 좌표를 준다**(2절 표). `Measurements.stroke_m` = 기름 좌표(L1 모터 위치 = `s_ref`, L2b `s_ref`, 하네스 `plant.sref`)이고, `stroke_corrected_m` = 피스톤이다(+ 같은 잡음 표본). D-3의 "L2b 입력이 `s_ref`"는 맞지만 L1과 다르지 않다. **엔진 간 불일치가 없으므로 지금까지의 판정(v5 기준, 436.8 봉인 규칙)은 내부적으로 일관되고 무효가 되지 않는다.** 436.8 규칙 39행도 "행정은 모터 행정 [m]"으로 같은 좌표를 쓴다. 좌표가 섞였던 곳은 H-6 E1 schema 2 하나이고, 이미 고쳤다(명세 432.4.5, 2026-10-31).
2. 제어기는 **두 좌표를 용도별로 나눠 쓴다**(R1 설계 결정, `c2.py` 29~35행). 행정 끝·예산·증분 규칙과 압력 진단은 기름 좌표를 쓰고, 크롤러 틈 ĉ·heave·LOC 틈·`lifted`·탐침 강성은 피스톤을 쓴다. CLAUDE.md 모델 규약("행정 센서 = 피스톤")은 `stroke_corrected_m`의 정의이고, `stroke_m`의 정의(기름 좌표)가 빠져 있다. **실기에는 `s_ref`를 재는 센서가 없다.** 그래서 문제의 본질은 "시뮬레이션 입력이 틀렸다"가 아니라 "실기에서 `stroke_m`을 무엇으로 채울지 정해지지 않았다"이다.
3. 피스톤으로 바꾸면 영향받는 곳은 세 가지다(3절).
   - (i) 끝·예산 문턱: 하중을 받은 다리에서 같은 숫자가 $F/k_h$만큼 덜 보수적이 된다.
   - (ii) 증분·"정지" 규칙: 비틀림 중 피스톤 증분은 `s_ref` 증분의 약 0.55~0.68배이고, 잠긴 다리도 하중이 바뀌면 피스톤이 움직인다. D1″ 계열의 "행정 정지 = 유량 없음" 의미가 깨진다.
   - (iii) 피스톤을 이미 쓰는 기능: 입력을 그대로 바꾸면 압축을 두 번 빼게 된다(크롤러 구역 식, `stroke_corrected_m` 없을 때의 대체 식).
4. **플랜트 쪽 발견**: 플랜트의 행정 한계는 기름 좌표 `s_ref` ≤ 0.70 m에 걸린다(`actuation.SpeedReference` 범위 = YAML `extension_range_m` [0, 0.7]). 실기 끝 정지는 피스톤에 걸린다. 하중 119 kN인 전방 다리에서는 `s_ref` = 700 mm일 때 피스톤이 693.2~693.5 mm다. 이 값은 FAULT 693.8·절단 694.7 mm보다 작다. 그러므로 제어기 입력만 피스톤으로 바꾸면 전방 다리의 `FAULT_STROKE_END`가 시뮬레이션에서 **걸리지 않고**, 플랜트 리미터에서 조용히 멈춘다. 피스톤 원좌표 안(②)은 플랜트 끝 정지 모델 변경이 먼저다.
5. 권고(4절): **(a) v5 뒤 별건 + (c2) 제어기 그대로, 실기 판독은 $\hat s_{ref}$ 재구성으로 정의.** v5·436.8의 제어기·플랜트 정체성과 해시는 그대로 둔다.

## 3. 항목 2: 피스톤 좌표로 바꿀 때 영향받는 요소와 권고

기호

| 기호 | 뜻 | 단위 |
|---|---|---|
| $s_{ref}$ | 헤드측 기름량 좌표(명령 유량 적분, 플랜트 리미터 대상) | m |
| $s_p$ | 피스톤 위치(실기 내장 센서가 읽는 양) | m |
| $k_h$ | 헤드측 기름 기둥 강성 $\beta A_p/(L_{0h}+s)$ | N/m |
| $\underline k_h$ | 실기 $k_h$의 하한(가장 무른 값) | N/m |
| $F$ | 실린더 순 힘(압축 +) | N |
| $S_{ii}$ | 다리 $i$ 하중 민감도(비틀림 증분, 기름 유연성 포함) | N/m |

관계식: $s_p = s_{ref} - F/k_h$(하중이 $F_s + mg$보다 클 때. 그보다 작으면 ±0.28 mm 안, D-3 3.2). 비틀림처럼 다른 다리가 받치는 증분에서는 $\Delta s_p/\Delta s_{ref} = 1 - S_{ii}/k_h$다.

수치(dynamics-dev 한 줄 계산, 4.4절 명령. $\beta$ 1 GPa, $s$ 0.68 m, $L_{0h}$ 0.05~0.08 m)

| 양 | 전방(ø130) | 후방(ø110) |
|---|---|---|
| $k_h$ [N/m] | 1.818~1.746×10⁷ | 1.302~1.250×10⁷ |
| $F/k_h$ [mm] | 6.54~6.81 @ 119 kN, 7.26~7.56 @ 132 kN | 3.46~3.60 @ 45 kN, 4.61~4.80 @ 60 kN(후방 하중은 **가정**) |
| `s_ref` = 700 mm에서 피스톤 [mm] | **693.2~693.5**(119 kN) | 695.2~696.5 |
| $1 - S_{ii}/k_h$(증분비, 추정) | 0.62~0.68 | 약 0.55 |

- $S_{ii}$ 5.828 / 6.985×10⁶ N/m(명세 65 개정 12)를 전방·후방에 어떻게 대응시키는지는 확인하지 않았다. 증분비는 범위로만 쓴다(**추정**).

**요소별 권고 요약**
- 끝 보호 문턱(FAULT·절단·P6·감속·꼬리 생략): 본래 피스톤·센서 끝을 지키는 양이다. 피스톤 원좌표(②)라면 **숫자는 유지**하고 여유 충분성은 H-3으로 판단한다. 단 플랜트 끝 정지 모델을 먼저 옮겨야 한다.
- 예산 문턱(가드 682.8, 642.8 두 곳, A5): 숫자 유지 가능. B1·SGS·DSb75 재검증이 필요하다.
- 증분·정지 규칙(꼬리, 재접지 이동, D1″·regain·D2/D3, 탐침 이동): **기름 좌표 의미를 유지**하는 편이 낫다. 그래서 ②를 고르더라도 내부에 $\hat s_{ref}$가 필요하다. 결국 ①이 ②보다 단순하다.
