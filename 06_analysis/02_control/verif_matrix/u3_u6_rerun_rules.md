## 5. 비교·읽기 규칙

### 5.1 U-3 키마다

| 양 | 정의 |
|---|---|
| 판정 | VB 판정(4절)이 이 묶음의 v5 결과다. V0 판정은 짝 비교용이다 |
| 이동 | (V0 → VB) 등급 이동: 통과·FLAG·안전 종료(`stroke_limited_stop`)·실패 네 등급의 4×4 표 |
| 차 | VB − V0: 첫 READY 시각 [s], 이탈 뒤 최소 실제 $F_{cyl}$ [kN], 실행 최대 행정 [mm], READY 틈(rut) [mm], 끝 자세 max(\|roll\|, \|pitch\|) [deg]. 값이 한쪽에만 있으면 `NA`로 센다 |
| 이전 판 | V0 − v4 저장(`final_SGS_R4`) 판정 이동과 같은 차. **기록만**(제어기 판 차이, 판정 아님) |

| 구분 | 조건 | 처리 |
|---|---|---|
| VB 고유 실패 | V0 통과·FLAG·안전 종료, VB 실패 | 묶음 판정 전에 **멈추고 묻는다**(행·사유를 적는다) |
| 기준선 실패 | V0·VB 모두 실패 | 기록하고 진행. 유압 연성과 무관한 제어기·모델 한계로 읽는다 |
| VB 개선 | V0 실패, VB 통과·FLAG·안전 종료 | 기록(원인을 한 줄로 적는다) |
| 안전 종료 이동 | 통과 ↔ 안전 종료 | 기록(행정 예산 차로 설명되는지 적는다) |

- 묶음 문구: "VB 통과 n / FLAG f / 안전 종료 s / 실패 k(그중 VB 고유 0)". VB 고유 실패가 1건이라도 있으면 사용자 결정 전에는 문구를 쓰지 않는다.

### 5.2 U-6

- 제어기마다 VB의 lite 통과 수, C2 안전 종료 수, 크롤러 하중 완료 수(`crawler_liftoff_fail`), 공식 판정 수를 v4 4.10과 같은 표로 낸다.
- v4 저장(V0 판 플랜트, 이전 판 C2)과의 차는 기록한다. 판정이 아니다.
- C2 ↔ ABL ↔ IND의 비교 문장은 같은 VB 플랜트의 값끼리만 쓴다.
