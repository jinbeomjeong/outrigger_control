## 3. IND와 기록 열 `IND_LAS` (사용자 결정 Q1 = I-2)

| 열 | 제어기 | 태그 | 실행 | 지위 |
|---|---|---|---|---|
| IND | `c8.py` 기준선 그대로(`HarnessIndustry(IndustryC8)`), LAS-b 없음 | `IND` | 봉인 3절 그대로(wide 226 + main 16 = 242) | **판정**. 봉인 4·5.2절 그대로 |
| IND_LAS | IND + 헤드 힘 기반 이륙 접근 감속 어댑터(명세 436.9.4, 관문 대응표는 거기) | `IND_LAS` | IND와 같은 242사례 × VB 플랜트 | **기록 전용 귀속 열**(ABL28과 같은 지위) |

- IND의 뜻: LAS-b는 C2 계열의 $\hat L$(하한 하중 추정)·크롤러 구역·LOC 전 LEVEL 단계에 정의된 규칙이다. C8 골격에는 대응 단계가 없어 IND에는 넣지 않는다. IND 행은 LAS 전환 전후 같은 제어기다.
- IND_LAS 처리
  - 출력: `06_analysis/02_control/v5_rerun/las/u6_b5_<label>_VB_IND_LAS.json`(`<label>` = wide·main). 판정 파일 `u6_b5_<label>_VB.json`과 섞지 않는다.
  - 판정 문장·비교 문장(봉인 5.2 "C2 ↔ ABL ↔ IND")에 쓰지 않는다. U-6 표에는 참고 열로 lite 통과 수·크롤러 하중 완료 수·공식 판정 수를 적는다. 각주 "업계형 순서에 같은 감속을 붙인 참고값. 문턱은 C2 값 그대로이고 IND에서 검증되지 않았다"를 붙인다.
  - 관문: G-1(실행 오류 0, 키 = IND와 같은 242)과 G-2(태그 `IND_LAS`, ③ 끔, v5 meta 칸)만 적용한다. G-5(VB 고유 실패)는 적용하지 않는다(V0 짝이 없다).
  - **IND_LAS의 실패는 멈춤 사유가 아니다.** 기록한다.
  - 비트 동일성 기록: 어댑터 관문이 서지 않은 사례는 IND_LAS 명령 해시가 IND와 같아야 한다. 다르면 어댑터 결함이므로 IND_LAS 열 전체를 쓰지 않고 python-expert에 넘긴다. IND 판정은 영향받지 않는다.
- U-6 판정 실행 수는 봉인 그대로 726이다(C2·ABL·IND). IND_LAS 242는 그 밖의 기록 실행이다.
