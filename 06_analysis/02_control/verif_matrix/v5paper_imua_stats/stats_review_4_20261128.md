### 추가 지적
- **A(원칙 5) E-1 "예상보다 큼"은 사실상 도달할 수 없다.**
  - 조건 4의 크기 상한(30/45 s)이 "설명됨" 안에 있다. 그래서 실제 지연이 커지면 줄이 "예상 크기 초과"로 빠지고, 설명됨 수는 오히려 줄어든다.
  - 공개 확인 실행 지연을 ×s로 키운 세계에서 P(설명됨 > 상한)
    - D-1 V0: ×1.25 0.56, ×1.5 0, ×2 0
    - D-1 VB: 모두 0
    - U-3: ≤ 0.5 %
  - 같은 세계에서 P((i) 성립 수 > 상한)
    - D-1 V0: ×1.25 0.999, D-1 VB: ×1.5 0.985
    - U-3 V0: ×1.25 0.26 / ×1.5 1.0, U-3 VB: ×1.25 0.20 / ×1.5 0.98
  - 확인 실행 지연 최대는 V0 26.1 s(< 30), VB 44.7 s(< 45)다. 그래서 "예상 크기 초과"의 기대 수는 0이다. VB 상한의 여유가 0.3 s뿐이라는 점도 공개한다.
  - 확인 필요 2의 추가 공개를 권한다.
- **B(원칙 4) E-2 상한은 정보가 적다.**
  - 근거가 기회 집락 3개(사건 1개)다. 하한은 0이고 상한은 기회 줄의 절반 정도다.
  - "예상보다 큼"은 π ≥ 2/3 ∧ q ≈ 1(V0 0.85, VB 0.92)이거나 π = 1 ∧ q ≥ 0.75(0.99)일 때만 대부분 걸린다. π = 1/3 ∧ q = 1이면 0.06~0.07이다.
