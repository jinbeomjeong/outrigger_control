## R2-1. 새 G-2′ (하한 여유)

$$\textbf{G-2′}:\quad F_{RL}\ \ge\ 10.400+m\ \text{kN}\quad\text{그리고}\quad F_{judged,min}\ \ge\ 10.400+m\ \text{kN}$$

$$m = 1.015\ \text{kN}\ \Rightarrow\ 10.400+m = 11.415\ \text{kN} = F_{min}+2.000\ \text{kN}\ (11.414589\ \text{kN, 이 값으로 비교})$$

| 기호 | 뜻 | 단위 |
|---|---|---|
| $F_{RL}$ | `diag.summary.F_RL_kN`(이륙 뒤 RL 실린더 순 힘 최소, 플랜트 참값) | kN |
| $F_{judged,min}$ | `diag.summary.F_judged_min_kN` | kN |
| $m$ | 하한 여유 | kN |

- 비교값은 **11.414589 kN**($F_{min}$ + 2,000 N)이다. "10.400 + m"은 표기일 뿐이다.
- **$m$의 근거(결과와 무관한 기존 프로젝트 값)**
  - 프로젝트 R8 설계 목표 "$F_{min}$ + 2 kN"(U-R8-18, 2026-10-24, decision_log 5절 "R-5 … 침하 최소 여유 1.34 kN, +2 kN은 목표")를 그대로 쓴다.
  - 원판 문턱 10.400 kN(≈ $F_{min}$ + 1 kN, LAS-b 원판 C1)이 "판정 하한"이라면, G-2′는 R8 설계가 처음부터 목표로 둔 여유다.
  - 이 1 kN 추가분이 덮으려는 것
    - (i) 원판 G-2가 허용한 뽑지 않은 위상의 흩어짐 0.500 kN
    - (ii) 하네스 모델 오차. 하네스는 강체 크롤러 + 집중 접촉이라 이륙 과도의 크롤러 접촉 이산 사건(분석서 2.4)을 단순화한다. 하네스와 Chrono의 G4 짝 차는 0.1 kN이었지만(control 개정 42), 이륙 과도에서 같은 일치는 확인되지 않았다.
  - 이 둘에 대한 보수 몫이다.
- **$m$을 결과에 맞추지 않았다는 점의 공개**
  - 이미 본 R-G·R-H의 P5r4 최소는 12.452 kN이다. 이 기준과의 차는 1.037 kN이다.
  - $m$은 위 기존 목표값으로 정했고, 1.0·1.5·2.0 kN 등을 결과와 견주어 고르지 않았다.
  - 만약 결과에 맞췄다면 12.4 kN 근처를 골랐을 것이다. 그렇게 하지 않았다.
- 센서 오차를 $m$에 넣지 않는 이유
  - $F_{RL}$은 플랜트 참값이다. 압력 센서 오차(WIKA normal 등급)는 제어기 판독에 들어가 궤적(위상)을 바꿀 뿐 판정값에 더해지지 않는다.
  - 센서 등급이 궤적에 주는 영향은 잡음 등급 L1~L3(436.8)에서 본다.
- 원 G-2·G-2H($R_c$, $R^{\cup}_c$ ≤ 0.500 kN)는 **기록 항목**으로 남긴다. 판정에는 쓰지 않고, 판정서에 칸별 값을 적는다.
- G-1·G-1H(≥ 10.400 kN)는 그대로 판정 기준이다.

### B.1 판정 도구 `las_revA_judge.py`

- **M-2 상수 정정**: `M2_P5_MAX_RANGE_KN = 1.105`를 `1.1049128292761132`로 바꾼다(rev1 RA1-2).
  - 주석에 "rev1 RA1-2: stored P5 max R_c (V0 c0.94, j <= 3), not the rounded 1.105"를 적는다.
  - 이 정정으로 R-G·R-H의 M-2 판정은 바뀌지 않는다(2.871·2.939 kN ≥ 두 값).
- **M-3 docstring 정정**: `M3_BRANCH_A` 설명의 P5 값 "11.314"를 **"11.418 (V0 nom j3, hash acfe58346d29; 11.314 was VB nom j3, rev1 RA1-1)"**로 고친다. 키는 그대로다.
- **G-2′**: `G2P_FLOOR_KN = 11.414589`(= F_min + 2 kN, rev2 R2-1)
  - R-0A의 R-G·R-H 54줄 + R-Q 48줄, 모두 `F_RL_kN`와 `F_judged_min_kN`을 이 값과 비교한다.
  - 실패 줄을 키·격자점·값으로 출력한다.
- 원 G-2·G-2H는 기록으로만 출력하고 status에 쓰지 않는다. 16점 합집합 범위(정수·반 칸·1/4 칸)도 기록으로 출력한다.
- **R-Q**: 격자점 $j$ 실수, 줄 이름 `-LQ-` 꼴. G-1Q, G-3(48줄), K-A5·K-A6·K-A8.

  - Q-1~Q-5 참·거짓을 출력한다. 어긋나면 H-12 멈춤으로 표시한다.
- **R-0A**: 54줄의 `commands_sha256`을 `revA_RG.jsonl`·`revA_RH.jsonl` P5r4 줄과 64자로 대조한다(H-2). 두 파일의 sha256을 대조한다(H-10). K-A1~K-A4는 R-0A 줄과 저장 P5 짝(R-G는 `rev_RG.jsonl`, R-H는 `revA_RH.jsonl` P5 줄)으로 한다.
- 후보 집합에서 P5r6을 뺀다(R2-2). 순위 규칙은 쓰지 않는다(후보 하나).
- 정체성 기록과 검사에 rev1·rev2 sha256(`rules_revA_rev1_sha256`, `rules_revA_rev2_sha256`)을 더한다.
- 상태와 멈춤: H-6′, H-12, H-13. 종료 코드는 원판과 같다(stop·undecidable·멈춤 = 1).
