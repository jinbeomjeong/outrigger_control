# C4G2·K1 인수 하네스 판정

코드 74032be(`scratchpad\cad_c4g2\wt`), 조합 C4G2 + K1, 축소 모델, Chrono 없음. 기준은 본 실행 전에 쓴 `criteria.md`이고 바꾸지 않았다. L4는 사용자 결정으로 생략. 수치 원본 `judgement.json`, 조합별 재실행 `split\`. 유량 끔, 음되먹임, $T_s$ 0.1 s, $d$ = 1.

## 결론

- **격자만 사전 기준 미달이다.** 통과→실패 1행(0.021 s 초과)이고 K1 몫이다. 나머지 묶음은 모두 합격이다.
- **잡음 L2 합격:** 10/855, CP 95 % 상계 1.976 %(≤ 3 %, 현행 11/855).
- **C4G2:** 기준 충족. 채택 권고. 다만 하네스 합격은 C4G2 단독이 아니라 둘 다 켠 조합의 값이다.
- **K1:** 사전 기준 미충족 2건(격자 1행, C-S8-41). 자동으로 합격 처리하지 않는다. 힘 이득은 크므로 예외 여부는 사용자 결정이다.
- **K1 토양 Chrono:** 위 결정 전에는 시작하지 않기를 권고한다.
