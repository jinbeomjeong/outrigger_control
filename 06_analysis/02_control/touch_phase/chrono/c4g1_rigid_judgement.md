# C4G1 강체 Chrono 4건 판정

대상은 커밋 15176d1, `with_10hz_d1(touch_twist_hold=True)`, 음되먹임, 제어 주기 $T_s = 0.1$ s, 출력 지연 $d = 1$이다. S7·K1·G2·보정 종료 규칙이 빠져 있어 채택 의견은 잠정이다. 조건마다 켬/끔 짝은 1개다. 수치 원본은 `c4g1_rigid_judgement.json`이다.

## 결론

- 판정 행 실패는 네 켬 실행 모두 0이다. 사양 미달은 없다.
- 하네스 예측(RL 62.3~64.2 kN)은 수준에서 맞지 않았다. Chrono는 44.47~57.51 kN이다. 비슷한 $D_{te}$에서 켬·끔 이득은 3 kN 안에서 맞는다.
- R9 대칭의 $D_{lift}$ 19.71 → −2.08 kN은 전부 G1 몫이다. C2 절단은 작동하지 않았다. 분리 실행은 필요 없다.
- R9 δ0.35의 RL 45.43 kN은 보정과 이륙이 겹쳐서 남는다. 이륙(TOUCH 끝 +0.43 s) 때 보정은 12 %만 끝났다.
- R4에서는 C4가 시작하지 않았고 G1 효과도 0.66 kN뿐이다. D̂ 창·보류 시간은 바꾸지 않는 것을 권고한다.

- 켬·끔 이득: $D_{te} \approx 0$에서 하네스 +11.56, Chrono +12.97 kN. $D_{te} \approx 12.6$ kN에서 +17.04, +14.14 kN. δ0.35에 대응하는 하네스 점은 없다.
- 하네스는 보정이 끝난 뒤 이륙하고 Chrono는 보정 초입에 이륙한다. 진행률은 TE 뒤 0.5 s에 22~25 %, 0.6 s에 39~42 %, 0.8 s에 76~80 %, 1.0 s에 101~103 %다. 최대 넘침은 11 %다.
- 앞선 Julia 예측 "0.5 s에 41 %"는 맞다. 시간 원점이 첫 명령이었고, Chrono는 TOUCH→LEVEL 주기의 영 명령이 한 주기 더 있어 te+0.6 s의 39~42 %와 대응한다.
- 이륙 시각 차이의 주원인은 강체 NSC 크롤러다(하네스 강성 스윕으로 확인, `../crawler_hold_report.md`). Chrono는 평균 행정 0.46~0.97 mm로 크롤러 하중 53~119 kN을 넘긴다.
- $\tau_{te}$와 $\hat D / k_{nom}$: δ0은 $\tau_{te} - n^T g = 0.570$ mm 대 0.568 mm로 맞다. δ0.35는 1.610 mm 대 1.686 mm로 4.7 % 크다. 원인 후보는 $\hat D$에 든 정지 꼬리(약 1.1 kN)와 실효 강성 약 23.8 kN/mm다. 보정 뒤 잔여 $D$는 R9 대칭 대비 약 +0.2~+0.65 kN(δ0), −1.8 kN(δ0.35)이다. 목표 부호와 크기는 타당하다.
- 첫 이륙 골: 켬에서는 RL이 내려가는 골이 아니다. TE의 37 kN에서 오르는 중에 이륙 판정이 들어온 값이고, te+0.7 s에 58 kN, te+0.9 s에 62 kN이다. $|D| > 10$ kN 구간은 켬 te+0.75 s까지, 끔 te+9.5 s까지다. RL < 50 kN 시간은 0.16 s 대 4.03 s다.
- 축소 모델 교차 점검: Python ↔ Julia 최대 상대차 2.9e-15, `일치`. 같은 모델을 두 언어로 푼 것이며 Chrono 검증은 아니다. 모델 ↔ Chrono RMS는 0.014 mm(δ0), 0.042 mm(δ0.35)이고 넘침은 Chrono가 약간 크다.

## 3. R4

- $\hat D$ 차이는 고착된 실 마찰로 확인했다. 같은 표본에서 $\hat D$ 판독 평균 −0.789 kN, $n^T F_{cyl}$ 평균 +0.604 kN이고 차이 1.39 kN의 대부분이 $n^T f_{seal}$(0.41, 1.96, 1.72 kN, 평균 1.36 kN)이다. `candidates.py`의 "$n^T F_s = 0$"은 네 다리가 모두 신장 중일 때만 맞다. 고착 때 상한은 F_s 4에서 약 ±7.3 kN(0.32 mm)이다.
- G1 효과가 작은 이유: 끔 명령 (0, v, 1.1, v)에서 큰 두 다리가 같은 비율로 잘려 끔의 $\tau$가 −0.03 mm뿐이다. $D_{lift}$ 차 0.66 kN과 맞는다.
- $D_{lift}$ −7 kN은 $\tau$에서 오지 않는다. $\tau \approx 0$인 채 $D$가 te+0.7, 0.9, 1.1 s에 −10.9, 0, −7.2 kN으로 진동하고 켬·끔이 같다. 강체 크롤러 이륙 로킹으로 판단한다. RL 37 kN도 $D < 0$(RL을 올리는 방향)인 때에 나오므로 비틀림으로 고칠 수 없다.
- 하네스 R4와의 차이: 하네스는 $\tau_{te}$ −0.43~−0.23 mm, $\hat D$ −1.1~−7.5 kN으로 C4가 시작해 $D_{lift}$ 폭이 2.84 → 4.63 kN으로 넓어진다. 대신 RL 폭은 2.87 → 1.64 kN으로 좁아지고 하한은 53.27 → 53.02 kN이다. Chrono R4는 이번 위상에서 $\tau_{te} = 0$이라 이 현상을 시험하지 못했다.
- 권고: D̂ 창·보류 시간 변경 없음. 보정은 te+1.0 s에 끝나 1.5 s 보류로 충분하다. 3표본의 정지 꼬리 몫은 1.05~1.52 kN(0.05~0.07 mm)이다. 어느 값을 바꿔도 이륙과의 겹침은 풀리지 않는다.

### 6.1 $\Delta u$ 정의: 지시문 정의를 권고

$l$은 다리별 제한 증분, $r$은 요구 증분, $\rho$는 공통 비율이다. 래퍼·구현은 $|n^T l|$, 지시문은 $|n^T (l - \rho r)|$이다. 두 값의 차는 $\rho\, n^T r$이므로 요구 명령에 비틀림이 있을 때, 곧 C4 보정 중에만 갈린다. 재현에서 보정이 없는 행은 같은 값이다.

| R16 mirror2 ε0 (목표 +0.599 mm) | 현재 $|n^T l|$ | 지시문 |
|---|---|---|
| 램프 3주기 $n^T l$ / $\rho\,n^T r$ (mm/s) | 0, 0, 0 / 0.40, 0.40, 0.37 | 같은 입력에서 차 0.40, 0.40, 0.37 → 공통 비율 |
| 램프 중 보정 | 전부 지워짐, 램프 뒤 시작 | 비율대로 통과 |
| $D_{lift}$ / +1 s / +3 s / +15 s (kN) | 2.06 / 3.47 / 2.27 / 2.68 | 4.17 / 3.11 / 2.14 / 2.60 |
| 보류 끝 잔차 (mm) | 0.042 | 0.012 |
| 이륙 시각 (TE 뒤) | 0.774 s | 0.782 s |
| RL 최소 (이륙 8 s 뒤, kN) | 39.91 | 39.78 |

이유:
- G2의 목적은 "제한이 명령 방향을 바꾸는지"이고 지시문 정의가 바로 그 양이다. 현재 정의는 네 다리가 같은 값으로 잘리면 보정을 지우면서도 0으로 읽는다.
- 5절의 경주(보정 대 이륙)에서 램프 3주기 손실은 직접 불리하다. 대칭 명령 + 틈 행이 이 경우에 해당한다.
- $D_{lift}$ 2.06 → 4.17 kN은 악화로 읽지 않는다. 현재 정의는 보정이 늦어 창이 중간 $\tau$(0.028 mm, 목표 0.327 mm)를 보는 값이다. 지시문 쪽은 $\tau$ 0.216 mm이다. 둘 다 약 +2.6 kN으로 수렴하는데, 이것은 $\hat D$ −13.6 kN과 실제 $D_{te}$ −10.06 kN의 차(정지 꼬리 3.5 kN)로 인한 과보정이고 G2와 무관하다.
- 판정 영향은 작다. R4 ε0 F_min +0.04 kN, S7 $D_{lift}$ −0.001 kN(전달값), R16 RL −0.13 kN.

단서: 짝 2개의 하네스 값이고 Chrono 값이 없다. 이득이 크지 않으므로 G2 Chrono 전에 정한다.
