사용자 결정: C4G2 채택, K1은 "토양 위상 스윕 뒤 정함". K1이 사전 기준(`criteria.md`, `c4g2_k1_judgement.md`)을 충족하지 못한 사실(격자 통과→실패 1행, C-S8-41, 토양 다른 다리 여유, P3-4 1행)은 그대로 둔다. **이 스윕은 합격 판정이 아니라 예외 판단 자료다.** 통과해도 "기준 충족"이라고 쓰지 않는다.

## 지표

$\Delta$는 항상 B − A(같은 행, 같은 $\delta$)다. 힘은 $F_{cyl}$ 1 ms, $F_{min}$ = 9.4146 kN. 음의 힘은 하중으로 인용하지 않는다.

| 지표 | 정의 |
|---|---|
| 공통 창 $W_c$ | 그 짝의 $\max(W_A, W_B)$ |
| 다리 최소 $m_{leg}$ | $t > W_c$의 다리별 최소 |
| 행 최소 여유 $M$ | $\min_{leg} m_{leg} - F_{min}$ |
| RR F_min 아래 위상 수 | 행마다 $m_{RR} < F_{min}$인 $\delta$ 수. 참고로 $< F_{min} + 5$ kN인 수 |
| 재READY 폭 | $t_{ready,back}$의 $\delta$별 값, $\Delta$의 최소·중앙·최대 |
| 쌍 합집합 | `pair_union_s`, 한계 1.8 s, 최대와 $\Delta$ 최대 |
| 위상 폭 $S$ | 팔 A, 조밀 11개에서 그 양의 최대 − 최소 |

통계는 조밀 11개로 내고, 최악값·위상 수는 15개 전부로 낸다. 위상들은 독립 표본이 아니므로 신뢰구간을 내지 않는다.

## 위상 산포와의 구분

어떤 양의 K1 효과가 **구분된다**: 조밀 11개 중 $\Delta$ 부호가 같은 위상 ≥ 9개이고 $|\text{median}\,\Delta| > S/2$. 아니면 **구분 안 됨**이다. 구분되지 않는 양은 이득으로도 비용으로도 주장하지 않고 범위만 적는다.

## 하네스 보정

사실: Chrono와 하네스는 힘의 절대값이 다르고(하네스가 높음), RR 효과 크기도 일정하게 어긋나지 않는다(RRFs0 −11.1 대 −2.4, FLFs0 −13.2 대 −11.4, FLFs8 −3.6 대 −10.3 kN). 재READY 효과도 RRFs0에서 +6.4 대 +0.1 s다.

1. 하네스 절대값을 그대로 F_min 여유로 읽지 않는다. 원시 값은 "하네스 안에서의 위반"에만 쓴다.
2. 앵커: Chrono 짝과 같은 위상. $\delta_a$ = FLFs0 0.00, RRFs0 0.00, FLFs8 0.05 s(Chrono 사건 시각 36.30, 36.30, 36.25 s의 주기 내 위치). Chrono 짝의 끔을 팔 A 앵커로 쓴다. F_s 0 행은 C4G2 보류가 사건 직전 다리 힘을 ≤ 0.03 kN만 바꿨다.
3. 다리별 배율 $g = \max(1, |\Delta_C| / \max(|\Delta_h(\delta_a)|, 0.5\text{ kN}))$. $\Delta_C$는 Chrono 켬 − 끔(공통 창 값, `k1soil_values.json`), $\Delta_h$는 하네스.
4. 보정 추정(불리한 쪽으로만 키운다):
   - $\hat A_{leg}(\delta) = C_{A,leg} + h_{A,leg}(\delta) - h_{A,leg}(\delta_a)$
   - $\hat B_{leg}(\delta) = \hat A_{leg}(\delta) + g\,\Delta_h(\delta)$, 단 $\Delta_h(\delta) \ge 0$이면 $g$ 없이 $\Delta_h(\delta)$
   - 행 최소는 $\min_{leg}$. 앵커에서 $\hat B$가 Chrono 켬과 다른 것(하네스 효과가 더 큰 행)은 허용한다. 그만큼 보수적이다.
5. 재READY도 같은 식이다. $g_t = \max(1, \Delta_{C,t} / \max(\Delta_{h,t}(\delta_a), 0.5\text{ s}))$, 늘어나는 쪽에만 곱한다. 이 값 + 행의 Chrono 사건 시각(loop 기준)으로 READY를 내고 P3-6 90 s와 비교한다.
6. 이 보정은 짝 3개에서 정한 경험식이다. 계산 값은 "보정 추정"으로 표시하고 확인으로 쓰지 않는다.

## 판단 항목

| # | 항목 | 통과 조건 |
|---|---|---|
| T1 | 판정 행 | 팔 B FAULT 0, 같은 위상에서 A 통과 → B 실패(E-1~E-7) 0 |
| T2 | 원시 F_min | 팔 B 행 최소 여유 $M \ge 0$, 15위상 전부. 저장 판정의 `Fmin_after_W`도 같이 본다 |
| T3 | 보정 F_min | $\hat B$ 행 최소 $\ge F_{min}$, 15위상 전부. 실패 위상은 수와 $\hat A$ 값을 함께 적는다 |
| T4 | 위상 최악 | 행별 15위상 최악 $M$이 B ≥ A인 행이 3행 중 2행 이상 |
| T5 | RR 위상 수 | 행별 RR F_min 아래 위상 수가 B ≤ A |
| T6 | 쌍 합집합 | 팔 B 15위상 최대 ≤ 1.8 s |
| T7 | READY | 보정 추정 READY ≤ 90 s, 15위상 전부 |
| B1 | 토양 이득 | RL의 $\Delta$ 중앙값 > 0이고 "구분됨"인 행이 2행 이상. **그리고** 행 최소 여유 $\Delta$ 중앙값 > 0이고 "구분됨"인 행이 1행 이상 |

## 판단 규칙

| 결과 | 조건 | 권고 문구 |
|---|---|---|
| **탈락 권고** | T1, T2, T6 중 하나 실패, 또는 T3 실패 위상에서 $\hat A$는 $F_{min}$ 위 | K1을 채택하지 않는다 |
| **예외 근거 있음** | T1~T7 전부 통과, B1 통과 | 예외를 인정할 근거가 있다. 사전 기준 미충족은 남는다. 채택은 사용자 결정이다 |
| **근거 불충분** | 그 밖 | 토양 쪽 근거만으로는 예외를 지지하지 못한다. 기본은 K1 끄기. 강체 이득을 더 무겁게 볼지는 사용자 결정이다 |

강체 쪽 이득(격자 `Fmin_after_W` 35 → 2)은 이 판단 규칙에 넣지 않고 리포트에 나란히 적는다.

## 보류 강제 팔(Af, Bf)의 읽기

Chrono F_s 0 행은 C4G2 보류를 걸었고 하네스는 걸지 않을 수 있다. 두 비교를 한다.
- 보류 몫: Af − A, 조밀 11개, 행 최소 여유·RL·RR의 중앙값과 범위.
- K1 몫의 변화: (Bf − Af)와 (B − A)의 중앙값 차.

위 차의 절댓값이 그 양의 $S/2$보다 작으면 "보류가 K1 몫의 읽기를 바꾸지 않는다"고 적는다. 크면 F_s 0 행의 T3~T5를 Af, Bf로도 내고, 둘 중 불리한 쪽으로 판단한다.
