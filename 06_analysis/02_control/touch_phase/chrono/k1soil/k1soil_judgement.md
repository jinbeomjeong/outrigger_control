# K1 토양 Chrono 9행 판정과 C4G2·K1 권고 자료

대상: `07_results\S9\batch_k1soil_G1_20261105`, 코드 74032be(`c2.py` 28482b8d…), G1, 패드 B, 상단, 평지, 압력 normal, IMU ideal, 유량 끔, RE1bF(30 mm/0.05 s), mid 시각. 음되먹임, $T_s$ 0.1 s, $d$ = 1. 항목 9는 ce21ffa 재생기. 수치 원본은 `k1soil_values.json`. 새 시뮬레이션은 없다. **Chrono 비평면 5건 전이므로 모든 권고는 잠정이다. 채택은 사용자 결정이다.**

## 결론

- **판정 행:** E-1~E-7은 끔·켬 6행 모두 통과다. FAULT 0, 크롤러 재접촉 0 ms, 놓침 0이다.
- **K1은 최소 힘을 없애지 않고 옮긴다.** RL은 3행 모두 오르고(+8.6~+17.6 kN) RR은 3행 모두 내린다(−3.6~−13.2 kN). 행 전체 최소는 1행 개선, 2행 악화다. RR 행 여유는 F_min 위 12.11 → 0.97 kN이다.
- **K1 사전 기준은 토양에서도 충족하지 못한다.** C-S8-41 FLAG가 3행 모두에 새로 생겼고, "다른 다리 여유 유지"도 엄밀히 읽으면 미달이다. 강체 쪽 미충족 2건에 더해진다.
- **비용:** 재READY +0.7, +2.2, +6.4 s(P3-6 안). 재접근이 줄어 사건 대각의 $|D|$가 더 오래 크다.
- **C4G2:** 토양에서 이득도 해도 없다. 하네스 예상과 달리 F_s 0 두 행에서 보류가 시작됐다. 그래서 F_s 0 짝은 K1 단독 비교가 아니다.
- **꼬리 진동(개정):** `FLFs8` 켬 행의 READY 꼬리에 명령 0에서 줄지 않는 2.0 Hz 진동이 있다(roll p-p 0.0013°). dynamics-expert 판정은 SCM 격자 수치 현상이다(아래 절). P3-4는 이 행에서 판정 불가이고, 주기 창 재계산 끝 자세는 0.0277°다.
- **권고(잠정):** C4G2는 채택 후보 유지, K1은 사전 기준대로는 합격이 아니므로 예외 없이는 채택을 권하지 않는다.
- **후속(2026-11-05):** 사용자가 C4G2 채택, K1은 위상 스윕 뒤 결정을 골랐다. 스윕 결과는 `sweep\sweep_judgement.md`이고 사전 규칙의 결과는 "탈락 권고"다.
- **사용자 결정(2026-11-05):** K1 탈락, C4G2 단독이 최종 후보. FLFs0 δ 0.03 C4G2 단독 Chrono 1건(cad-expert 준비). 재실행 범위는 잡음 L1·L2·L3 + 강체 격자 768행(`acceptance\criteria_c4g2_only.md`). P3-4 FLFs8 켬은 "수치 진동으로 판정 불가"로 기록하고 K1 FLAG에서 뺀다. 침하율 창 재계산은 했고 적용은 다시 묻는다. `sweep_criteria.md`와 `criteria.md`는 고치지 않았다.

- **확인:** K1은 3행 모두 작동했다. FLFs8은 사건 전 명령이 끔과 같아 차이가 K1에서 시작한다.

- **추정:** 재접근이 줄어 사건 대각이 가벼운 상태가 오래가고, 그 때문에 비틀림 완료가 늦다. `ok_twist` 마지막 거짓이 재READY 지연과 같이 늦어지는 것(RRFs0 34.6/28.2 s)이 이를 뒷받침한다.
- **추정:** RRFs0 RR 10.38 kN은 1.4 s 보류 동안 내려간 값이다. 끔은 같은 표본에 재접근을 시작해 21.52 kN이다.
