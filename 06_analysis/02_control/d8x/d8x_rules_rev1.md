## 1.3 검증 모드 `verification_ext` (대체)

`TargetLimits.for_mode(SlopeLimitMode.VERIFICATION_EXT)`는 다음 값을 돌려준다.

| 필드 | 값 |
|---|---|
| `relative_roll_span_rad` | radians(5.7) |
| `relative_pitch_span_rad` | radians(3.7) |
| `relative_pitch_span_nose_up_rad` | **radians(3.6)** |
| `usage_tolerance` | 0.01 |

- 의미: `relative_pitch_span_for(θ_t − \hat θ_g)`는 상대 pitch가 양수일 때 3.6°를 쓴다. 목표가 0이면 상대 pitch가 양수인 경우가 바닥 추정 $\hat\theta_g<0$, 곧 앞들림 바닥이다. 따라서 A1과 A4가 rev1 1.1의 비대칭 마름모가 된다.
- 기존 `TargetLimits.relative_pitch_span_for` 기구를 그대로 쓴다. 새 분기를 만들지 않는다.
- `TargetSettings.relative_pitch_span_nose_up_rad`(설정 수준 덮어쓰기)는 원판처럼 검증 모드에서 금지한다. 그러면 모드가 정한 3.6°를 바꿀 수 없다.
- 절대 마름모, 축별 상한, 정착 사상 허용, 기존 `VERIFICATION`(5.5/3.5, 대칭)은 그대로다.

- 후보 11점과 지표 $m(p)$, 동률 규칙, 이름표(`dxpp025`, `dxpp075`, `dxpm025`, `dxpm050`, `dxpm075`, `dxmp050`, `dxmm050`, `d45pp`, `d45pm`, `d45mp`, `d45mm`)는 원판과 같다.
