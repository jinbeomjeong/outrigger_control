# K-2 검증용 산일 보강 모델 명세 (V-3 `diss_preset`, V-6 이동 중 감쇠)

- 출처: **dynamics-expert 리포트 2026-11-10**(메인 세션이 control-expert에 전달한 요약과 사용자 답 Q-1, 2026-11-10). 이 파일은 control-expert가 그 내용을 그대로 옮겨 적은 것이다. 해석이 갈리면 dynamics-expert 원 리포트가 맞다.
- 쓰는 곳: `k2_touch_creep_rules.md` 3.3(V-3), 3.5(V-6), 5.4(사전 예측).
- 단위: SI. 감쇠비 ζ는 무차원. 속도 [m/s].

## 1. 하네스 옵션 (`KPlant`에 직접 넣음, 묶음 이름 `diss_preset`)

| 기호·이름 | 정의 | 값 |
|---|---|---|
| 밸브 열림 | 1 ms 구간에서 그 다리의 밸브 출력 \|u\| > `lock_eps` | `lock_eps` = 1e-6 m/s |
| 열림 다리 | TOUCH 접근, K-2 크리프, LEVEL, 재접근 다리 | – |
| LOCK 다리 | 래치 뒤 정지 다리, READY 다리 | – |
| τ_v 꼬리 | 명령 0 뒤 밸브 출력이 줄어드는 구간 | 위 \|u\| 정의를 따르고 길이는 기록만 |
| ζ_mov | 열린 다리의 **법선(축) 감쇠 cn만** 바꾼다: cn_move = cn_LOCK × 0.10/0.03. 접선 ct는 LOCK 값 | ζ 0.10 |
| 크롤러 L1 동등(`chrono_l1`) | 크롤러 kt/kn 배수(Chrono L1 값, 현 YAML에서 계산) | 0.233093 |
| 크롤러 heave 감쇠비 | | 0.05 |
| $F_s$ | 실 마찰, 전방 / 후방 | 4 kN / 전방 × 0.8333 |
| `KT_REL_CHRONO` | 하네스 기존 상수(옛 YAML 값). 이름만 정정하고 값은 그대로 | 0.4022 |

## 2. 팔 (각 팔 × {끔, K-2})

| 팔 | 구성 |
|---|---|
| H0 | 현 하네스(옵션 모두 끔) |
| L1eq | 크롤러 kt/kn × 0.233093 |
| L1eq_fs | L1eq + $F_s$ |
| L1eq_zm | L1eq + ζ_mov |
| AUG | L1eq + $F_s$ + ζ_mov |
| AUG_crc2 | AUG + 크롤러 c × 2 |
| AUG_eps | AUG, 열림 문턱 ε = 0.1 v_max(크리프 다리를 LOCK으로 봄) |

- 대상: D8x J3 실패 행과 같은 두 사분면(상단·앞내림 쪽)의 통과 표본. 행 선정은 control-expert가 한다(규칙 3.3).
- 비트 불변: 옵션을 모두 끄면 기존 플랜트와 비트가 같아야 한다. G0 60행과 R-c 표본의 `commands_sha256`로 확인한다.
- 행 신원: `isinstance KPlant`, `case_id`, 보강 요청값, [`t_touch`, `t_lift`] 구간의 다리별 열림 시간 비율.

## 3. Chrono (V-6)

- L1-R: 매 스텝 훅에서 그 다리의 패드 구·패드 패치 재질 gn을 ζ_mov(위 정의)로 바꾼다. 합성 재질은 충돌 검출마다 새로 만들어지므로 다음 스텝부터 적용된다. 밸브 열림 정의는 하네스와 같다.
- L2b-NSC: 강체 NSC 접촉(감쇠 없음). 이동 중 감쇠는 넣지 않는다(규칙 3.5에서 정함).

## 4. V-6 사전 예측 (이동 중 감쇠를 켜면 끔 행의 J3가 0 쪽으로 더 간다)

| 행 | 예측 |
|---|---|
| L1 끔 | J3 중앙 0(범위 0~150, P(J3 > 0) ≈ 0.35), 창 안 최소 N 0~50 kN, 로킹 첨두 2.9~3.5 Hz |
| L1 K-2 | J3 0(확신 ≥ 0.8), 최소 N 0~25 kN(중앙 약 9 kN), TOUCH 끝 −0.5~+2 s, READY ±1.5 s, CAP 래치 0, D8 최소 힘 ±5 kN |
| L2b | 끔·K-2 모두 J3 0, 최소 N ≥ 40 kN, 공중 거짓 래치 0, CAP 래치 0 |
