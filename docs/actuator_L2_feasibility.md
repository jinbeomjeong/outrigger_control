# 구동기 L2 적용 가능성 검토 (2026-10-19)

작성: dynamics-expert. 지금 확보된 정보만으로 L2(`ChLinkMotorLinearForce` + 유압유 기둥 힘 법칙 + 기준 속도 포화, L2b 횡 부싱 포함)를 적용할 수 있는지 검토했다. 무결성 점검에서 받은 Chrono SMC 접선 모델 제약(4절)도 반영했다.

- 입력: `CLAUDE.md`, `docs/dynamics_model.md`(개정 3), `docs/hydraulic_fluid_survey.md`, `params/rexome33.yaml`, `scripts/dynamics/dyn_model.py`. 모두 읽기만 했다.
- 추가 계산: `scripts/dynamics/run_actuator_L2_feasibility.py` → `analysis/dynamics/actuator_L2_feasibility.json`(약 2 s, conda `dynamics-dev`).
- 규약: `dynamics_model.md` 1절과 같다. 기체 좌표는 x 전방, y 좌측, z 상방이고 $\mathbf g=-9.80665\,\hat z$ m/s²다. 다리 순서는 FL, FR, RL, RR이다. 힘은 실린더 힘(압력 × 보어 면적, 압축 +)이 기준이다. 상단 오거 단계, 크롤러 50 mm 띄움 운용점이다.
- 표기 갱신(2026-10-20): 자세 정확도 목표가 ±0.1°에서 **±0.2°**로 완화돼(CLAUDE.md) 3.4절 누설, 3.6절 표, 5절 선택지 표·결론의 네 곳 표기만 바꿨다. 결론은 같다(정상상태는 적분 제어가 정하므로 목표값과 L1/L2 선택은 무관하다).
- 재현 확인: 수평 운용점에서 이 스크립트의 L1 로킹 1.7845 / 2.9842 Hz, L2b 1.7854 / 2.9885 Hz, $S_{FL}$ 4.77 kN/mm, FL+ $F_{min}$ 문턱 12.07 mm가 `reference.json` 값과 같다.

## 0. 요약

| 질문 | 답 |
|---|---|
| L2가 L1에 없는 **물리** 입력을 새로 요구하는가 | **아니다.** 강성은 L1과 같은 가정($\beta_{eff}$, $L_0$, $k_{frame}$, 콘크리트)에서 나온다. 새로 생기는 것은 감쇠를 유압 쪽과 접촉 쪽으로 나누는 값($c_{oil}$, 로드 국부 ζ 0.3)뿐이다. 이 값에는 L1 감쇠와 마찬가지로 물리 근거가 없다 |
| L2가 L1보다 나은 점 | 신장에 따른 $k_{oil}(e)$를 반영한다. 큰 경사(최대 레벨링 경사)에서 하중 민감도가 −23 %, $F_{min}$ 문턱이 +29 %, 로킹 진동수가 −12 % 달라진다. 하지만 이 차이는 $\beta$ 감도 범위(민감도 −29 % ~ +51 %)보다 작다. SCM 연약 지면에는 L2가 꼭 필요하다 |
| 제어 대역 안의 압력 신호 | ≤ 0.5 Hz에서 L1과 L2b의 실린더 힘 응답 차는 2.4×10⁻⁵ 이하다. 차이가 없다 |
| 두 모델 모두 빠뜨린 큰 효과 | **실 마찰(stick)이다.** 마찰이 2~12 kN이면 압력 판독이 실제 다리 하중과 최대 $F_s$만큼 다르다. 왕복 뒤에는 실제 하중이 최대 5.9 kN, 압력이 최대 17 kN 남는다. $F_{min}$ 9.45 kN과 같은 크기다. 이 효과를 넣을 수 있는 구조는 L2뿐이다 |
| Chrono SMC 접선 모델 | 설치 헤더에 "MultiStep falls back to OneStep"이 있다. 그러면 L1, L2, L2b 모두 접촉에 정지 마찰 스프링이 없다. L1 로킹이 1.78 → 3.06 Hz로 바뀌고, 2° 경사에서 기계가 미끄러져 내려간다(추정, 4절). L2b 부싱은 접촉 stick을 대신하지 못한다 |
| 결론 | **조건부 가능**이다. 필요한 입력은 지금 모두 있다. 다만 그 입력이 L1과 같은 근거 없는 가정이어서 L2로 바꿔도 하중 신뢰도는 오르지 않는다. 접선 stick 구현(4절)이 선결 조건이다 |
| 추천 | **선택지 B**: L1을 제어기 개발 기본으로 유지한다. L2b를 검증용 2차 모델로 병행해 큰 경사, SCM, 마찰 감도를 본다(5절) |

## 3. L1과 L2의 수치 비교

### 3.1 신장 의존성 $k_{oil}(e)$ (상단, β 1.0 GPa)

L1은 접촉 $k_n$을 운용점 $e_{op}$ 값으로 고정한다. L2는 다리별 레벨링 신장의 $k_{oil}(e_i)$를 쓴다. 경사 지면 위의 레벨링 신장은 `dynamics_model.md` 3.3절의 식이다(크롤러 50 mm 여유).

계산 방법:
- 하중: "놓고 정착(place and settle)" 실린더 힘이다. 수직 스프링 3자유도 모델로 구했다.
- 민감도: FL 단독 신장에 대한 $S$ 대각이다.
- 진동수: L1은 6자유도, L2b는 10자유도로 구했다.

해석:
- 레벨링 경사가 커질수록 L1은 다리 강성을 최대 약 25 % 과대평가한다. 민감도는 +29 %, $F_{min}$ 문턱은 −17 % 쪽으로 틀린다. 문턱이 작게 나오므로 보수적 방향이다.
- 하지만 이 차이는 β 감도 범위 안에 있다. 그래서 β를 0.69~1.6 GPa로 돌리는 감도 해석이 이 오차를 덮는다.
- 정착 하중 차는 최대 4.9 kN(= 0.052 W/4)이다. 실제 레벨링에서는 비틀림을 압력 루프가 정하므로, 이 값은 "개루프 하중 분배" 기준값에만 해당한다.
- **L1 보정판(L1u)**: L1 접촉 $k_n$을 레벨링 신장의 $k_v(e_i)$로 다시 계산해 넣으면 정적 값은 L2와 같아진다. 로킹 차도 ≤ 4.5 %(최대 pitch+ 1차)로 준다. 단 시뮬레이션 도중 신장이 바뀌는 것은 따라가지 못한다.

**V14 기준 변경(2026-10-20, `dynamics_model.md` 개정 5)**: 최대 pitch+ 3.86°에서는 FL·FR 신장이 0.6797 m라 남은 스트로크가 0.28 mm뿐이다. 그래서 위 표의 FL+ 문턱(14.58 mm)은 Chrono에서 시험할 수 없다. V14는 세 경우 모두 **RL+**로 한다. 기준값은 경사면 위 L2b-NSC 정역학(`static_slope_10dof`, 축 $k_{oil}(e)$ ⊕ 로드 ⊕ 프레임 ⊕ 콘크리트, NSC 강체 접촉, 횡 부싱 $k_t$)에서 다리마다 ±1 mm를 줘서 다시 냈다(JSON `A_extension_dependence.V14_rev5`).

### 3.3 실 마찰: 두 모델 모두 빠뜨린 효과

모델(준정적, `run_actuator_L2_feasibility.py` C절):
- 로드는 질량이 없다고 본다. 기름 스프링 $k_{oil}(e_{op})$과 Coulomb 마찰 $|f|\le F_s$를 병렬로 두고, 로드·프레임·콘크리트 $k_s$ = 2.17×10⁸ N/m를 직렬로 둔다.
- 정지(stick) 중에는 기름 기둥이 잠겨 다리 강성이 $k_s$(L1 $k_n$의 10배)가 된다.
- 압력 = 실제 다리 하중 − $f$다.
- 초기 마찰 상태는 $f=0$으로 가정했다(실제로는 레벨링 이력에 따라 정해지지 않는다).

- 마찰이 수 kN을 넘으면 **압력이 실제 하중보다 늦게 $F_{min}$에 닿는다.** $F_s$ 5 kN이면 1 mm, 12 kN이면 2.3 mm 늦다. 압력 기준 $F_{min}$ 판정이 실제보다 낙관적이 된다.
- 잠긴 다리의 하중 변화가 압력에 보이지 않는 불감대가 생긴다($F_s$ 12 kN이면 FL +1 mm에서 RL 압력 변화 0).
- 비틀림 루프에 이력(hysteresis)이 생긴다.
- 작은 진폭(하중 진폭 < $F_s$)에서는 다리가 잠긴 채 흔들린다. 그때 로킹은 3.78 / 4.51 Hz로 L1 기준(1.78 / 2.98 Hz)의 약 2배다. IMU 진동 성분과 $\Delta t$ 판단이 바뀐다.
- 마찰 값의 근거는 "정격 하중의 약 10 %" 관행뿐이다. 실린더 실 형식과 압력이 미확보다. 그래서 크기는 열려 있다. 하지만 **영향이 L1/L2 차이(3.1절)보다 크고 $F_{min}$ 판정에 직접 걸린다.**
- L2 힘 법칙에는 마찰 항을 더할 수 있다. 정지를 정칙화한 Karnopp 형, 또는 로드-배럴 축방향 탄소성 요소를 쓴다. 설치 헤더에 `ChLoadBodyBodyBushingPlastic`(축별 항복력 상한)이 있다. 의미(항복 = $F_s$)는 실행으로 확인해야 한다. L1에서는 기름 기둥이 접촉에 합쳐져 있어 넣을 수 없다.

**V15 기준 변경(2026-10-20, `dynamics_model.md` 개정 5)**: 위 표는 접촉을 양방향(선형)으로 두고 0 → 16 mm까지 갔다. 그런데 $F_s$ = 0에서 RL은 14.08 mm에서 뜨므로, 그 너머의 값과 왕복 잔류는 단방향 접촉인 Chrono와 비교할 수 없다. 그래서 V15를 둘로 나눴다(JSON `C_seal_friction.V15_rev5`).

- (b) 왕복 0 → 10 → 0 mm: 어느 다리도 $F_{min}$·부상에 닿지 않으므로 선형 모델이 정확하다. 잔류는 16 mm 왕복과 같다(마찰이 완전히 반전되기 때문이다).

### 3.6 제어기 검증에 L1이 충분한가

| 목표 | L1로 충분한가 | 근거 |

| 자세 ±0.2° 정상상태(옛 ±0.1°) | **충분하다** | 자세는 IMU 적분 제어로 맞추므로 정상상태 오차는 강성과 무관하다. 기구학 $A^+$는 강성에 거의 무관하다. 동특성(로킹 1.5~1.8 Hz)은 레벨링 대역의 5배 이상이고, L1/L2 차 ≤ 12 %다 |

## 4. Chrono SMC 접선 모델 제약 (MultiStep → OneStep)

확인한 것:
- `C:\ProgramData\miniforge3\envs\Chrono-dev\Library\include\chrono\physics\ChSystemSMC.h:94`에 "Note that currently MultiStep falls back to OneStep."이 있다. 51행에는 "OneStep: use only current relative tangential velocity"가 있다.
- 같은 헤더 107~110행에 "Slip velocity threshold: 이 값보다 접선 상대 속도가 작으면 접선력을 만들지 않는다"가 있다.
- 기본 접촉력 계산 `ChDefaultContactForceTorqueSMC::CalculateForceTorque`의 인자에는 접촉 이력이 없다(`ChContactSMC.h:45`).
- 구현(.cpp)은 설치본에 없다. 그래서 OneStep의 정확한 식은 확인하지 못했다. 아래는 **추정**이다: $\delta_t = v_t\Delta t$, $F_t = -k_t\delta_t - g_t v_t$.

결과: 세 모델 모두 접촉에 **정지 마찰 스프링이 없다.** 접선력은 속도에 비례하는 점성력 $c_{eq} = k_t\Delta t + c_t$만 남는다.

| 영향 | L1 | L2(강체 가이드) / L2b(부싱) |
|---|---|---|
| 접선 강성 | $k_t$(다리 굽힘 ⊕ 콘크리트)가 **사라진다** | 접촉 $k_t$가 사라진다. **L2b 부싱은 접촉과 직렬이라 접촉이 점성뿐이면 직렬 합도 점성뿐이다.** 부싱은 다리 횡유연성을 표현할 뿐 stick을 대신하지 못한다 |
| 수평 지면 동특성(상단) | 1차·2차 로킹 1.785 / 2.984 Hz(ζ 0.013 / 0.023) → **3.06 / 4.16 Hz(ζ 0.15 / 0.06)**. surge·sway·yaw는 0 Hz 표류(과감쇠)가 된다. V7이 +72 % / +39 % 어긋난다 | 같은 경향이다(횡 구속이 사라짐) |
| 수평 지면 정적 하중 | 영향 없다(스위블이라 정적 접선력 ≈ 0) | 같음 |
| 2° 경사 | 기계 전체가 미끄러져 내려간다. 추정 속도 $W\sin\alpha/\Sigma c_{eq}$ = 13.3 kN / 1.22×10⁵ N·s/m ≈ **0.11 m/s**. 0.1 mm까지 1 ms다. V12(미끄럼 < 0.1 mm)는 성립하지 않는다 | 13.3 kN / 7.75×10⁵ ≈ 0.017 m/s. 0.1 mm까지 6 ms다 |
| 슬립 속도 문턱 | 정지에 가까울수록 접선력이 0이 되어 표류가 계속된다 | 같음 |

구현 선택지(Chrono 모델은 cad-expert 몫, 판정은 이 문서와 `dynamics_model.md` 5절):

| 방법 | L1 | L2b | 비고 |
|---|---|---|---|
| (a) 지면 고정 접선 부싱 | 패드가 처음 닿을 때 볼 중심 아래 접촉점과 지면(고정 바디) 사이에 x, y 방향 부싱을 붙인다. $k$ = L1 $k_t$, z 강성 0. 접촉 $k_t$는 0에 가깝게 둔다. 항복을 μN으로 두려면 `ChLoadBodyBodyBushingPlastic`의 축별 항복을 매 스텝 접촉력으로 갱신한다(상자형이라 원형 Coulomb과 대각 방향에서 최대 √2 차). 부상하면 강성을 0으로 한다 | 같은 방법이다. 부싱 강성 = 콘크리트 접선 $k_c$(또는 부싱과 합친 값) | 일반 접촉 대신 Python 이벤트 로직이 필요하다. 강체 지면에만 쓴다 |
| (b) NSC 접촉 | **쓸 수 없다**(강체 모터 + 강체 접촉이면 하중이 부정이다) | **쓸 수 있다.** 수직 유연성은 기름 스프링에, 횡유연성은 부싱에 있으므로 4점 하중이 정해진다. NSC 마찰은 정지를 정확히 표현한다. 콘크리트 유연성은 축 스프링에 직렬로 합친다(합친 L2b의 로킹 1.785 / 2.989 Hz로 원래 L2b와 같다) | 로드 국부 모드가 70 Hz로 내려가 $\Delta t$ 약 2×10⁻⁴가 가능하다. NSC 하중 정확도는 V1로 확인한다 |
| (c) 사용자 접촉 콜백 | `ChContactForceTorqueSMC`를 상속해 접선 변위를 직접 적분한다. 인자에 이력이 없으므로 (objA, objB) 키로 외부 저장해야 한다 | 같음 | 가장 일반적이지만 구현 부담이 가장 크다 |
| (d) 수평 지면만 OneStep 허용 | 정적 하중은 맞다. 동특성(V7)과 표류는 틀린다 | 같음 | 제어기 검증용으로는 부족하다(IMU가 보는 진동 대역이 달라진다) |

권고:
- **L1은 (a)로 구현한다.**
- **L2b는 (b)를 우선 검토한다.** (b)는 L2b 쪽이 접선 문제를 더 깔끔하게 푸는 이유이기도 하다.
- 어느 쪽이든 먼저 Chrono에서 단순 시험을 해서 실제 거동을 확인한다. 예: 블록 하나를 2° 경사에 놓고 10 s 동안 미끄럼을 보고, MultiStep과 OneStep 설정을 비교한다(cad-expert).

## 5. 결론과 선택지

**판정: 조건부 가능.**
- 필요한 입력은 지금 모두 채울 수 있다.
- L1 대비 새 가정은 감쇠 분배(#11, #12) 두 가지이고 둘 다 근거가 없다.
- 이득(신장 의존 강성, SCM, 마찰 수용성)은 실제로 있다. 하지만 그 크기는 β·마찰 불확도보다 작거나 같은 수준이다.

전제 조건:
1. 접선 stick을 구현해야 한다(4절 (a) 또는 (b)). L1도 마찬가지다.
2. L2를 쓸 때 최소 가정 세트와 감도 범위를 아래 표로 정한다.

| 가정 | 기본 | 감도 범위 |
|---|---|---|
| $\beta_{eff}$ | 1.0 GPa | 0.69 ~ 1.6 GPa(기존 결정) |
| $L_0$ | 0.05 m | 0 ~ 0.15 m |
| 로드측 챔버 | 무시(플런저) | 잠금·가압 시 강성 +12 % |
| $c_{oil}$ | heave ζ 0.05 역산 | ζ 0.02 ~ 0.10, V7 실측으로 맞춤 |
| 로드 국부 ζ | 0.3(수치 위생) | 고정, 결과 영향 확인만 |
| 실 마찰 $F_s$ | 0 | **0 / 2 / 5 / 12 kN** |
| 누설 | 0 | 0.25 ~ 0.5 mL/min(장시간 유지 시험만) |

| 선택지 | 내용 | 얻는 것 | 놓치는 것 / 비용 |
|---|---|---|---|
| A. L1 유지 | 현행대로. 보완: 접선 부싱(4절 a), 가상 스트로크 = 모터 위치 − $F/k_{oil}$, 누설은 모터 위치 외란, 큰 경사 시험에서 $k_n$을 레벨링 신장값으로 다시 넣음(L1u) | 가장 싸다(Δt 2×10⁻⁴). 자세 ±0.2°(옛 ±0.1°) 검증에 충분하다 | 실 마찰(압력 판독 오차·이력·잠김 강성)을 볼 수 없다. SCM과 함께 쓸 수 없다. 신장 변화 중의 강성 변화(≤ 25 %)를 따라가지 못한다 |
| **B. L1 기본 + L2b 병행(추천)** | 제어기 개발과 회귀 시험은 L1. L2b(+ 선택적 마찰 항)를 검증 모델로 추가해 큰 경사, SCM, $F_s$ 감도에서 같은 제어기를 다시 판정 | L1의 속도를 유지한다. $F_{min}$ 판정의 가장 큰 미지수(마찰)와 SCM을 다룰 수 있다. 4절 (b)를 쓰면 L2b도 Δt 2×10⁻⁴ 수준이 가능하다 | 모델 2개를 관리해야 한다. L2b 검증 기준(V1~V13 L2 열)을 함께 유지해야 한다 |
| C. 지금 L2b로 전환 | 기본 모델을 L2b로 바꾼다 | 단일 모델로 SCM까지 쓴다 | 같은 무근거 가정 위라 신뢰도 이득이 없다. SMC 콘크리트 접촉이면 스텝이 4배다. 구현·안정성 부담이 지금 제어기 개발 단계에 들어온다 |

**추천: B.** 근거:
1. 자세 ±0.2°(옛 ±0.1°)는 L1과 L2의 차이에 민감하지 않다. 제어 대역에서 압력 응답 차가 2.4×10⁻⁵ 이하이고, 정상상태는 적분 제어가 맞춘다.
2. $F_{min}$ 판정의 지배적 불확도는 β(−29 ~ +51 %)와 실 마찰(±$F_s$)이다. 후자는 L2 구조에서만 시험할 수 있다.
3. SCM 시나리오가 CLAUDE.md 범위에 있다. 그 시나리오에서는 어차피 L2가 필요하다.
4. OneStep 문제로 L1도 접선 구현을 다시 해야 한다. 이때 L2b는 NSC로 이 문제를 더 깔끔하게 풀 수 있다.

결정은 사용자가 한다.
