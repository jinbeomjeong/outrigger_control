# 10_rpi_migration — 라즈베리파이 제어기 이식 (검토 단계)

이 폴더는 최종 제어기(R8 C2 + L1gs + DSb75 + SGS any_loc + R4c30, `03_src/outrigger_sim/control/c2.py`)를 라즈베리파이 같은 임베디드 제어기에서 Python으로 돌리기 위한 작업 공간이다. 하드웨어 드라이버와 실시간 실행은 본 프로젝트(시뮬레이션) 범위 밖이므로, 여기서 하는 일은 **사전 검토와 이식 준비**로 한정한다. 시뮬레이션 코드(`03_src`)와는 따로 둔다.

## 현재 상태 (2026-10-30, control-expert 검토)

판정은 **조건부 가능**(Python 기반)이다.

- 의존성: 제어기 import 사슬에 필요한 외부 패키지는 numpy와 PyYAML뿐이다. aarch64 휠은 있고, numpy 2.5는 cp313 휠만 있다. Python 3.11 이상이 필요하다(`StrEnum`). 제어기는 `Measurements`와 `Params`만 읽는다.
- 계산량: PC E코어 1개에서 다른 계산과 경합하며 잰 한 주기는 평균 1.9~2.3 ms, p99 2.7~3.4 ms, 최대 8 ms다.
  - Pi 5로 환산하면 100 ms 주기의 25 % 이하이고, Pi 4로 환산하면 65 % 이하다. 두 값 모두 추정이다.
  - 100 Hz IMU 필터는 10 Hz `update` 안에서 10샘플씩 몰아 계산한다.
- 결정성: 같은 플랫폼에서 측정값을 재생하면 명령 해시가 같다. PC(x86 MKL)와 Pi(aarch64) 사이에서는 비트까지 같다고 보장할 수 없다. 그래서 허용 오차 기반 재생 시험을 쓴다.

## 이식 조건

1. 출력 타이밍(d = 1): 제어기가 버퍼에 넣기 전 출력을 노출하는 API를 두고, 다음 틱에 출력하는 래퍼를 만든다.
2. 신호 정의(사용자 결정 필요): `stroke_m`과 `stroke_corrected_m`이 실기 행정 센서에 어떻게 대응하는지 정한다. IMU 10 ms 평균, 하드웨어 타임스탬프, 군지연도 정한다(U-R8-9 ⑤).
3. 안전 기능은 Linux 밖에 둔다. 하드웨어 워치독, 밸브 중립 인터록, 비상 정지, 압력·행정 하드 한계는 별도 MCU나 모바일 컨트롤러에서 맡고, Pi와는 CAN으로 잇는다.

권장 구성: Pi 5 + PREEMPT_RT, 격리 코어, `SCHED_FIFO`, `mlockall`, GC 수동 관리(`gc.freeze`·`gc.disable`, 주기 밖에서 `collect`). 그 위에서 CPython 3.13 + numpy로 C2를 10 Hz로 돌린다.

## 이행 작업 (규모는 추정)

| # | 작업 | 규모 |
|---|---|---|
| 1 | 제어기 패키지 분리: control, 필터·면적·상수만 담고 잡음 모델과 하네스는 뺀다. Params는 고정 설정으로 내보낸다 | 2~4일 |
| 2 | d = 1 실기용 출력 API와 틱 래퍼 | 1일 |
| 3 | 신호 정의 결정(명세 1절) | 사용자 결정 |
| 4 | 크기 제한 없는 이벤트·이력 리스트에 상한 두기 | 0.5일 |
| 5 | aarch64 동치 시험: PC 측정값을 Pi에서 재생, aarch64 기준 해시 생성 | 2~3일 |
| 6 | Pi 5 실측: 전체 프리셋의 p99·최대, `cyclictest` | 1~2일 |
| 7 | 실시간 실행 래퍼: 수집 스레드, 하트비트 | 3~5일 |
| 8 | HIL: PC numpy 플랜트와 Pi를 CAN으로 연결, 지연·지터 주입 | 1~2주 |
| 9 | I/O·안전층 사양 | 범위 밖(하드웨어) |

## 폴더 구성 (예정)

- `docs/`: 검토 보고, 신호 정의, 실시간 설계
  - `docs/controller_block_diagram.{graphml,png,svg}`: 최종 제어기 블록 다이어그램(yEd 원본과 미리보기, 설명은 `docs/README.md`)
- `ctrl_pkg/`: 분리한 제어기 패키지(작업 1). 원본은 `03_src`이고 여기에는 내보내기 결과만 둔다
- `runtime/`: 실시간 실행 래퍼(작업 2·7)
- `replay/`: 측정값 기록과 재생 동치 시험(작업 5)
- `bench/`: Pi 실측 스크립트와 결과(작업 6)

아직 코드는 없다. 작업을 시작하면 하위 폴더를 만든다.
