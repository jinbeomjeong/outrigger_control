# 제어기 블록 다이어그램 구성 요소

`controller_block_diagram.{graphml,png,svg}`에 나오는 블록 49개를 그룹별로 정리했다. 블록마다 이름과 역할을 한 줄로 적는다. 대상 제어기는 최종 구성(R8 C2 + L1gs + DSb75 + SGS any_loc + R4c30)이고, 코드는 `03_src/outrigger_sim/control/c2.py`, 명세는 `00_docs/04_control/s6_control_spec.md`다. 수치는 R8 프리셋(`C2Config().with_10hz_d1()`) 기준이다.

## 입력 (센서·명령)

| 블록 | 역할 |
|---|---|
| IMU (비력·각속도) | 상부 프레임에 단 IMU다. 비력과 각속도를 100 Hz로 주며, 제어 주기마다 10표본을 넘긴다 |
| 실린더 압력 | 다리 4개의 헤드·로드 압력을 10 Hz로 재며, 다리 힘 계산과 접지 판정의 기본 입력이다 |
| 행정 센서 × 4 | 실린더 내장 행정 센서다. 10 Hz로 다리 신장 길이를 준다 |
| 목표 자세 | 운전자가 요청한 roll·pitch 목표다(보통 0). `request_target`으로 들어온다 |

## 신호 처리 (Pi에서 실행, IMU 100 Hz·압력·행정 10 Hz)

| 블록 | 역할 |
|---|---|
| 자세 계산·필터 | 비력으로 roll·pitch를 계산하고 2차 저역통과(τ 0.8 s × 2단)를 100 Hz로 걸어 진동 성분을 걸러 낸다 |
| 자이로 바이어스 제거 | CHECK 단계에서 정지 상태로 추정한 자이로 바이어스를 각속도에서 뺀다 |
| 압력 영점 교정 | CHECK 단계에서 다리를 ±3 mm 왕복시켜 압력 센서의 영점 오차를 교정한다 |
| 실린더 순 힘·센서 진단 | F = p_h·A_p − p_r·A_ann으로 다리 힘을 구하고, 압력 센서 고장(헤드·로드)을 진단한다 |
| 행정 보정 | 유압유 압축 변위를 뺀 행정(보정 행정)을 만든다. 센서 값이 있으면 그것을 쓴다 |

## 판정·추정 (10 Hz)

| 블록 | 역할 |
|---|---|
| 목표 수용 판정 | 목표 자세가 허용 범위 안인지 검사하고(A0–A5, 마름모 규칙), 기준 램프를 만든다 |
| 접지 판정 + 탐침 | 압력·행정·IMU를 결합해 다리 접지를 판정하고, 자세 변화 ±0.1° 안의 탐침으로 접지를 확인한다 |
| 크롤러 틈 추정 | 로드 행정으로 크롤러 바닥과 지면 사이 최소 틈(c_min)을 추정한다 |
| LOC 크롤러 이탈 확인 | 10 mm 창에서 다리 하중 합 상승이 2 kN 이하로 평탄해지면 크롤러가 땅에서 떨어진 것(LOC)으로 확정한다 |
| 토양 모드 | 크롤러 영역 규칙이 LOC 전에 풀리면 연약 지반 대응 모드로 들어가 유지한다 |

## 상태 기계 (C2Phase, 10 Hz)

| 블록 | 역할 |
|---|---|
| CHECK | 시작 전에 정지 확인, 압력 영점 교정, 자이로 바이어스 추정을 한다 |
| IDLE | 목표가 거부됐을 때 대기한다 |
| TOUCH | 다리를 내려 지면에 접근하고 접지를 잡는다 |
| LEVEL | 상부체를 들어 올리면서 자세를 목표로 맞춘다(들어 올림도 이 단계에 포함) |
| DONE | 자세가 완료 데드밴드(0.03°) 안에 들어온 상태다 |
| PROBE | 다리별 탐침으로 모든 다리의 접지를 확인한다 |
| REANCHOR | 앞내림 조건에서 고착점을 다시 잡는다(H4) |
| READY | 레벨링을 마치고 잠금을 유지하는 작업 가능 상태다 |
| FAULT_REGROUND | 고장이 났을 때 뜬 다리를 다시 접지시킨 뒤 FAULT로 간다 |
| FAULT | 모든 다리를 멈추는 고장 정지 상태다 |
| 단계 경로 명령 | LEVEL 밖 단계(TOUCH, 영점 왕복, 탐침, REANCHOR, 재접지)의 다리 명령을 만든다 |

## 제어 법칙 (LEVEL 단계, 10 Hz)

| 블록 | 역할 |
|---|---|
| 자세 PI (조건부 적분) | roll·pitch 오차로 다리 속도를 만드는 PI 제어기다(Kp 0.2 s⁻¹, Ki 0.01 s⁻², 포화 때 적분 멈춤) |
| heave 틈 제어 | 상부체 높이(크롤러 틈)를 목표로 맞추는 heave 채널이다(Kz 0.5, τ_z 0.2 s) |
| 비틀림 | 4점 지지의 비틀림 하중을 줄여 대각 다리 하중을 고르게 한다(Ktw 0.5 s⁻¹) |
| 가드 (하중 하한 F_min) | 다리 하중이 F_min 근처로 내려가면 그 다리를 보호하는 보정 속도를 더한다(K_g 0.15 s⁻¹) |
| 다리 속도 합성·v_max 스케일 | 자세·heave·비틀림·가드 성분을 다리 4개 속도로 합치고, 최대 속도를 넘지 않게 비례 축소한다 |
| 크롤러 영역 규칙 | 크롤러가 떨어지기 전에는 다리를 수축시키지 않고 들어 올리기만 한다 |
| 재접근 | 하중이 1.4 F_min 아래로 떨어진 다리를 다시 지면에 붙인다(비틀림 모드) |
| LOC 전 느린 들어 올림 | LOC 전에 다리 하중이 빠르게 떨어지면 들어 올림 속도를 잠시 줄인다(P-S8-30) |
| R-5 하중 하락 예측 | 4주기 앞의 다리 하중 하락을 예측해 미리 재레벨을 시작한다 |

## 최종 구성 추가 규칙 (그림에서 빨간 테두리)

| 블록 | 역할 |
|---|---|
| L1gs: LOC 사후 취소 | LOC 뒤 하중 합이 계속 오르면 거짓 LOC로 보고 취소한다(P-S8-33) |
| DSb75: 차등 침하 보상 | LOC 뒤 한쪽이 가라앉으면 가라앉는 쪽 다리에 보상 속도를 더한다(P-S8-35) |
| 행정 예산 가드 | 다리 행정이 682.8 mm에 닿으면 네 다리를 같이 낮추거나 멈춘다(P-S8-28, R8 기본 규칙) |
| SGS any_loc | LOC 뒤 행정 가드가 처음 작동하는 주기에 바로 안전 정지(FAULT_LIFT_STROKE_LIMIT:soil)한다(P-S8-36) |
| R4c30 | 평지 토양에서 LOC 때 크롤러 틈 목표를 +30 mm(50 → 80 mm) 높인다(P-S8-37 R4, 논문 R9) |

## 출력 (10 Hz, d = 1)

| 블록 | 역할 |
|---|---|
| 행정 끝 자르기·감속 | 행정 양 끝에 가까워지면 속도를 줄이고 끝을 넘는 명령을 자른다 |
| 증분 제한 | 주기당 명령 변화량을 0.25 v_max로 제한한다. FAULT일 때는 즉시 0으로 만든다 |
| 출력 지연 버퍼 d = 1 | 계산한 명령을 한 주기 늦춰 낸다(실기에서는 다음 틱에 출력) |
| 다리별 속도 명령 × 4 | FL·FR·RL·RR 다리의 최종 신장 속도 명령이다 |
| 사건·FAULT 로그 | INFO·WARN·FAULT 사건을 기록한다(C2Event) |

## I/O·안전층 (MCU, 프로젝트 범위 밖)

| 블록 | 역할 |
|---|---|
| 밸브 구동 | 속도 명령을 밸브 전류로 바꾸고 앰프 램프(≤ 0.1 s)를 건다 |
| 하드웨어 워치독 | Pi 하트비트가 끊기면 밸브를 무여자(중립)로 만든다 |
| 밸브 중립 인터록·비상 정지 | 비상 정지 때 밸브 전원을 하드와이어로 끊어 중립·잠금 상태로 둔다 |
| 압력·행정 하드 한계 | 압력(350 bar)과 행정 끝을 Pi와 독립적으로 감시해 넘으면 멈춘다 |

|---|---|
| 밸브 × 4 | 다리마다 비례 방향 밸브와 파일럿 체크 잠금 밸브로 실린더를 구동하고 정지 시 잠근다 |
