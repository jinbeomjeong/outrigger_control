# 성능 확보 주제별 체크리스트 (2026-10-22, 갱신 2026-10-25 S8 마감)

프로젝트 성능을 확보하는 데 필요한 일을 7개 주제로 나누고, 주제마다 세부 항목을 체크리스트로 정리했다.
- **단계 체크 상태의 원본은 계획 문서 [03_chrono/chrono_build_plan.md](03_chrono/chrono_build_plan.md) 체크리스트이고, [00_roadmap.md](00_roadmap.md) 4절이 같은 상태를 보여 준다.** 이 문서는 그 항목을 성능 목표(자세 정확도 ±0.2°, 모든 다리 접지·$F_{min}$ 여유, 압력·힘 한계, 레벨링 시간) 기준으로 다시 묶은 **점검표**다. 두 문서가 다르면 로드맵이 맞다. Chrono 구축 계획은 [03_chrono/chrono_build_plan.md](03_chrono/chrono_build_plan.md)를 따른다.
- 표기: `[x]` 완료, `[ ]` 남음, `⏸` 보류(사용자 방침), `(사용자)` 사용자 결정·자료 제공이 필요한 항목.
- 근거 문서: 제어 명세 [04_control/s6_control_spec.md](04_control/s6_control_spec.md)(개정 1~56, 현행 R8 C2 원본은 개정 30·136절 이후), 동역학 [01_dynamics/dynamics_model.md](01_dynamics/dynamics_model.md)(개정 43), 유압 [02_hydraulic/hydraulic_circuit.md](02_hydraulic/hydraulic_circuit.md)·[02_hydraulic/s8_seal_friction_counterbalance.md](02_hydraulic/s8_seal_friction_counterbalance.md), 결정 [decision_log.md](decision_log.md).
- 현재 위치(2026-10-25): S0~S8 완료(S8은 4/6, D2·V17 보류, U-S8-58). 다음은 S9(SCM 파라미터 확보 전에는 보류).
- 2026-10-22판(S6 R5 시점)에서 바뀐 것: 제어기 R5 → **R8 C2**(10 Hz, d = 1), 힘 추정 헤드측만 → **헤드·로드 두 압력 순 힘**, 속도 22.67 → **20.924 mm/s**, 실린더 REXOME35 치수·다리별 힘 한계, S7 L2b-NSC·S8 실 마찰·카운터 밸런스·V15·ML 비교 완료. R5 시점 항목은 이력으로 남기고 "(R5 이력)"을 붙였다.
