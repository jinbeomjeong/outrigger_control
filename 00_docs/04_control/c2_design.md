## 3. 루프별 플랜트

### 3.1 준정적 구조

모든 패드가 접지하면 준정적 관계는 다음과 같다.

$$\dot s=u,\qquad q_o=J_K s,\quad J_K=(A^TKA)^{-1}A^TK,\qquad \Delta F = S\,\Delta s,\quad S=K-KAJ_K$$

$u=[A\;n]v$를 넣으면 $J_KA=I_3$(어떤 $K$에서도)이고 $SA=0$이다. 그래서

$$\begin{bmatrix}\dot u_z\\\dot\phi\\\dot\theta\\ n^T\dot F\end{bmatrix}=\begin{bmatrix}I_3 & J_Kn\\ 0 & n^TSn\end{bmatrix}v$$

| 기호 | 뜻 |
|---|---|
| $K$ | diag(패드 수직 강성 $k_{v,i}$) |
| $J_Kn$ | 비틀림 명령이 자세로 새는 양(같은 강성이면 0) |
| $n^TSn$ | 비틀림 강성(같은 강성이면 $k$) |

**결합은 삼각형이다.** 자세·heave 명령은 비틀림 하중을 바꾸지 않는다(수치 $\lVert n^TSA\rVert/\lVert S\rVert$ = 8×10⁻¹⁷, 연약 패드 3×10⁻¹⁶). 비틀림 명령만 자세를 조금 바꾼다. 안정성은 대각 루프가 정하고, 비대각은 외란일 뿐이다.

## 6. 비선형: 포화·안티와인드업·기술함수

### 6.1 속도 포화 방향

C2는 벡터 스케일($\max|u_i|>v_{max}$이면 $u\leftarrow u\,v_{max}/\max|u_i|$)을 쓴다. 다리별 자르기와 비교(초기 명령, $K_p$ 0.4, heave 25 mm/s):

| 경사 | 비틀림 속도: 스케일 / 자르기 [mm/s] | 비틀림 하중 속도(자르기) [kN/s] | 자세 속도 비 roll / pitch(스케일 → 자르기) |
|---|---|---|---|
| roll +3° | 0 / −0.52 | −10.9 | 0.43 → 0.45 |
| 대각 3° | 0 / **14.8** | **310** | 0.29 / 0.29 → 0.36 / 0.44(방향 틀어짐) |
| roll +5.7° | 0 / 1.50 | 31.5 | 0.29 → 0.44 |
| pitch +3, +3.7° | 0 / 0 | 0 | 대칭이라 같음 |

다리별 자르기는 대각 경사에서 비틀림 하중을 초당 310 kN 쌓는다(비틀림 루프가 1 s⁻¹로 따라가도 ±300 kN 수준 → $F_{min}$ 위반). **벡터 스케일은 필수**다. 크롤러 하중 구간의 "순수 heave 더하기"도 스케일 뒤에 다시 스케일한다(구현 명세 4.6).

### 6.2 안티와인드업

자세 PI는 조건부 적분이다: $0.01°<|e|<0.2°$일 때만 $I\leftarrow I+eT$, $|I|\le0.02$ rad·s. 포화는 오차 1.3°(pitch) ~ 2.5°(roll) 이상에서만 생기므로(분해 채널 하나가 $v_{max}$에 닿는 오차 = $v_{max}/(K_p\max|A_{ij}|)$), 포화 구간에서는 적분이 항상 멈춰 있다. 적분 기여 상한 $K_i|I|$ = 4×10⁻⁴ rad/s = 0.023°/s다.

포화를 이득 $\kappa\in(0,1]$로 보는 기술함수 점검: 루프 이득을 0.001~1배로 줄인 61개 경우 모두 폐루프 안정(스펙트럼 반경 − 1 ≤ −2.1×10⁻⁶, 상단 강체·마스트 하한·크롤러 위). **포화 한계 사이클 없음**.

### 6.3 기술함수

| 비선형 | 위치 | 판정 |
|---|---|---|
| 비틀림 데드밴드 2 kN | $n^TP$ 오차 | DF는 [0, 1)의 실수. 위상 교차에서 $|L|$ ≥ 1이 있어야 한계 사이클. 비틀림 루프 GM 50배(34 dB) → **없음** |
| 속도 포화 | $u$ | 6.2절 → **없음** |
| 실 마찰(backlash) | 다리 길이 ↔ $s_{ref}$, 반폭 $F_s/k_{oil}$. 자세 환산 반폭 $b=\sum|J_{\phi,i}|F_s/k_{oil,i}$ | 아래 표 |

실 마찰 backlash와 자세 루프(다른 루프 닫음, 수치 DF: 사인 입력의 1차 고조파):

| $F_s$ | 반폭 roll / pitch [°] | PI: 한계 사이클(안정, Loeb) | 자세 진폭 roll / pitch [°] | 불안정 한계 사이클(문턱) | P만 |
|---|---|---|---|---|---|
| 2 kN | 0.0039 / 0.0020 | 0.72 rad/s, 주기 8.8 s | 0.0029 / 0.0015 | 0.10 rad/s(주기 63 s) | 없음 |
| 5 kN | 0.0097 / 0.0051 | 같음 | 0.0073 / 0.0038 | 같음 | 없음 |
| 12 kN | 0.0233 / 0.0122 | 같음 | **0.0176 / 0.0092** | 같음 | 없음 |

- 적분기 + 적분 플랜트 + backlash의 전형적 사냥이다. 진폭이 완료 데드밴드 0.03°보다 작아서 완료 판정(완료 신호 < 0.03°, 1 s)이 성립하고 래치가 다리를 잠근다. 시간 응답(8절, $F_s$ 12 kN)에서도 정상 오차 ≤ 0.033°였다.
- 데드밴드를 0.03° 아래로 줄이거나 적분 동결 구간(0.01°)을 넓히지 않는 한 문제없다. 데드밴드를 줄이게 되면 **$K_i$ = 0 또는 적분 동결 구간 ≥ 0.02°**를 함께 바꾼다.
- 완료 0.03° / 재레벨링 0.07° 히스테리시스 사이에서는 다리가 잠겨 있으므로 감시 단계에 사냥이 없다.

## 7. LQR/LQG 비교 기준

| 항목 | 값 | 해석 |
|---|---|---|
| 준정적 LQI(Bryson: 자세 0.2°, 채널 최대 속도 = $v_{max}/\max|A_{ij}|$) | $k$ = 4.91 s⁻¹(roll), 2.54 s⁻¹(pitch) | 구조는 대각 P(I) = C2와 같다. 대역만 C2의 6~12배. 3.3절대로 필터 없이는 불안정하고 2차 필터로는 GM이 남지 않는 값이다 → **대역은 액추에이터가 아니라 로킹·IMU가 정한다** |
| 이산 LQG(동적 6자유도, 상단 강체 설계, 측정 = IMU 2 + 압력 4 + 스트로크 4, **가정** 잡음) $\rho$ = 1 | 지배 극 1.33 rad/s, 다리 입력 디스크 α 0.84, $M_s$ 1.68 | 더 빠르지만 여유가 작다 |
| 같은 LQG $\rho$ = 30 | 지배 극 0.24~0.47 rad/s(C2와 같은 대역), α **1.17**, $M_s$ 1.33 | 공칭에서는 C2(α 1.04, $M_s$ 1.39)보다 조금 낫다 |
| 같은 LQG $\rho$ = 1000 | 0.042 rad/s, α 1.68 | 느림 |
| LQG(세 가중 모두)를 유연 마스트 하한 플랜트에 적용 | 스펙트럼 반경 1.0008 / 1.0005 / 1.0001 → **불안정** | 모델 기반 관측기가 로킹 진동수(−49 %)를 잘못 알면 무너진다 |
| C2 | 82개 플랜트 모두 안정, α ≥ 1.03 | 모델 없이(기구학 $A$, $n$, $k_{nom}$만) 같은 대역에서 강인하다 |

결론: C2는 같은 대역의 LQG에 비해 공칭 여유가 약 10 % 작고, 플랜트 불확도(마스트·β·감쇠)에는 훨씬 강하다. 마스트 지지 강성(Q-B1·Q-B3)이 정해지기 전에는 모델 기반 동적 제어(C5)로 옮길 이유가 없다([control_candidates_comparison.md](control_candidates_comparison.md) 1절 C5 판단과 같은 결론을 정량으로 확인).

- 평형을 만족하는 모든 하중은 $F=F_{eq}+n\,t$($F_{eq}$ = 같은 강성 분배)다. 그래서 $n^TF=0$이면 **패드·지면 강성과 무관하게** $F=F_{eq}$다. 연약 FL에서 수동 스프링 분배는 96.2 / 138.3 / 96.9 / **46.7** kN($n^TF$ = −46.3 kN)이고, 비틀림 루프가 이를 70.9 kN 최소로 되돌린다.
- 최소 하중 최대화는 최소를 0.9 kN(1.3 %)만 올리면서 무게중심 xy와 두 다리 하중 동일 판정이 필요하다.
- **권고: $n^TP\to0$ 유지 + $F_{min}$ 가드(우선순위)**. 최소 하중 최대화는 무게중심 xy가 크게 치우친 미래 운용(작업 하중 등)이 생기면 다시 본다.

### 10.2 실 마찰 설계 띠 $F_{band}$ (D5)

| $F_s$ | 비틀림 판독 오차 최대 $\sum|n_i|F_s$ | 다리 하중 오차 최대(루프 수렴 뒤) | 가드 하한이 실제 하한이 되려면 $F_{band}$ ≥ |
|---|---|---|---|
| 0 | 0 | 0 | 0.9 kN(3σ 압력 잡음) |
| 2 kN | 4.0 kN | 2.1 kN | 2.9 kN |
| 5 kN | 10.0 kN | 5.2 kN | 5.9 kN |
| 12 kN | 24.0 kN | 12.5 kN | 12.9 kN |

- 압력 판독 $P=F-f$, $|f|\le F_s$이므로 실제 실린더 힘의 하한은 $P-F_s$다. 가드가 놓치지 않으려면 $F_{band}\ge F_s+3\sigma_P$.
- 가드가 동작하는 판독 = $F_{min}$ + 5 kN + $F_{band}$: 14.5(0) / 16.5(2) / 19.5(5) / 26.5(12) / 27.5(13) kN. 레벨링된 상태의 최소 판독(≈ 58~71 kN)과 멀어 오작동하지 않는다. 레벨링 중 과도 최소(시간 응답 18~25 kN, 상단 대각 3°·pitch +3.7°)에서는 $F_{band}$ 12~13 kN이면 가드가 걸릴 수 있다(결합 판정으로 기본 행렬을 돌리지는 않았다. 결합 판정 실행은 수평·roll +3°만이고 모두 통과, 8.2절. S6 확인 항목).
- **권고: $F_{band}$ = 13 kN(설계 상한 12 kN + 3σ)으로 시작.** 탐침으로 줄이는 것은 탐침 $F_s$ 추정 정확도(현재 참값 0에 −4.7~17 kN, [control_candidates_comparison.md](control_candidates_comparison.md) 5.4절)가 ±2 kN 수준으로 검증될 때까지 하지 않는다. 그 전에는 탐침 결과로 **늘리기만** 허용한다($F_{band}\leftarrow\max(F_{band},\hat F_s+1\,\mathrm{kN})$).

### 10.3 탐침 빈도 (D4)

- 실 마찰은 판독이 실제를 따라가지 못하게 한다. 이것은 다리가 잠긴 채 하중이 바뀔 때(침하·외란) 생긴다. C2는 비틀림 루프가 움직이는 동안 판독을 다시 실제 쪽으로 끌어오므로 압력만으로도 침하를 회복했다(8절 settle, [control_candidates_comparison.md](control_candidates_comparison.md) 5.3절).
- **권고**: (1) 레벨링 완료 뒤 1회(6.1 s, 기존 C2 접지 후 시간의 약 35 %)는 기본 절차에 넣는다. 압력만으로는 확인할 수 없는 "뜬 다리"를 증분 강성으로 확정하는 유일한 수단이다. (2) 감시 단계에서는 트리거 때만: 재레벨링 뒤, 저하중 추정($P-F_{band}<F_{min}$ + 3 kN), D2 외란 사건 뒤, 자세 > 0.07°. (3) 주기적 탐침은 현재 근거가 없어 넣지 않는다(실기 침하 속도 자료가 생기면 다시 본다).

### 14.3 매 주기 순서 ($k$, $T$ = 0.02 s)

1. 측정 읽기 → 2. 필터 → 3. 단계 논리 → 4. 레벨링 명령 → 5. 출력 램프. 식은 다음과 같다($a$ = $T$/0.5 = 0.04, $b$ = $T$/1.0 = 0.02, $c$ = $T$/0.2 = 0.1).

$$\phi_{1,k}=(1-a)\phi_{1,k-1}+a\,\phi_{acc,k},\quad \phi_{f,k}=(1-a)\phi_{f,k-1}+a\,\phi_{1,k},\quad \phi_{s,k}=(1-b)\phi_{s,k-1}+b\,\phi_{f,k}$$

(θ도 같다. 순서대로 갱신 — 둘째 단은 이번 주기의 첫째 단 값을 쓴다.)

(R1) 크롤러 구간 규칙용 저역 압력은 모든 단계(TOUCH 포함)에서 매 주기 $\bar P_k=(1-c)\bar P_{k-1}+c\,P_k$로 갱신한다(첫 측정값으로 초기화, $c$ = 0.1).

### 14.4 TOUCH

- 접지 하중 조건 $C_i$: 압력만 $P_i\ge1.5F_{min}$; 결합 $P_i-P_{air,i}-W_{rod}\ge1.5F_{min}$($W_{rod}$ 1047.2 N).
- **(R1) 접지 확인 유지 시간** $t_h$ = 0.5 s: $C_i$가 처음 참이 된 시각을 후보 시작으로 두고, $C_i$가 연속으로 참인 채 $t-t_{cand,i}\ge t_h-10^{-9}$ s가 되면 `touched[i]` 래치. $C_i$가 한 번이라도 거짓이면 후보를 지운다.
- **(R1) 접근 감속**: $C_i$가 한 번이라도 참이었던 다리(`touch_seen[i]`)는 미접지일 때 $0.25\,v_{max}$로 신장한다.
- $u_i$ = 0(접지 래치 또는 후보 대기 중), $0.25v_{max}$(미접지, 본 적 있음), $v_{max}$(미접지, 처음). 네 다리 모두 래치 → LEVEL.
- 근거: 16.3절(옛 판정은 크롤러 흔들림(1.33 Hz) 정점에서 걸려 LEVEL 진입 때 전방 두 패드가 떠 있었다).

### 14.5 LEVEL (순서 고정)

1. `lifted` 래치: $c_{lr}(x)>0.01$ m.
2. 자세: $e=-\phi_f$; $0.01°<|e|<0.2°$이면 $I\leftarrow\mathrm{clip}(I+eT,\pm0.02)$; $\dot\phi_d=K_pe+K_iI$. θ도 같다.
3. heave: $\bar c\leftarrow(1-c)\bar c+c\,c_{lr}(x)$; $\dot z=\mathrm{clip}(K_z(0.05-\bar c),\pm v_{max})$. $c_{lr}(x)$ = 크롤러 상자 네 모서리 중 최소 여유(패드 평면 최소제곱 $[1,x,y]$ 맞춤, 비교 스크립트 `Ctx.clearance_est`와 같음).
4. 비틀림: $t=n^TP$; $e_t=0$($|t|<2$ kN) 또는 $t-\mathrm{sgn}(t)\,2$ kN; $\dot\tau=-K_{tw}e_t/k_{nom}$.
5. $F_{min}$ 가드: $L=P$(압력만) 또는 $P-F_{band}$(결합); $i=\arg\min L$; $L_i<F_{min}+5$ kN이면 (a) $\dot\tau\,\mathrm{sgn}(n_i)<0$이면 $\dot\tau=0$, (b) $\dot\tau\mathrel{+}=\mathrm{sgn}(n_i)K_g(F_{min}+5\,\mathrm{kN}-L_i)/k_{nom}$.
6. $u=A[\dot z,\dot\phi_d,\dot\theta_d]^T+n\dot\tau$.
7. 벡터 스케일: $m=\max_i|u_i|>v_{max}$이면 $u\leftarrow u\,v_{max}/m$(다리별 자르기 금지, 6.1절).
8. 크롤러 하중 구간(**R1 개정**): 느린 여유 추정 $\hat c_{r}=c_{lr}\big(s-\bar P/k_{oil}(s)\big)$($s$ = `stroke_m`, $\bar P$ = 상태표의 저역 압력, $k_{oil}(s)$ = `oil_stiffness_N_m`, β 1.0 GPa 공칭)로 래치를 갱신한다: `crawler_zone`이 켜져 있고 $\hat c_r\ge$ 20 mm면 끈다. 꺼져 있고 $\hat c_r<$ 10 mm면 다시 켠다. 켜져 있으면 $u\leftarrow u+\max(0,-\min_iu_i)\mathbf 1$ 뒤 다시 7. (옛 규칙: 매 주기 $c_{lr}(x)<0.02$ m. $x$의 유압 압축 항이 3 Hz 로킹을 타 릴레이가 됐다, 16.2절.)
9. 스트로크 끝 고장(**R1: `stroke_m` 기준**): $s_i\ge s_{max}-1$ mm이고 $u_i>10^{-5}$ m/s인 상태가 2 s 넘으면 FAULT(모든 $u$ = 0, 알람). (옛 명세는 $x_i$ 기준이라 하중 압축 3 mm 때문에 걸리지 않았다.)
10. 스트로크 끝 자르기(**R1: `stroke_m` 기준**): $s_i\ge s_{max}-0.1$ mm면 $u_i\le0$, $s_i\le0.1$ mm면 $u_i\ge0$.
11. 완료 판정: $|\phi_s|,|\theta_s|<0.03°$ 그리고 $|\bar c-0.05|<2$ mm 그리고 $|n^TP|<3$ kN이 1 s 지속 → DONE(이번 주기 $u$는 그대로 내보냄).

### 14.6 DONE / PROBE / READY / 감시

- DONE: 결합 판정이면 PROBE(다리마다 +2 mm(0.25 $v_{max}$) → 0.4 s 정지 → −2 mm → 0.4 s 정지, 증분 강성 > 0.3 $S_{ii}$면 접지, 하중 = 판독 중점 − $S_{ii}\Delta x/2$). 압력만이면 바로 READY. 탐침 결과로 $F_{band}\leftarrow\max(F_{band},\hat F_s+1$ kN$)$(늘리기만, 10.2절). 뜬 다리나 $F_{min}$ + 5 kN 미만이면 그 다리를 목표 하중까지 늘린 뒤 LEVEL로(최대 3회).
- READY: $u$ = 0(다리 잠금). 감시: $\max(|\phi_s|,|\theta_s|)>0.07°$ 또는 (`lifted`이고 $\min L<F_{min}$ + 3 kN)이면 LEVEL로(적분 유지, 탐침 초기화).

### 14.7 출력 램프

$$u_{out,k}=u_{out,k-1}+\mathrm{clip}(u_k-u_{out,k-1},\ \pm v_{max}T/0.1)$$

램프는 제어기 출력에 둔다(구동기 모델이 이상적이어도 가속 한계를 지키게). 엔진이 밸브 램프를 따로 구현하면(L2) 제어기 쪽 램프와 중복되지 않게 설정 하나로 끈다. 지연·ZOH는 플랜트·통신 쪽이고, 제어기 계산은 한 주기 안에서 끝나야 한다(총 추가 지연 ≤ 100 ms, 4.3절).

### 16.2 (B) 크롤러 구간 규칙: 릴레이 한계 사이클 제거

원인(3.9.7.5 (B)):
- 옛 규칙은 매 주기 $c_{lr}(x)<$ 20 mm이면 수축을 막고 순수 상승을 더했다.
- $x=s-P/k_{oil}$의 압축 항이 3 Hz pitch-surge 로킹을 그대로 싣는다.
- 앞내림 경사에서는 후방 크롤러 모서리가 바닥 근처에 남아 추정이 17~21 mm에서 맴돈다.
- 그 결과 규칙이 후방 다리를 0 ↔ −10 mm/s로 로킹 주기마다 뒤집는 **릴레이 되먹임**이 됐다.

실측 조건: it3, 상단 앞내림 3.5° / 3.7°, 강체, 지연 0. 크롤러 이탈 뒤 15 s 동안의 2~4.5 Hz 대역 통과 성분이다(스크래치 진단).

| 추정 | 3 Hz 성분 첨두-첨두 [mm] | 비고 |
|---|---|---|
| 원 추정 $c_{lr}(x)$(옛 규칙) | 3.38 / 3.51 | 후방 속도 반전 92 / 109회, 상태 전환 39 / 43회 |
| 1차 저역 τ 0.2 s($c_{lr}(x)$ 전체) | 0.93 / 0.97 | 명령 운동에도 0.2 s 지연이 생긴다 |
| **$\hat c_r$**(압축 항만 저역) | **0.61 / 0.63** | 명령으로 생긴 기하 변화는 지연 없이 통과한다 |

- 1차 오일러 저역(τ 0.2 s, $T$ 20 ms)의 이득은 2.98 Hz에서 0.272, 1.33 Hz(크롤러 흔들림)에서 0.534다(Python·Julia 일치, 16.6절).
- **필터만으로는 부족하다.** 문턱 하나에 걸친 신호는 잡음이 아무리 작아도 문턱 근처에서 계속 뒤집힌다. 필터만 쓴 변형(`B_lpfx`)은 전환이 31회 남았다.
- **히스테리시스 폭 10 mm**(20 mm에서 해제, 10 mm 아래에서만 재무장)를 둔다.
  - 이 폭은 한계 사이클 동안의 최대 3 Hz 성분(원 추정 3.5 mm pp)보다 크고, $\hat c_r$ 성분(0.63 mm pp)의 16배다.
  - 3 Hz 릴레이가 스스로 유지되려면 진동 진폭이 히스테리시스 반폭(5 mm)을 넘어야 한다. 원 추정으로도 닿지 않는다.
  - 그래서 필터는 2차 안전장치다. 압축 항 저역이 남기는 것은 β 오차에 따른 바이어스뿐이다: 100 kN에서 $P/k_{oil}$ = 4.3 mm이므로 β 0.69~1.6 GPa이면 −1.6~+1.9 mm.
- 979회 검증 전체에서 래치 전환은 최대 3회(해제 → 재무장 → 해제)였다.
  - 재무장은 앞내림 경사에서만 나왔다. 해제 직후 후방이 수축하면 추정이 10 mm 아래로 내려가 다시 켜진다.
  - 이것은 1.5~3 s 주기의 느린 순환 1회이고 3 Hz 성분은 없다.
  - 크롤러 재접촉(크롤러 법선력 > 0)은 0회였다.
- 남은 것
  - 래치 해제 순간 후방 속도가 0 → −13 mm/s로 계단처럼 바뀐다(램프 0.1 s만 거침). 이것이 pitch-surge를 약하게 가진한다(그림, 후방 ±7 kN).
  - 하중 여유에는 영향이 없어 더 다듬지 않았다. 필요하면 해제 뒤 1 s 동안 수축 속도 한계를 선형으로 푸는 방법이 있다.

### 16.3 (A) 접지 확인: 크롤러 흔들림과 떠 있는 패드

### 16.4 (S) 스트로크 끝: `stroke_m` 기준

- 문제
  - L1에서 스트로크 한계는 모터 위치 $s$에 걸린다. 로드 위치 $x=s-P/k_{oil}$은 하중 70 kN에서 약 3 mm 짧다.
  - 옛 명세(14.5 9·10항)는 $x\ge s_{max}-1$ mm로 판정해서 끝에 닿아도 고장을 내지 못했다. 그래서 앞들림 3.7°가 150 s 동안 끝나지 않았다(`not_done_150s`).
- 수정
  - R1은 판정과 자르기 모두 `stroke_m`을 쓴다. c2.py가 이미 그렇게 하므로 명세를 코드에 맞췄다.
  - 실기·L2에서도 `stroke_m`은 "한계가 걸리는 좌표"(피스톤 위치)로 정의한다.
  - 허용폭을 $P/k_{oil}$만큼 넓히는 방법은 쓰지 않았다. β 오차에 따라 판정이 바뀐다.
- 결과
  - 앞들림 3.7°는 모든 단계·마스트(9건)에서 접지 뒤 19.3~19.4 s에 `stroke_end_fault`로 끝난다(알람 + 다리 정지, 최소 힘 ≥ 65.4 kN 유지).
  - D8은 이 경사를 시작 전에 걸러내므로, 이것은 마지막 방어선이다.
- 보조 제안(선택, 구현하지 않음): 정체 감시. 신장 명령이 0.5 $v_{max}$보다 큰데 `stroke_m` 증가율이 명령의 10 % 미만인 상태가 2 s 이어지면 고장으로 본다. 끝 위치 정의와 무관하게 스트로크 끝·210 bar 포화·기계 걸림을 함께 잡는다.

### 17.2 설계

#### 17.2.1 상태 기계 위치와 D4 탐침과의 관계

```
TOUCH → LEVEL → DONE(첫 번째) ─┬─ 적용 조건 불만족 → (기존) PROBE(결합) / READY
                               └─ 만족 → REANCHOR[WAIT 2 s → (MOVE → HOLD → RETURN → HOLD2) × 4]
                                          → LEVEL(트림) → DONE → PROBE(결합) / READY
```

- **위치는 첫 DONE과 PROBE 사이다.** 탐침보다 앞에 두는 이유는 세 가지다.
  1. 재설정은 하중 분배를 흐트러뜨린다. $F_s$ 12 kN이면 되돌린 뒤 실제 비틀림 하중이 7~11 kN 남는다. 그래서 트림(LEVEL 재진입) 뒤에 접지 확정(D4 탐침)이 와야 최종 상태를 검증한다.
  2. 탐침을 앞뒤로 두 번 하면 6.1 s가 더 든다.
  3. 탐침의 $F_s$ 추정은 D5 규칙상 $F_{band}$를 **늘리기만** 한다. 그래서 탐침을 먼저 해도 재설정 문턱을 낮출 수 없다(17.3절).
- **D4 탐침과 통합하지 않는다.**
  - 탐침은 다리 하나를 ±2 mm 움직여 증분 강성을 잰다.
  - 재설정은 네 다리를 비틀림 모드로 움직이고, 목표 패드를 미끄러뜨리는 것이 목적이다. 그 사이의 하중 변화가 강성 측정을 오염시킨다.
  - 대신 두 동작은 $F_{band}$를 공유한다. 재설정은 진입할 때의 $F_{band}$로 문턱을 고정한다. 뒤에 탐침이 $F_{band}$를 그보다 크게 올리면 사건 `reanchor_band_exceeded`를 남긴다. 기록만 하고 동작은 없다(하중은 이미 복원됐다).
- **한 번만 한다.** 한 들어 올림 주기(TOUCH부터 FAULT·reset 전까지)에 한 번이다.
  - 재레벨링(감시 트리거) 때는 다시 하지 않는다. 접선 내력은 경사면에서 기체 z로 들어 올릴 때 쌓이고, 작은 자세 보정으로는 다시 쌓이지 않는다.
  - 결과(`completed`, `aborted:*`, `skipped:*`)는 `meta()`에 남긴다.

#### 17.2.2 적용 조건(첫 DONE에서 한 번 판정)

| 조건 | 값 | 근거 |
|---|---|---|
| 앞뒤 경사 | $\lvert\theta_c\rvert\ge$ 2.5° | 접선력은 θ²에 비례한다. 2.5°에서는 21 kN → 16 kN(−21~−23 %)이다. 2.0°에서는 14.7 kN이고 효과가 없다(F4 강제 −0.2 %). D8 다이아몬드 안에서 $\lvert\theta\rvert\ge$ 2.5°이면 $\lvert\phi\rvert\le$ 1.57°이므로 "앞뒤 성분이 지배한다"는 조건이 따로 필요 없다 |

| 크롤러 구간 래치 | 꺼짐 | 크롤러가 하중을 받는 동안은 하지 않는다 |

$\theta_c$는 크롤러 위 자세다. 크롤러 정착 기울기(앞내림 쪽 +0.13~+0.25°)와 IMU 바이어스가 들어간다. 그래서 지면 2.5°에서 앞내림은 적용되고, 앞들림은 −2.40°로 측정돼 빠진다. 문턱은 측정 자세 기준으로 정의한다.

#### 17.2.3 동작(매 주기, $T$ = 20 ms)

| 상태 | 명령 $u$ | 전이 |
|---|---|---|
| WAIT | 0 | 진입 후 2 s가 지나면 같은 주기에 MOVE. 자세 감시에 걸리면 `aborted:attitude_wait`로 끝낸다 |
| MOVE | $d_j v_r$, $c_k\mathrel{+}=uT$ | $P_j\le P_{stop,k}$이면 HOLD |
| HOLD | 0 | 1 s가 지나면 RETURN |
| RETURN | $-c_k/\lVert c_k\rVert_\infty\cdot v_r\lambda$, $\lambda=\min(1,\lVert c_k\rVert_\infty/(v_rT))$ | $\lVert c_k\rVert_\infty<10^{-10}$이면 HOLD2 |
| HOLD2 | 0 | 1 s가 지나면 $k\leftarrow k+1$, $c\leftarrow0$, MOVE. $k$ = 4이면 끝낸다(`completed`) |
| ABORT_RETURN | RETURN과 같음 | 0에 닿으면 끝낸다(`aborted:<이유>`) |

멈춤 문턱은 진입할 때 한 번 계산한다(근거는 17.3절).

$$P_{stop,k}=\max\big(S_k,\;20\ \mathrm{kN},\;F_{min}+F_{band}+10\ \mathrm{kN}\big),\qquad S=(45,\,30,\,20,\,20)\ \mathrm{kN}$$

$F_{band}$가 13 kN(D5 시작값)이면 45 / 32.45 / 32.45 / 32.45 kN이다.

- **목표 순서는 RR → RL → RR → RL이다.**
  - 가벼운 축은 후방이다(경우 C 무게중심, 레벨링 뒤 하중 118 / 116 / 72 / 71 kN).
  - 다른 기종이나 하중이면 "판독 합이 작은 축의 두 다리"로 일반화한다. 설정 `reanchor_targets`로 둔다.
- **자세는 거의 변하지 않는다.** 비틀림 모드는 $A^Td_j=0$이라 강체 자세가 변하지 않는다. 실측 자세 변화는 ≤ 0.0028°였다. 단일 다리 수축은 0.11°라 쓰지 않는다(dynamics 결과).
- **첫 단계 45 kN의 역할**: 대각이 아닌 후방 다리의 순간 접선력 증가를 줄인다. 30 kN에서 바로 시작하면 +6.2 kN, 45 kN 계단이면 +4.2 kN이다(screen2, 앞내림 3.5°).

- 트림은 탐침 시간을 빼고 1.06 s였다(최대 1.52 s, 강제 좌우 $F_s$ 12 kN).

#### 17.2.5 하드 중단과 실패 처리

| 조건(검사 시점) | 동작 | 근거 |
|---|---|---|
| MOVE: 목표 외 다리 $\min_{i\ne j}L_i<F_{min}$ + 5 kN | ABORT_RETURN(`other_low`) | 동역학 제안의 하드 중단 |
| HOLD: 모든 다리 $\min_iL_i<F_{min}$ | ABORT_RETURN(`hold_low`) | 목표 다리 유지 중 강하 $D$에 대한 마지막 방어. 문턱을 $F_{min}$ + 5 kN으로 두면 결합 판정의 정상 강하($D$ ≤ 4.6 kN)로도 걸린다. 그 중간안에서는 26회 중 4회가 중단됐다 |
| MOVE: $\lVert c_k\rVert_\infty\ge$ 8 mm | ABORT_RETURN(`stroke_cap`) | 예상 이동 1.2~2.9 mm(β 0.69이면 약 3.4 mm)의 약 3배. 목표가 덜어지지 않으면 대각 다리가 떠 있거나 지면이 무르다는 신호다 |
| 언제든: $\max(\lvert\phi_s\rvert,\lvert\theta_s\rvert)>$ 0.07° | ABORT_RETURN(`attitude`) | 자세 재레벨 트리거와 같은 값 |
| 스트로크 끝 자르기가 걸림 | 해당 다리 자르기(기존) | 적용 조건의 10 mm 여유 때문에 실제로는 생기지 않는다 |

- 중단 뒤에는 명령 적분을 같은 속도로 0까지 되돌리고 LEVEL(트림)로 간다.
- 재시도는 하지 않는다. 사건 `reanchor_aborted:<이유>`를 남기고(경고 수준) READY까지 정상 진행한다.
- 최종 H4 검증(적용·강제 157회)에서 중단은 0회였다.

### 17.3 $F_{band}$·실 마찰과 멈춤 문턱

판독과 실제 힘의 관계는 $P_i=F_i-f_i$, $\lvert f_i\rvert\le F_s$다(14.5절, 10.2절). 그래서 목표 다리의 실제 힘 하한은 다음과 같다.

$$F_j\ \ge\ P_{stop}-F_s-D$$

**유지 강하 $D$ 실측(판독 − 실제 최소)**

| $F_s$ | $D$ |
|---|---|
| 0 | 최대 4.61 kN(β 1.6 GPa, 앞내림 3.5°), 95 % 값 2.5 kN |
| 2 / 5 kN | ≤ 0.9 kN |
| 12 kN | 판독 − 실제 최대 6.9 kN. 마찰 상태가 띠 끝까지 가지 않았다 |

**여유 10 kN의 근거**
- $F_s\le F_{band}$일 때 $F_j\ge F_{min}$ + 5 kN(D8 기준)을 보장하려면 $P_{stop}\ge F_{min}+F_{band}+5+D_{max}$가 필요하다.
- $D_{max}$ 4.6 kN에 압력 잡음 3σ 0.9 kN을 더해 반올림하면 **여유 10 kN**이다.
- 동역학이 제안한 "약 8 kN"보다 2 kN 크다. 8 kN이면 최악 조합에서 13.2~13.8 kN으로 기준 14.45 kN에 못 미친다.

**기각한 대안: 마찰 방향 인식 문턱(G 계열)**
- 가정
  - 목표는 수축만 하므로, 마찰이 수축 방향으로 완전히 서면 실제 ≥ 판독이다.
  - 그러니 판독이 $2F_{band}$ 이상 떨어진 뒤에는 20 kN까지 내려도 된다.
- 진단($F_s$ 12 kN, 앞내림 3.5°, 첫 단계)
  - 판독 82.8 → 43.2 kN, 실제 71.1 → 38.7 kN이었다. 마찰 오프셋은 −11.7 → −4.6 kN으로, 끝까지 실제 < 판독이었다.
  - 레벨링 동안 신장 방향으로 선 마찰이 그대로 남아 있었다.
  - 비틀림 모드에서는 나머지 세 다리도 움직여 목표 하중을 바꾼다. 그래서 목표 로드가 붙어 있는 동안에도 실제 하중이 판독과 함께 떨어진다.
- 판정: 이 가정은 비틀림 모드에서 성립하지 않는다.
- G 계열 결과는 기록으로만 남겼다(`screen2`, `verify_G4b`). 모두 통과했지만 β 1.6에서 14.71 kN으로 여유가 0.26 kN뿐이었다.

**탐침과 공유**
- 재설정은 진입할 때의 $F_{band}$를 쓴다. 탐침이 뒤에 $F_{band}$를 올리면 사건만 남긴다.
- $F_{band}$가 검증으로 작아지면 문턱도 자동으로 20 kN 쪽으로 내려간다.
  - $F_{band}$ ≤ 0.55 kN이면 45 / 30 / 20 / 20 kN이 된다.
  - 탐침 하한이 1 kN이라 실제로는 최소 20.45 kN이다.
- 다만 지금 탐침의 $F_s$ 추정은 참값 0일 때 6.3~13.5 kN으로 크게 나온다.
  - 재설정이 없어도 같다(상단 앞내림 3.5°, 결합 판정 진단: 재설정 없음 14.46 / 있음 13.53 kN).
  - 그래서 D5 규칙대로라면 $F_{band}$는 13 kN 아래로 내려가지 않는다.
  - 동역학 원안 수준(−69 %)을 얻으려면 **탐침 $F_s$ 추정 개선이 먼저**다.

**실 마찰의 부작용**
- $F_s$ 12 kN이면 되돌린 뒤 실제 비틀림 하중 $n^TF$가 남는다. 압력만 판정이면 7~11 kN, 결합 판정이면 −3~−5 kN이다.
- 판독 기준으로는 3 kN 안이고, 최소 다리 하중은 66.8 kN 이상이라 문제가 없다.
- R1(재설정 없음)에서는 0.1 kN이었다.
