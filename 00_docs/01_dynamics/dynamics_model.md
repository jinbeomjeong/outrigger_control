핵심 판단:
1. **유압유 기둥이 다리 축방향 유연성의 약 90 %다**(2.3절). L1은 이 유연성을 접촉 강성에 합쳐 넣는다. 그래서 L1의 하중 분배·민감도·진동수는 체적 탄성계수 가정 $\beta_{eff}$에 거의 비례해 움직인다(2.4절 민감도 표).
2. **비틀림 모드는 IMU로 보이지 않고 압력으로 보인다.** 압력 센서를 쓸 수 있으므로(Q1 결정) "모든 다리 반력 ≥ $F_{min}$"을 실린더 힘으로 직접 판정한다(6절).
3. **스위블 패드에서는 다리 힘이 볼 중심을 지난다.** 그래서 모서리 접촉과 로드 굽힘 문제가 사라진다. 대신 지지점이 패드 중심이 되어 전도 여유가 팔각형 껍질 기준보다 0.17~0.21 m 줄어든다(3.5절).
4. **Chrono 10 SMC 접촉만으로는 기계가 경사에서 미끄러진다**(정지 마찰 없음, 2°에서 0.109 m/s). 접선 정지는 L1에서 부싱, L2b에서 NSC가 맡는다(4.1절).

### 2.3 유연성의 위치와 구동기 구성

다리 축 방향 하중 경로는 직렬 스프링이다.

$$\frac{1}{k_v} = \frac{1}{k_{oil}} + \frac{1}{k_{rod}} + \frac{1}{k_{frame}} + \frac{1}{k_c},\qquad k_{oil}(e)=\frac{\beta_{eff}A_p}{L_0+e}$$

| 기호 | 뜻 | 값(운용점) | 상태 |
|---|---|---|---|
| $A_p$ | 보어 면적 $\pi D_b^2/4$(헤드측만 반영) | 0.010387 m² | CAD. 실린더는 복동이다(회로도). 로드측은 아래 별도 행 |
| $\beta_{eff}$ | 유효 체적 탄성계수 | 1.0×10⁹ Pa(감도 범위 0.69~1.6×10⁹, CLAUDE.md) | **가정**(사용자 결정 값, Q5 미정) |
| $L_0$ | 배관·포트 체적을 길이로 환산한 값 | 0.05 m | **가정**. 회로도에서 로크 밸브(이중 파일럿 체크)가 실린더에 직결돼 호스가 잠긴 체적 밖이다. 작은 값이라는 가정을 지지한다 |
| $k_{oil}$ | 잠긴 유압유 기둥 강성 | 2.30×10⁷(전방) / 2.36×10⁷(후방) N/m. $e$=0에서 2.08×10⁸, $e$=0.68에서 1.42×10⁷ | 가정에서 계산 |
| $k_{rod}$ | 로드 축강성 $EA/L$, $L$≈1.05 m | 1.90×10⁹ N/m | 계산 |
| $k_{frame}$ | 브래킷·아우트리거 박스 | 1.0×10⁹ N/m | **가정** |
| $k_c$ | 콘크리트 슬래브(Westergaard $8k_s\ell^2$) | 3.24×10⁸ N/m | **가정**(E 30 GPa, ν 0.15, 두께 0.2 m, $k_s$ 80 MN/m³, $\ell$ 0.711 m) |
| $k_v$ | 직렬 합 | **2.08×10⁷(전방) / 2.12×10⁷(후방) N/m** | |
| $k_{lat}$ | 횡방향 합성(스위블 다리 굽힘 ⊕ 접촉 접선 $k_c$) | **8.51×10⁶ / 8.40×10⁶ N/m** | 다리별 기하(부착 z 0.047/0.0593, 배럴 하단 −0.4755/−0.4857, 수축 패드 바닥 −0.6998/−0.7100 m), 하중점 = 볼 중심 |
| $k_{ann}$ | 로드측(환형) 기름 기둥, 헤드측과 병렬. $\beta A_{ann}/(s_{max}-e+L_0)$, $A_{ann}$ = 8.84×10⁻⁴ m² | 2.69×10⁶(전방) / 2.61×10⁶(후방) N/m = $k_{oil}$의 +11.7 % / +11.1 %. $k_v$로는 +10.4 % / +9.9 % | **기준 모델에 넣지 않는다**(감도). 아래 설명 |

로드측 챔버(개정 4, 회로도 반영):
- 이중 파일럿 체크가 두 챔버를 모두 가둔다. 그래서 로드측 기름도 피스톤 움직임에 저항한다.
- 다만 로드측은 신장 이동 중 탱크로 열려 있다가 잠기므로 잠긴 압력이 낮다(가정: 수 bar). 다리 하중이 늘면 피스톤이 위로 가서 로드측 체적이 커진다. 그러면 로드측 압력은 0 근처로 떨어져 강성을 거의 보태지 못한다. 하중이 줄 때(피스톤 아래로)만 +10 % 강해진다. 즉 한쪽 방향 비선형이다.
- 크기(+10 %)가 $\beta$ 감도 범위(−29 ~ +51 %) 안이다. 그래서 기준 모델은 헤드측만 둔다(플런저 근사). 감도 해석에서 $k_v$ +10 %로 덮는다.
- 압력 센서가 헤드측만 읽으면 실린더 힘 오차는 $p_{rod}A_{ann}$이다. 5 bar면 0.44 kN이다(가정 값).
- 수치는 `reference.json` `hydraulic_circuit`에 있다.

| 구성 | 상태 | 구동기 | 접촉 | 비고 |
|---|---|---|---|---|
| **L1** | **임시 기본(제어기 개발)** | `ChLinkMotorLinearSpeed`(또는 적분 위치를 준 `Position`), 강체. 힘 포화 4.4절 | 패드당 구 1개, SMC 수직만 $k_n=k_v$. 접선 $k_t=k_{lat}$는 지면 고정 부싱 + 원형 Coulomb 항복(4.1절) | 단순하다. 수직·횡 거동이 물리 추정(L2b)과 진동수 1.5 % 이내로 같다. 한계: $k_{oil}$의 신장 의존성(운용점 값 고정), 침투가 5.7 mm로 보인다. SCM에는 쓸 수 없다 |

### 3.1 수평 강체 지면에서 다리 하중 분배

정적 3자유도 $[u_z,\phi,\theta]$에서 압축은 $c_i=\delta_i-(Aq)_i$, 하중은 $F_i=k_ic_i$다.

$$A=\begin{bmatrix}1 & y_i & -x_i\end{bmatrix}_{i=1..4},\qquad A^T K A\,q = A^T K\delta - w,\qquad w=\begin{bmatrix}W & W y_c & -W x_c\end{bmatrix}^T$$

| 기호 | 뜻 |
|---|---|
| $K=\mathrm{diag}(k_i)$ | 다리별 수직 강성 |
| $\delta_i$ | 다리 $i$의 추가 신장(오차), m |
| $W$, $(x_c,y_c)$ | 무게(N)와 무게중심 수평 위치 |

해는 하나다. 하중이 음수인 다리는 빼고 다시 푼다(활성 집합). 스위블에서는 힘이 볼 중심(= 실린더 축)을 지나므로 모멘트 팔이 $(x_i,y_i)$로 고정된다.

같은 강성(YAML의 가정)일 때:
- 상부체만: 118,254.6 / 116,261.5 / 72,700.3 / 70,885.4 N. YAML과 최대 상대차 3.6×10⁻⁷이고 세 단계가 같다.

### 3.2 신장 오차 민감도와 $F_{min}$ 문턱

### 3.4 고유진동수

6자유도 선형화(로드는 상부체에 고정, L1·R1)는 다음과 같다.

$$M\ddot q + Kq = 0,\quad M=\mathrm{diag}(m,m,m,I_c),\quad K=\sum_i\big[k_{n,i}\,a_{z,i}a_{z,i}^T + k_{t,i}(a_{x,i}a_{x,i}^T+a_{y,i}a_{y,i}^T)\big] + K_g$$

$$a_{z,i}=[0,0,1,d_y,-d_x,0],\ a_{x,i}=[1,0,0,0,d_z,-d_y],\ a_{y,i}=[0,1,0,-d_z,0,d_x],\quad K_g^{rot}=-\sum_i F_i\begin{bmatrix}-d_z&0&d_x/2\\0&-d_z&d_y/2\\d_x/2&d_y/2&0\end{bmatrix}$$

- L2b-NSC는 NSC 강체 접촉을 매우 큰 $k_c$(1×10¹³ N/m, 감쇠 0)로 근사해 10자유도 모델로 구했다(`run_reference.py` `L2b_NSC_...`). 로드-지면 모드(약 48.7 kHz)는 표에서 뺐다.

감쇠(가정, **개정 7**: 다리 축 ζ 0.03을 heave 모드 7.39 Hz에 맞춤, [damping_survey.md](damping_survey.md)):
- L1: 패드당 수직 $c_n$ 2.70×10⁴ / 2.73×10⁴ N·s/m, 접선 $c_t$ 1.73×10⁴ / 1.72×10⁴ N·s/m. 결과 ζ(상단, 감쇠 진동수 순) = 0.0078 / 0.0139 / 0.0373 / 0.0363 / 0.0324 / 0.0494(개정 6: 0.013 / 0.023 / 0.062 / 0.061 / 0.054 / 0.082). 감쇠 진동수 변화 ≤ 0.02 %.
- L2: 유압(잠김) 2.79×10⁴ / 2.82×10⁴ N·s/m, 이동 중 9.31×10⁴ / 9.42×10⁴ N·s/m, 접촉 수직 8.74×10⁴ / 8.72×10⁴ N·s/m, 접촉 접선 1.07×10⁵ N·s/m. 로킹 ζ 0.0071 / 0.0124, 로드 국부 ζ 0.300.
- L2b-NSC: 유압(잠김) 2.79×10⁴ / 2.82×10⁴ N·s/m(축 힘 법칙), 이동 중 9.31×10⁴ / 9.42×10⁴, 부싱 실제 감쇠 1.73×10⁴ / 1.72×10⁴ N·s/m(Chrono 입력은 그 절반, 4.1절). 접촉 감쇠 없음. ζ(상단) = 0.0080 / 0.0142 / 0.0376 / 0.0368 / 0.0337 / 0.0502.
- 고정 대시포트의 모드 감쇠비는 $\zeta_i\approx c\,\omega_i/(2k_i)$로 진동수에 비례한다. 그래서 heave(7.4 Hz)에서 0.03이면 1차 로킹(1.8 Hz)은 0.008이다. 이 분포는 문헌의 강구조·장비 자료(0.8~8 %)와 맞추려는 것이 아니라 보수적 하한이다.
- L2 접촉 수직 감쇠는 로드 국부 모드(286 Hz)의 **전체** 감쇠비가 0.3이 되도록 정했다: $c_c = 2(0.3)\sqrt{(k_{oil}+k_c)m_r} - c_{oil}$. 로드에는 유압 감쇠기와 접촉 감쇠기가 병렬로 걸리므로 유압 몫(잠김 값)을 뺀다. 0.3은 물리 자료가 아니라 국부 진동을 몇 주기 안에 없애기 위한 수치 위생값이다. 이동 중 $c_{oil}$로 바꾸면 로드 국부 ζ가 0.3보다 조금 커진다(무해). 상부체 모드의 감쇠에는 영향이 거의 없다(heave ζ 0.028).

- **$F_{min}$ 동적 여유는 배치에 따라 부호가 바뀐다**(+125 N ↔ −10.5 kN). 네 다리를 최대 속도로 동시에 신장하는 개루프 시나리오에서 "접지 뒤 $F_{min}$ 미달 없음"(3.7절)은 크롤러 모델에 기대는 결론이다. 감쇠가 작은 크롤러 위 pitch 모드와 접지 순간 하중 램프의 꺾임이 원인이다. 제어기의 접지 단계(접지 전 감속, 다리별 접지 확인)가 이 여유를 만들어야 한다. 이는 제어기 판정에 의미가 있다.
- 경사 위 크롤러 안정성: 레벨링 범위(≤ 6°)에서 전도는 어느 배치로도 생기지 않는다(앞 전도 ≥ 8°, 실제로는 앞 들린 트랙이 닿아 약 15~17°). 다만 A는 앞 내림 5.8°까지 뒤 롤러가 하중을 유지한다고 보지만, CAD 배치(D)에서는 **앞 내림 1.3°에서 뒤 끝이 뜬다**. 크롤러를 경사 바닥에 놓고 시작하는 제어 비교 시나리오의 초기 자세가 달라진다.

**부수 결과: 레벨링 가능 경사(3.3절)의 크롤러 여유 기준.** 3.3절과 제어 비교는 크롤러를 bbox 상자(바닥 높이 모서리 x ±1.84, y ±1.366 m)로 보고 여유를 잰다. CAD 솔리드 bbox의 하한 포락선(10 mm 격자, 보수적)으로 바꾸면 양 끝이 들려 있어 범위가 넓어진다. 여유 50 mm에서 pitch +3.86 / −3.76° → **+4.62 / −4.34°**, roll ±5.92 → 5.98 / 5.96°, 대각 3.31 → **3.80°**(여유 0 mm: 4.55 / 4.41 → 5.36 / 5.03°, 6.97 → 7.04 / 7.01°, 3.90 → 4.48°)다. 접촉 배치와 따로 정할 수 있다.

**권고(결정 당시, 1~5 모두 채택됨).**
1. **바꾼다.** 현행 A는 바닥에 닿지 않는 트랙 양 끝을 지지로 세어 크롤러 위 pitch 강성을 3.8배 과대평가한다. 그 결과 V4 기준해의 첫 접지 다리, 크롤러 정착 길이, 접지 전환 하중 여유가 CAD와 다른 쪽으로 나온다. 끝 상태와 다른 V 기준값은 바뀌지 않으므로 바꾸는 비용은 크롤러 구간 산출물에 한정된다.
2. **배치는 D(롤러 위치 + 틈 있는 끝 슈)**로 한다. 평탄 슈 균등(C)은 롤러 사이 슈까지 같은 강성을 줘서 지지 길이를 짧게 잡는다(하한). 롤러만(B)은 앞 롤러 압축이 다음 슈 틈보다 커서 기하와 모순이다.
3. **총 강성은 보존**한다. 바닥 접촉 롤러 12점의 합 = `kn_total_N_m` 1×10⁸ N/m(값은 그대로 두되 무른 쪽일 수 있음을 기록), 끝 슈 12점은 같은 점당 강성을 틈 뒤에만 더한다. 총 대시포트 1.97441×10⁵ N·s/m도 그대로 두고 롤러 12점에 나눈다. 끝 슈 구도 같은 재질 값을 쓴다(Chrono 재질 하나).

5. 크롤러 정착은 지금처럼 **해석 정착 자세로 초기화**한다. 그러면 65 s 정착은 초기화를 못 할 때만 필요하다.

## 4. 적분기·접촉

### 4.1 접촉 모델 (개정 4)

**시험 결과**([chrono_stick_friction_test.md](../03_chrono/chrono_stick_friction_test.md), pychrono 10.0.0, `06_analysis/01_chrono/stick_friction.json`):
- Chrono 10 SMC 접촉에는 **정지 마찰(stick)이 없다.** MultiStep은 OneStep과 비트 단위로 같다(헤더 `ChSystemSMC.h:94` "MultiStep falls back to OneStep"이 실행으로 확인됨).
- OneStep 접선력은 $F_t=(k_t\Delta t+c_t)\,v_t$인 점성력이다(μN에서 잘림). 다리 하나 몫 블록(9,745.7 kg)이 2° 경사에서 **0.109 m/s**로 계속 미끄러진다(식 $mg\sin\alpha/(k_t\Delta t+c_t)$ = 0.10935 m/s와 4자리 일치). 수평에서는 접선 진동 없이 표류한다.
- 따라서 SMC 접선 모델만으로는 V7(접선 모드)·V8·V12의 전제가 성립하지 않는다. **"MultiStep을 쓴다"는 개정 3 권고를 지운다.**

| 구성 | 수직 | 접선(정지 마찰) | 근거 |
|---|---|---|---|
| **L1** | `ChSystemSMC`, Hooke, `UseMaterialProperties(false)`. 재질 $k_n$, $g_n$만 주고 **$k_t=g_t=\mu=0$** | 패드마다 **지면 고정 `ChLoadBodyBodyBushingSpherical`**(접선 2축 $k_t$, 법선 축 강성 0) + 매 스텝 뒤 **원형 Coulomb 복귀 사상**(Python): $k_t\lvert d\rvert>\mu N$이면 지면 쪽 고정점을 $d$ 방향으로 $\lvert d\rvert-\mu N/k_t$만큼 옮긴다(`SetApplicationFrameB`). 미끄럼 중에는 부싱 감쇠를 끈다. $N$은 패드별 접촉 수직력(로드 바디에 다른 접촉이 없으면 `GetContactForce()`, 아니면 `ReportContactCallback`). 부상($N=0$)하면 고정점이 따라간다 | 시험: 2° 미끄럼 0, 탄성 0.3923 mm(이론 0.3919), 수평 4.7023 Hz(이론 4.703), 30°에서 μ_eff 0.505 |
| **L2b-NSC** | `ChSystemNSC`, PSOR 50회(`GetSolver().AsIterative().SetMaxIterations(50)`), μ 0.5 | NSC 마찰이 정지를 정확히 표현한다. 접선 유연성은 다리 횡 부싱(구동 링크 가이드 x, y를 풀고 부싱으로 잡음)이 맡는다 | 시험: 2° 미끄럼 2×10⁻¹² m, 30°에서 μ_eff 0.5000. APGD는 25배 느려 쓰지 않는다 |
| 쓰지 않음 | — | SMC OneStep/MultiStep 접선, 내장 `ChLoadBodyBodyBushingPlastic`(30°에서 μ_eff 0.554, $c$ = 0이면 발산. 유한차분 강성 계산 중 소성 상태가 갱신되는 것으로 추정) | 시험 |

L1 부싱 배치:
- 부싱 프레임 축은 지면 접평면 2축 + 법선 축이다. 법선 축 강성·감쇠는 0이다(수직은 SMC 접촉이 맡는다).
- A 바디 = 다리 이동부(로드), B 바디 = 고정 바닥이다. 작용점은 구의 접촉점(볼 중심에서 지면 법선을 따라 $h_b$ 아래)이다. 패드가 처음 닿을 때 만든다. 3.4절 6자유도 기준해의 접선 스프링 작용점과 같다. 볼 중심에 붙이면 작용 높이가 6 cm 바뀌는데, 영향은 0.1 % 미만이다.
- 부싱 힘은 B(바닥) 프레임 축 기준으로 나온다(`GetForce()`).

**감쇠 입력 규약 (확인됨, 개정 3의 "미확인"을 바꿈):**

| 입력 | 규약 | Chrono에 넣을 값 | 시험 근거 |
|---|---|---|---|
| SMC Hooke `gn`(`gt`) | **유효 질량당 값**이다. 실제 감쇠 = $g\,m_{eff}$, $m_{eff}=m_1m_2/(m_1+m_2)$ | $g_n = c_n/m_{eff}$. L1에서는 접촉 쌍이 **다리 이동부(YAML `legs.<leg>.moving_part.mass_kg`, 약 106.78 kg) + 바닥**이므로 $g_n = c_n/m_{moving}$ [s⁻¹]이다(바닥 1×10⁹ kg이면 $m_{eff}$ 상대차 1×10⁻⁷). 시험 블록의 9,745.7 kg이 아니다 | 바닥 1×10⁹ kg에서 ζ 0.0502(목표 0.050). `SetGt(c_t)`(N·s/m 그대로)는 발산했다 |
| 바닥 바디 질량 | 고정 바디도 질량이 $m_{eff}$에 들어간다 | **1×10⁹ kg**(`SetFixed(True)`와 함께). ChBody 기본값 1 kg이면 감쇠가 사라진다 | 바닥 1 kg에서 ζ 0.0010 |
| 부싱 감쇠 `c` | 입력의 **2배**로 작용한다(원인 미확인, 헤더만 있음) | **$c_t/2$**를 넣는다 | `c` = $c_t/2$에서 ζ 0.0531, $c_t$에서 0.103 |
| SMC 재질 합성 | 두 재질의 합성값이 쓰인다(헤더 `ChContactMaterialCompositeSMC`). 합성 식은 구현(.cpp)이 없어 미확인이다 | 패드 구와 바닥에 **같은 값의 재질**을 준다. 전후 $k_n$이 다르면 패드마다 재질을 두고, 바닥은 다리별 충돌 형상(같은 재질)으로 나누거나 V2 침투로 실제 $k_n$을 확인한다 | 시험은 같은 재질을 썼다. 추가 확인 필요(V0) |

공통:
- `SetContactStiff(true)`는 V9로 효과를 확인한다.
- Chrono 함정: `body.GetPos()`는 참조를 돌려준다. 고정점·초기값을 저장할 때 `ChVector3d(body.GetPos())`로 복사한다.

### 4.4 구동기 모델

유압 회로 근거([hydraulic_circuit.md](../02_hydraulic/hydraulic_circuit.md), 2026-10-19 회로도와 제조사 설명):
- 실린더는 **복동**이다. **이중 파일럿 체크 밸브가 실린더에 직결**돼 정지 중 두 챔버가 모두 잠긴다. 압력 센서는 이 로크 밸브 블록(실린더 쪽)에 있어 정지 중 갇힌 부하 압력을 읽는다.
- 방향 밸브는 비례 + 섹션 압력 보상(LS)으로 보인다(확인 필요). 그렇다면 **이동 중 속도는 부하와 무관하게 명령에 비례**한다. 그래서 L1의 속도 제한 위치 모터가 이동 구간을 잘 근사한다. 다리별 독립 속도 명령도 가능하다.
- 펌프 60.2 L/min은 네 다리 동시 최대 신장(22.67 mm/s × 헤드 면적 × 4 = 56.5 L/min)을 6 % 여유로 감당한다. 그래서 $v_{max}$를 네 다리에 동시에 줘도 된다.
- 이동 중 압력 상한은 MCV 릴리프 **210 bar**다. 행정 끝에서 멈췄을 때만 도달한다. 힘으로는 **신장 218.1 kN**(헤드 1.0387×10⁻² m²), **수축 18.6 kN**(환형 8.84×10⁻⁴ m²)이다. 정하중 압력은 68~114 bar(실린더 힘 70.9~118.2 kN)다.
- 잠긴 정지 상태에서는 외력 진동·뒤틀림으로 압력이 변하며 **최대 350 bar(364 kN, 실린더 최대 부하 시험 압력)**까지 예상된다. 현재 파일럿 체크는 그 이상을 제한하지 않는다. 카운터 밸런스 밸브(교체 계획 옵션)는 350 bar에서 릴리프처럼 다리를 밀리게 한다.

카운터 밸런스 옵션 모델(제안, L2b-NSC): 기름 스프링과 직렬인 **강소성(릴리프) 요소**로 둔다. 부싱 Coulomb와 같은 복귀 사상이다.
- 매 스텝 시험 힘 $F^{tr}=k_{ax}(s_{ref}-s)+c_{oil}(\dot s_{ref}-\dot s)$를 계산한다.
- $F^{tr}>F_{cb}$(= 350 bar × $A_p$ = 363.5 kN)이면 기름이 빠져나간 만큼 기준을 옮긴다: $s_{ref}\leftarrow s_{ref}-(F^{tr}-F_{cb})/k_{ax}$. 그러면 $F=F_{cb}$이고 다리가 짧아진다(위치 이동, 되돌아오지 않음).
- 기록: 누적 미끄럼 $\sum\Delta s_{ref}$, 소산 일 $F_{cb}\sum\Delta s_{ref}$(V8 에너지 수지에 넣는다).
- 밸브 응답과 크래킹 압력 이력은 넣지 않는다. 순간 과압(충격)은 이 모델로 막지 못한다는 제조사 설명과 맞추려면 밸브 지연 $\tau$(가정)를 더한다.
- L1에서도 같은 일을 모터 위치에서 할 수 있다: $s_{motor}\leftarrow s_{motor}-(F_{cyl}-F_{cb})/k_n$.

### 4.5 수치 안정성 점검

1. 정지 5 s: 자세 드리프트 < 1×10⁻⁴°, 접촉력 변동 < 0.1 % W/4. **정착 길이(개정 5)**: 1차 로킹(L1 상단 1.785 Hz, ζ 0.00777, 개정 7)의 시정수는 $\tau_1=1/(\zeta_1\omega_1)$ = 11.5 s다. 패드가 막 닿은 상태(침투 0)에서 놓으면 pitch 진동이 수백분의 1° 생긴다. 이를 1/100로 줄이려면 $\ln(100)\,\tau_1$ ≈ **53 s** 정착이 필요하다. 그래서 정적 시험은 **해석 정적해**(V2 침투, V3 자세, 접선 예하중 0)에서 시작하고, 그 뒤 정지 5 s를 판정한다. 정적해로 시작할 수 없으면 정착을 53 s 이상 둔다. 크롤러 위 정착(V4 앞)은 $\ln(100)\max\tau$ = **65.5 s**(개정 8 D안: 크롤러 위 pitch 1.327 Hz, ζ 0.0084, τ 14.2 s; `simulation.settle_on_crawler_min_s` 65.47; 개정 7의 2×9는 23.2 s) 이상이다(`lift_V4_compliant_crawler / crawler_on_floor_modes (layout D, legs at 0)`). **크롤러 정착 자세(해석해)로 초기화하면 이 정착은 필요 없다**(권장). 경사 바닥에서는 크롤러 접선(L2b-NSC 마찰, 제어 비교 모델의 부싱) 예하중이 0에서 시작해 이 pitch 모드를 들뜨게 하므로 초기화해도 이 길이를 둔다. 정착 상태(위치·속도·부싱 고정점)를 저장해 다른 시나리오가 재사용한다.
2. $\Delta t$, $\Delta t/2$, $\Delta t/4$ 비교(V9).
3. 모터 구속 위반과 NaN 점검. 접촉점 수가 다리당 1개인지 점검.
4. 감쇠 0 자유 진동에서 에너지가 늘지 않는지 점검(V8).
5. L1 부싱: 항복 스텝 수, 고정점 누적 이동, 부상 중 고정점 추종을 매 시험 기록한다. L2b-NSC: PSOR 수렴 잔차, 다리당 접촉점 1개.

## 6. 제어 관점 메모 (개정 6: 목표 ±0.2°, C2 잠정 채택)

### 6.1 상태공간

준정적 모델(1차 로킹 ≥ 1.78 Hz ≫ 레벨링 대역):

$$\dot s = u,\quad \begin{bmatrix}u_z\\ \phi\\ \theta\end{bmatrix} = J_K(s-s_0)+q_g,\quad F_{cyl} = K\big(s-s_0-A[u_z,\phi,\theta]^T\big)+F_0,\quad J_K=(A^TKA)^{-1}A^TK$$

| 기호 | 뜻 |
|---|---|
| $s$ (4) | 다리 신장(상태, 스트로크 센서로 측정) |
| $u$ (4) | 다리 속도 명령(입력), $\lvert u_i\rvert\le v_{max}$ |
| $y=[\phi,\theta]$ | 자세(IMU) |
| $F_{cyl}$ (4) | 실린더 힘(압력 센서) |
| $q_g$ | 지면 경사·초기 조건 항 |

좌표를 바꾸면 $[\dot u_z,\dot\phi,\dot\theta,\dot\tau]^T=[A^+;\,n^T]\,u$(같은 강성)가 된다.
- $\phi,\theta$: IMU로 관측된다.
- $u_z$: 스트로크로 관측된다.
- 비틀림 $\tau=n^Ts$: **압력으로 관측된다**(Q1 결정). 비틀림 하중 $n^TF_{cyl}$ = $k\,\tau$ + 상수다.

네 방향이 모두 측정 가능하고, 입력 4개로 각각 독립적으로 움직일 수 있다.

제약: $0\le s_i\le0.68$ m, $\lvert u_i\rvert\le0.022667$ m/s, $F_{cyl,i}\ge F_{min}$ = 9.453 kN, 크롤러 바닥 여유 ≥ 0. 유압 한계(개정 4): 이동 중 $F_{cyl,i}\le$ 218.1 kN(210 bar, 넘으면 그 다리 정지), 잠긴 상태 $F_{cyl,i}\le$ 363.5 kN(350 bar, V17 판정 지표).

센서 정밀도(개정 6, 목표 ±0.2°, 축마다 선형 합 예산. **장착 몫은 2026-10-20 사용자 결정으로 0.02°(IMU C1, 보수안)**, 이전 0.03° 행은 기록):

| 몫 | 값 [°] | 근거 |
|---|---|---|
| 목표 정상상태 오차 | 0.20 | CLAUDE.md(2026-10-20 결정) |
| − 데드밴드 | 0.03 | 유지(6.2절) |
| − 잡음·로킹 잔류 | 0.01 | 2차 필터 뒤 완료 판정 잔류 0.0024°(최악 추정, C1에서 0.0022°) 포함 |
| − 장착(**결정**: 영점 기준 0.01 + 프레임 국부 0.01, C1 방진 마운트 아래 구조체) | **0.02** | 사용자 결정 2026-10-20(보수안). 이전: 영점 기준 0.01 + 캐빈 마운트 가변 0.02 = 0.03(→ 허용 0.13° = 2.27 mg). 0.01°로 줄이는 조건(핀 러그 무하중 제조사 확인, 브래킷 용접·연결)은 열린 항목. 검토 기록: C1(방진 마운트 아래 구조체)이면 0.01°(조건부) 또는 보수안 0.02°로 줄여 허용 0.15° / 0.14°(2.62 / 2.44 mg)가 되는 안을 검토했다([imu_cabin_and_accuracy_review.md](../05_sensors/imu_cabin_and_accuracy_review.md) 10.4절). 결정 0.02° |
| **= 센서 정지 영점 허용** | **0.14°(2.44 mg)**(이전 0.13° = 2.27 mg) | 1 mg ≈ 0.0573°. **현장 영점 교정 후** 값(온도계수 × 45 K + 반복성)으로 판정 |

개정 5까지의 "±0.1° = 1.75 mrad → 바이어스 ≤ 약 1.7 mg"은 데드밴드·잡음·장착 몫을 빼지 않은 값이라 폐기한다(같은 예산으로 ±0.1°면 캐빈 0.03° = 0.52 mg). 폐루프 시뮬레이션에서는 PI가 측정값을 0 근처로 몰아 정상 오차 ≈ 영점 오차 + 0.01~0.02°였다([imu_cabin_and_accuracy_review.md](../05_sensors/imu_cabin_and_accuracy_review.md) 4절). IMU 모델은 제어기와 분리한다(CLAUDE.md).

### 6.2 제어기 구조 후보

개정 6: **C2를 잠정 채택**했다(사용자 결정 2026-10-20). 기구학 분해(heave·roll·pitch) + 압력 기반 비틀림 루프($n^TF_{cyl}\to0$) + $F_{min}$ 가드, 레벨링 뒤 결합 접지 판정(탐침). 대안은 C8(2상). 비교는 [control_candidates_comparison.md](../04_control/control_candidates_comparison.md).

| 후보 | 구조 | 장점 | 단점 |
|---|---|---|---|
| C1 기구학 분해 + PI | roll·pitch PI → $A^+$ 열 조합. heave·비틀림은 스트로크로 유지 | 단순 | 국부 침하·강성 차에 의한 하중 쏠림을 압력으로 보정하지 않는다 |
| C2 C1 + 비틀림(하중) 루프 | 압력에서 $n^TF_{cyl}$ 오차 → $\dot\tau$ 명령. 목표는 같은 강성 해 또는 최소 하중 ≥ $F_{min}$ 여유 | 압력 센서가 있어 바로 쓸 수 있다. 비틀림은 자세에 영향이 없어 자세 루프와 분리된다 | 하중 목표의 정의가 필요하다(어떤 분배를 "정상"으로 볼지) |
| C3 규칙 기반 순차 레벨링 | 압력으로 접지 감지 → 들어 올림 → 낮은 쪽만 신장 → $F_{min}$ 확인 | 실무 관행에 가깝다 | 느리고 경우 나눔이 많다 |
| C4 제약 QP/MPC | $\min\lVert\dot y_{des}-Ju\rVert^2+\rho\lVert u\rVert^2$, 속도·스트로크·$F_{cyl}+S u\Delta t\ge F_{min}$ | 제약을 명시적으로 다룬다. 압력 측정으로 하중 모델 오차를 매 주기 보정할 수 있다 | 구현·검증 부담. $S$(강성)는 $\beta$ 가정에 의존한다 |
| C5 LQR/LQI | 선형 동적 모델 | 동적 거동까지 다룬다 | 제약을 못 다룬다. 준정적 문제라 이득이 작다 |

공통 조건:
- 레벨링 대역 ≤ 0.2~0.35 Hz(1차 로킹의 1/5~1/10).
- IMU 자세 필터는 **2차 저역통과(1차 τ 0.5 s × 2단, −3 dB 약 0.32 Hz)**(개정 6 결정). 1차 τ 0.5 s만으로는 완료 판정 필터 뒤 로킹 잔류가 최악 0.023°로 남아 목표 0.005°(가정)를 넘는다. 2차면 0.0024°, 위상 여유 71° → 60°(자세 PI $K_p$ 0.4, $K_i$ 0.02, 지연 30 ms 가정).
- 완료 판정 데드밴드 **0.03° 유지**(개정 6 결정). 0.06°로 넓혀도 레벨링 시간 중앙값 이득이 0 s였다(시간은 스트로크 이동이 정한다).
- 제어 주기 ≤ 20 ms(한 주기 이동 0.45 mm = roll 0.005°).
- 비틀림 보정 속도: 5 kN/mm이므로 $v_{max}$에서 약 110 kN/s다.
