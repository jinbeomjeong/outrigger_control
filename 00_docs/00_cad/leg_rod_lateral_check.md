# 다리 로드·실린더 횡하중 검토 (경사 운용, D8) — 개정 2, 2026-10-21

dynamics-expert 핸드오프에 대한 cad-expert 검토다. 경사에서 레벨링하면 패드가 바닥에 고착된 채 기체가 수평으로 돌아가서 패드 접선 내력이 생긴다. 이 힘이 그대로 로드 횡하중이 된다. 이 하중으로 로드·배럴 굽힘, 좌굴(P-δ 포함), 가이드(글랜드 부시·피스톤) 면압을 해석식으로 확인했다. FEM은 하지 않았다(판정을 가르는 것이 소재와 가이드 세부라서 FEM으로 결론이 바뀌지 않는다).

- 스크립트: `04_scripts/00_cad/leg_rod_lateral_check.py` (Chrono-dev, 약 47 s)
- 입력 하중: `06_analysis/00_dynamics/pad_tangential_check.json`(`00_docs/01_dynamics/dynamics_model.md` 개정 18, 3.10절)
- 결과: `01_cad/02_legs/leg_rod_lateral_check.json`, 그림 `01_cad/02_legs/leg_rod_lateral_check.png`
- 좌표: 기체 좌표(x 전방, y 좌측, z 상방, 원점 CAD 원점), m. 경사 부호는 3.10.1을 따른다(pitch > 0 앞내림, roll > 0 좌측 위 = 우측 낮음). 응력은 MPa, 힘은 kN으로 표시했다.

## 1. 결론

1. **좌굴은 문제가 아니다.** 흔들림 모드 좌굴 여유는 정적 축력에서 19~32배, 잠김 364 kN에서도 6.4배 이상이다(요구 3.5, 가정). 개정 1과 같다(형상만으로 정해진다).
2. **로드 굽힘 판정은 로드 소재와 $k_t$ 모델에 따라 갈린다.** D8 검증 범위 경계(Φ 5.5°, Θ 3.5°)에서 가장 불리한 곳은 **좌우 끝의 긴 전방 다리**(신장 0.660 m)다. 여유(항복/응력, 요구 1.5)는 다음과 같다.
   - 할선(최선 추정): C45 **1.16** / 20MnV6 **1.72**(34.0 kN)
   - YAML(상한): C45 **0.74** / 20MnV6 **1.10**(54.4 kN)
3. **잠정 한계(Φ 4.4°, Θ 3.2°)의 최소 여유**는 다음과 같다.
   - 할선: C45 **1.69** / 20MnV6 **2.49**(앞내림 3.2°, FL 23.7 kN)
   - YAML: C45 **1.19** / 20MnV6 **1.76**(좌우 4.4°, FL 35.5 kN)
   - 즉, 잠정 한계는 **"할선 + C45"와 "YAML + 20MnV6"를 모두 만족**한다. **"YAML + C45"(두 불확실성이 모두 나쁜 쪽)만 미달**이다.
4. **로드 굽힘 여유 1.5를 지키는 경사 한계**(6절 표)는 다음과 같다. 행정 한계는 앞내림 3.86° / 앞들림 3.76° / 좌우 5.92°다(크롤러 여유 50 mm 기준).

   | 로드 소재(가정) | 할선(최선 추정): 앞내림 / 앞들림 / 좌우 | YAML(상한, μ 0.5): 앞내림 / 앞들림 / 좌우 |
   |---|---|---|
   | C45 305 MPa | **3.42° / 3.62° / 4.72°** | **2.88° / 2.94° / 3.94°** |
   | 20MnV6 450 MPa | 행정 한계(≥ 3.86° / ≥ 3.76°) / **5.88°** | 행정 한계(고착이면 3.46° / 3.50°) / **4.74°** |

5. **잠정 한계 3.2°/4.4°는 그대로 두기를 권한다.** 지금은 바꿀 근거가 없다.
   - 최선 추정(할선)으로는 C45 로드여도 통과한다(여유 각 0.22° / 0.32°).
   - 상한(YAML)은 경사로 길게 뺀 다리를 평지 신장 0.40 m의 보로 계산해 2.1~2.4배 단단하게 본다. 브래킷·가이드 틈 유연성은 두 모델 모두 빠져 있다(실제는 더 무르고 힘은 더 작다). 그래서 상한을 설계값으로 쓸 이유가 약하다.
   - 로드가 **C45급으로 확인**되고 상한까지 보수적으로 덮으려면 **2.8° / 3.9°**로 줄인다.
   - **20MnV6급으로 확인**되면 다음처럼 넓힐 수 있다.
     - 앞뒤: D8 Θ 3.5°까지(할선이면 행정 한계, YAML 고착이면 3.46°로 경계)
     - 좌우: 할선 기준 5.5°까지, YAML 기준 4.7°까지
6. **고착점 재설정(3.10.7)은 앞뒤 한계를 올리지 않는다(기준 A).**
   - 최대 하중(레벨링 끝값)은 재설정 **전에** 이미 걸린다. 앞들림에서는 재설정 첫 단계에 긴 후방 다리가 오히려 더 받는다(YAML +4.4 kN, 할선 +0.6 kN). 그래서 재설정을 넣은 한계가 조금 낮다.
     - YAML·C45: 2.94° → 2.74°
     - 할선·C45: 3.62° → 3.52°
   - 대신 **작업 중 지속 하중을 36 → 9~12 kN(YAML) / 26 → 9~15 kN(할선)으로 줄인다.** 그 효과는 다음과 같다.
     - 잠김 350 bar가 겹칠 때 로드 여유: YAML·C45 앞내림 3.5° FL에서 0.86 → 2.27
     - 피스톤 가이드 지속 면압: 145 → 41 MPa
   - **선택 기준 B**(레벨링 끝 1회성 최대는 항복만 넘지 않으면 됨, 지속 하중은 1.5)를 쓰면 재설정 적용 시 앞뒤 한계가 오른다.
     - 할선·C45: 행정 한계까지
     - YAML·C45: 앞들림 3.60°(고착이면 3.32~3.48°)
   - 기준 B를 쓸지는 설계 기준 결정이다(사용자·제조사).
7. **가장 약한 곳은 여전히 가이드다.** CAD 피스톤 폭 20 mm로 보면 다음과 같다.
   - 잠정 한계 앞내림 3.2°의 피스톤 면압은 할선 74 / YAML 105 MPa(중심 모델)다. 일반 가이드 링 허용값(동적 40 MPa, 정적 상한 100 MPa, 가정)을 넘는다.
   - 40 MPa를 지키는 경사는 앞뒤 2.4~2.7°, 좌우 3.5~3.9°다.
   - CAD에 가이드 링·스톱 튜브 세부가 없다. 그래서 **제조사 자료 없이는 판정할 수 없다**(10절 질문 2·3).
8. **잠김 350 bar(364 kN) 점검**(같은 횡하중 + 364 kN, 항복 없음)은 다음과 같다.
   - YAML·C45는 잠정 한계에서 0.95~0.96으로 미달이다. 앞뒤는 재설정으로 해소된다(2.1 이상). 좌우는 재설정 효과가 없어 거의 그대로다(재설정 뒤 FR: 좌우 +4.4° 1.01, +5.5° 0.96).
   - 할선이면 잠정 한계에서 1.30 이상이다.

### 3.2 횡하중: dynamics 3.10 행렬 (볼 중심 높이, 기체 x·y)

- **기구**(3.10.2): 크롤러 위에서 기울어진 채 패드가 고착된다. 그 뒤 수평으로 돌리면 앞뒤(또는 좌우) 패드 사이에 $\delta\approx \tfrac{L}{2}(\beta^2-\theta_s^2)$의 어긋남이 생긴다. 이 어긋남이 두 패드의 직렬 접선 강성에 걸려 내력이 된다. 힘은 대략 경사의 제곱에 비례한다.
- **값**: 세 단계 × 네 마스트 × 시드·지연·β 행렬의 최대(YAML $k_t$ 32~36회/점, 할선 6회/점)다. 레벨링 끝과 동적 최대(첫 접촉 ~ 완료 + 10 s, 1 ms 표본)를 모두 가져왔다. **구조 점검에는 동적 최대와 그 순간의 축력**을 쓴다. 동적 최대는 레벨링 끝보다 최대 +1.6 kN 크다.
- **두 $k_t$ 모델**:
  - **할선 $k_t(e)$**: series(경사별 레벨링 신장 e의 스위블 보 굽힘, 콘크리트 3.24×10⁸ N/m)다. 이 스크립트의 보로 다시 계산한 값이 dynamics 값과 1.8×10⁻³ 안에서 같다. **최선 추정**이다.
  - **YAML $k_t$**: 8.51 / 8.40×10⁶ N/m(평지 e 0.40 m의 보)다. **상한**이다.
- 이 스크립트는 3.10의 행렬을 run 단위로 다시 모았다. dynamics 보고 표(`report.*.max_kN`)와 **차 0 kN**이다(두 범위, 두 $k_t$, 레벨링 끝·동적 최대).

**3.7° 앞내림(개정 1의 기준점) 다시 보기**: 상단, `R:BS_hold`, 레벨링 끝 FL / FR / RL / RR [kN]

| 경우 | 값 | FL 로드 여유 C45 / 20MnV6(e 0.669, 동적 최대) |
|---|---|---|
| YAML, μ 0.5(개정 1이 쓴 36 kN) | 36.5 / 35.9 / 36.4 / 36.1 — **후방 μN에 잘림** | 1.04 / 1.54 |
| YAML, μ 5(고착 수요) | 44.5 / 44.1 / 43.9 / 44.4 | 0.89 / 1.32 |
| 할선, μ 0.5 | 29.2 / 29.0 / 28.7 / 29.4 — 잘리지 않음 | 1.33 / 1.96 |

- 개정 1의 보정 계수 0.838(= 36 / 43)은 잘린 값을 고착 값으로 본 것이었다. 그래서 폐기한다.
- 앞뒤 경사는 후방 μN이 전방까지 묶어서(Σ$F_t$ = 0) 상한이 우연히 맞았다.
- 좌우 경사는 각 쌍에 무거운 전방이 있어 전방이 $\mu N_F$ ≈ 59 kN까지 갈 수 있다. 그래서 개정 1이 과소 추정했다(43.8 → 54.7 kN).

### 3.3 시뮬레이션 사이 각도: 축척한 고착 기구학 (한계 각 계산용)

시뮬레이션은 두 마름모의 꼭짓점(3.2/3.5°, 4.4/5.5°)만 있다. 한계 각을 찾으려면 연속 곡선이 필요하다. 그래서 다음처럼 만들었다.
1. 개정 1의 고착 패드 기구학 모델(평면 강체 이동 제거)에 $k_t$ 모델(YAML 또는 할선 $k_t(e(\theta))$)을 넣는다.
2. **잠정 한계 꼭짓점의 시뮬레이션 동적 최대에 다리별로 축척**한다. 이 꼭짓점은 미끄럼이 없다(후방 이용률 ≤ 0.94). 축척 계수는 0.99~1.07이다.
3. μN 상한을 둔다. μ 0.5 × 정적 패드력 × cos(경사)다.
   - 앞뒤 경사는 Σ$F_t$ = 0이라 네 패드 모두 후방 μN 중 작은 값(35.9 kN)으로 자른다.
   - 좌우 경사는 다리별로 자른다.
4. "YAML 고착" 변형은 μN 상한 없이 계산한다(정지 마찰이 μ 0.5보다 클 때의 상한).

검증(D8 검증 꼭짓점에서 모델 대 시뮬레이션):
- μN 상한 모델 대 μ 0.5 동적 최대: 차 ≤ 4.6 %
- 상한 없는 모델 대 μ 5 고착 수요: 차 ≤ 4.3 %
- 앞뒤 YAML의 상한 모델은 35.9 kN이고 시뮬레이션 동적 최대는 36.1~37.5 kN이다. 이 경우 상한 모델이 1~4 % 작다(미끄럼 경계의 동적 넘침).

## 4. 계산 모델 (개정 1과 같음)

- **배럴–로드 보:** 브래킷 볼트 무게중심(z 0.047)에서 고정한 계단 단면 Euler-Bernoulli 보다. 배럴(Ø160/Ø115)은 배럴 하단까지, 그 아래는 로드(Ø110)다. 요소 80개이고, 횡강성이 YAML `k_lateral_leg_swivel_N_m`을 1.4×10⁻⁵ 안에서 재현한다.
- **하중점:** 스위블 볼 중심, 끝 모멘트 0(프로젝트 결정).
- **로드 모멘트:** 글랜드 반력점에서 $M = F\,a$($a$ = 글랜드 중심 → 하중점)다.
- **P-δ:** $M_{tot} = (F a + P(\delta + e_0))/(1-P/P_{E,sway})$다. $e_0$ = 초기 굽음 L/1000 + 가이드 틈 0.3 mm에 의한 기울기다(**가정**).
- **좌굴:** 같은 보의 선형 좌굴 고유값이다. 흔들림 모드(고정–자유)를 지배 경우로 두고, Johnson 포물선을 적용했다.
- **가이드 반력:** 중심 모델은 $R_p = M_{gl}/b$, $R_{gl} = R_p + F$다. 가장자리 모델은 비교용이다. 면압 = R/(지름 × 지지 폭)이다. 피스톤 폭 20 mm는 CAD 값, 글랜드 띠 40 mm는 **가정**이다.
- **배럴:** 맨 아래 볼트 열 단면의 굽힘 + Lamé 원주·반경 응력의 von Mises다.
- **허용 횡하중:** 축력이 정해지면 로드 응력이 F에 대해 1차식이다. 그래서 $F_{allow}$ = (항복/요구 여유 − σ(0)) / (dσ/dF)로 구한다.

  - $\max(0.5,\ 0.5 + F_{res}/F)\times F$
  - $F_{res}$ = 재설정 잔류 약 10 kN
- 이렇게 되면 기준 A의 앞뒤 한계 자체가 오른다. 다만 확인할 것이 있다. 중간 자세에서 크롤러가 이미 떴는지, 그때 $F_{min}$·자세 제약이 맞는지다.

## 10. 제조사 질문

1. **로드 소재와 열처리**(C45 / 20MnV6 / 42CrMo4, 항복·인장 강도), 크롬 도금 두께. 로드에 허용하는 횡하중 또는 설계 기준(EN 13000, ISO 등)은 무엇인가? **이 답 하나로 한계 각이 0.5~1.0° 바뀐다**(6절).
2. **가이드 구성:** 글랜드 부시·가이드 링 재질, 폭, 개수와 위치, 피스톤 가이드 링 폭, 허용 면압(동적·정적).
3. **스톱 튜브와 최소 겹침:** 완전 신장에서 피스톤–글랜드 지지 간격은 얼마인가? CAD는 피스톤 20 mm에 스톱 튜브가 없어 73 mm다. 스트로크 680 mm가 맞는지도 확인한다.
4. **스위블 패드:** 볼 중심 높이, 볼·소켓 치수, 허용 기울기, 패드–로드 결합부(CAD의 Ø80 목)의 실제 단면.
5. **브래킷:** 볼트 규격·등급, 측판 두께, 용접 사양. 75 kN·m급 모멘트(좌우 5.5°, 상한)를 설계에서 고려했는가? 브래킷·박스의 횡강성 자료가 있으면 $k_t$ 추정이 좁혀진다.
6. 경사 운용(앞뒤 3.5°, 좌우 5.5°)을 설계 조건에 넣었는가? 넣었다면 그때 가정한 패드 접선력은 얼마인가?
7. **(신규) 하중 구분:** 레벨링 끝에 한 번 걸리는 횡하중(수 초~수십 초)과 작업 중 지속 하중에 다른 안전율을 쓰는가? 1회성 하중에 항복 여유 1.0~1.25를 허용하면 재설정 동작으로 앞뒤 한계를 올릴 수 있다(6절 기준 B).
8. **(신규) 잠김 350 bar와 횡하중의 조합:** 실린더 최대 부하 시험 압력 350 bar에서 로드에 횡하중이 함께 걸리는 경우를 검토했는가? 좌우 경사에서는 횡하중이 재설정으로 줄지 않는다(7절).
9. **(신규) 패드–바닥 마찰:** 패드 바닥 재질·형상(돌기 유무)과 정지 마찰 계수 자료가 있는가? 정지 마찰이 0.5보다 크면 앞뒤 경사 하중의 상한(후방 μN)이 올라간다.
