## 4. 도면 기준으로 바뀌는 값

### 4.1 면적과 힘 (다리별, SI)

면적은 π/4·d²로 계산했다(`cyl_drawing_values.py`). 압력은 210 bar(이동 중 릴리프)와 350 bar(잠김 최대)를 썼다. 정적 하중은 YAML `superstructure.auger_levels.top.static_leg_loads_N`(4점 강체 스프링 가정)이다.

| 항목 | 현재 YAML (공통) | 전방 FL·FR (도면) | 후방 RL·RR (도면) |
|---|---|---|---|
| 보어 / 로드 / 튜브 [m] | 0.115 / 0.110 / 0.160 | 0.130 / 0.110 / 0.160 | 0.110 / 0.090 / 0.137 |
| A_p [m²] | 1.03869e-2 | **1.32732e-2** (×1.278) | **9.50332e-3** (×0.915) |
| A_ann [m²] | 8.83573e-4 | **3.76991e-3** (×4.27) | **3.14159e-3** (×3.56) |
| A_p / A_ann | 11.76 | 3.52 | 3.03 |
| 신장 포화 210 bar × A_p [kN] | 218.12 | 278.74 | 199.57 |
| 수축 포화 210 bar × A_ann [kN] | 18.56 | 79.17 | 65.97 |
| 잠김 한계 350 bar × A_p [kN] | 363.54 | 464.56 | 332.62 |
| k_oil(0) = β A_p / L_dead, β 1 GPa, L_dead 0.05 m [N/m] | 2.077e8 | 2.655e8 | 1.901e8 |
| k_oil(s_max) = β A_p / (L_dead + s_max) [N/m] | 1.423e7 (s 0.68) | 1.770e7 (s 0.70) | 1.267e7 (s 0.70) |
| 로드 축강성 비(A_rod) / 굽힘 I 비 / 단면계수 Z 비 | 1 / 1 / 1 | 1 / 1 / 1 | 0.669 / 0.448 / 0.548 |
| 정적 머리측 압력(상단, FL/FR/RL/RR) [bar] | 113.8 / 111.9 / 70.0 / 68.2 | 89.1 / 87.6 | 76.5 / 74.6 |

- 신장 포화는 후방이 199.6 kN으로 내려간다. 기존 들어 올림 기준 동적 피크 141.0 kN(`06_analysis/00_dynamics/leg_extension_loads.json`)은 여전히 그 아래다. 다만 상한 판정 "실린더 힘 < 218 kN"은 다리별 값(278.7 / 199.6 kN)으로 바꿔야 한다.
- 수축 포화가 18.6 kN에서 66~79 kN으로 크게 오른다. 이 값을 쓰는 판정(포화 법칙 C, V11b)은 다시 봐야 한다.
- 면적비가 11.8에서 3~3.5로 내려가므로 YAML `actuator.rod_side_chamber_model: "neglected (head side only)"`의 근거가 약해진다. 이중 파일럿 체크로 두 챔버가 모두 잠기면 로드측 유압유 기둥도 강성을 보탠다. 크기 예: 전방 수축 상태에서 β A_ann / (L_dead + 0.70) ≈ 5.0e6 N/m. 판정은 hydraulics-expert가 한다.
- 펌프: 네 다리 머리측 면적 합이 4.1548e-2 → 4.5553e-2 m²가 된다. 22.67 mm/s로 동시에 펴려면 61.95 L/min이 필요하다. 펌프는 60.2 L/min이다(2.9 % 부족). 펌프 유량으로 네 다리가 동시에 낼 수 있는 속도는 22.03 mm/s이고, 이때 700 mm를 펴는 데 31.8 s가 걸린다. 지금 YAML의 "56.5 L/min 필요 — 일치" 점검은 깨진다.
