## 1. 실린더 닫힌 길이와 완전 수축 패드 높이

### 1.1 전제와 정의

- 사용자 결정(2026-10-24): 아우트리거 부착 위치는 STEP과 같다. 다리 축 xy·기구학(A)·D8·규칙 A는 CAD 값을 유지한다(CLAUDE.md Q-C2 갱신).
- 이 문서의 해석: **장착판(볼트 구멍·판 하단)의 높이가 CAD와 같다.** 근거는 다음과 같다. 전방 볼트 패턴(2×6-ø26, 피치 25-50-50-95-50-50-25, 판 길이 345, 판 상단 ~ 캡 끝 270)이 도면과 CAD에서 0.1 mm 안으로 같다. 후방도 피치 70·판 길이 340·판 상단 ~ 캡 끝 250이 같다(`cad_cylinder_vs_drawing.md` 2절).
- 닫힌 길이는 이 실린더가 핀 장착이 아니라 **플랜지 장착**이라 핀–핀 길이가 없다. 다음 두 길이로 비교한다.
  - 전장 = 패드 바닥 ~ 캡 끝
  - 장착면–로드 끝 = 패드 바닥 ~ 장착판 하단
- 도면은 수축 상태로 그려져 있다(피스톤이 140 구간 경계에 걸침, 패드부 170이 행정 700보다 짧음).

### 2.5 YAML 가정(1×10⁹)과 비교, 다리 강성 변화

YAML 운용점 $k_n$(FL 2.591×10⁷, RL 1.950×10⁷ N/m)과 $k_{lock}$(3.393 / 2.640×10⁷)에서 $k_{frame}$만 바꿨다: $1/k' = 1/k - 10^{-9} + 1/k_{frame}$. 지금 YAML에서 프레임 몫은 다리 컴플라이언스의 전방 2.6 %, 후방 2.0 %다.

| 다리·경우 | $k_{frame}$ / YAML | 다리 컴플라이언스 중 프레임 몫 | $k_n$ 변화 | $k_{lock}$ 변화 |
|---|---|---|---|---|
| 전방 상한 | 0.74 | 3.5 % | −0.9 % | −1.2 % |
| **전방 중앙** | **0.11** | **19.4 %** | **−17.3 %** | **−21.5 %** |
| 전방 하한 | 0.067 | 28.5 % | −26.6 % | −32.1 % |
| 후방 상한 | 7.6~8.7 | 0.2~0.3 % | +1.7~1.8 % | +2.3~2.4 % |
| **후방 중앙** | **1.2~1.5** | **1.3~1.7 %** | **+0.3~0.6 %** | **+0.4~0.9 %** |
| 후방 하한 | 0.19~0.23 | 7.8~9.5 % | −6.0~−7.7 % | −8.0~−10.1 % |

- 판정(메인 세션 문턱): **전방은 중앙 1.1×10⁸이 "1×10⁸ 근처"이므로 R8 재판정 강성 감도 사례에 넣기를 권고한다.** 감도 값은 전방 $k_{frame}$ = 1×10⁸ N/m(중앙)과 6.7×10⁷ N/m(하한)이다. 후방은 중앙이 1×10⁹보다 크므로 **가정 유지**다.
- 전후방이 크게 다르므로 YAML의 공통 스칼라 `actuator.frame_stiffness_N_m` 하나로는 표현이 안 된다. 다리별 키로 나누기를 권고한다(키 변경은 Params.sha256 변경 → 1.4절과 같이 묶어서 하는 편이 낫다).
- 참고: 전방만 $k_{lock}$ −21 %이면 heave 기준 강성 합이 약 −12 %, 진동수가 약 −6 %다(감쇠 기준 모드 8.88 Hz → 약 8.3 Hz, **추정**). 1.4절의 $e_{op}$ 변화($k_n$ −10~−13 %)와 같은 방향이라 겹치면 더 커진다.

### 2.6 방향 결합(수평 성분)

팔이 휘면 끝이 수직으로 움직일 뿐 아니라 **기울어져** 실린더 축이 함께 기운다. 패드가 지면에 고착돼 있으면 이 기울기가 패드에 접선 변위를 강제한다. 접선력 ≈ $k_t$ × 기울기 × (보 중립축 ~ 지면)으로 어림했다. $k_t$는 YAML 값(전방 7.15×10⁶, 후방 3.71×10⁶ N/m)이고, 거리는 전방 1.16 m, 후방 1.63 m다.

| 다리·경우 | 기울기 [rad / 100 kN] | 패드 수평 변위 [mm / 100 kN] | 고착 시 접선력 [kN / 100 kN] | 방향 |
|---|---|---|---|---|
| 전방 상한 / 중앙 / 하한 | 2.5×10⁻⁴ / 1.34×10⁻³ / 1.91×10⁻³ | 0.29 / 1.56 / 2.22 | 2.1 / **11.2** / 15.9 | 팔 길이 방향(대각), 패드가 바깥으로 밀림 |
| 후방 상한 / 중앙 / 하한 | 1.0×10⁻⁵ / 1.3×10⁻⁴ / 6.4×10⁻⁴ | 0.02 / 0.21 / 1.04 | 0.06 / 0.8 / 3.9 | 기체 y(바깥쪽) |

- 전방은 결합이 크다. 정적 하중(약 118 kN)이 패드 접지 뒤에 쌓이면 중앙 경우 약 13 kN의 바깥 방향 접선력이 두 앞 패드에 대칭으로 생긴다. 자세에는 거의 영향이 없다(대칭 내력). 대신 로드 굽힘(`leg_rod_lateral_check`, 앞내림 접선력 16.5~36.5 kN 규모)에 더해질 크기다.
- 이 결합은 지금 L1 모델(실린더 축이 상부체에 강체 고정)에 없다. 넣을지는 dynamics 판정이다(아래 위임).
