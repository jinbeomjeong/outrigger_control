# 아우트리거 유압 회로 해석 (2026-10-19)

원본: [hydraulic/outrigger_circuit.jpg](hydraulic/outrigger_circuit.jpg) (사용자 제공 회로도). 아래는 회로도 기호를 읽은 해석이며, "확인 필요"로 표시한 항목은 기호만으로 확정하지 못한 것이다.

## 구성 요소

| 구성 | 회로도 표기 | 해석 |
|---|---|---|
| 펌프 | P6, 60.2 L/min, 30 cc | 고정 용량 펌프. 60.2 L/min ÷ 30 cc ≈ 2,000 rpm 기준 토출량 |
| 흡입 체크 | 펌프 출구 스프링 체크 | 역류 방지 |
| 배관 | P 1/2", T 3/4", A/B 3/8", 호스 ② | 밸브 블록 ↔ 실린더 사이 3/8" 호스 |
| 방향 제어 밸브 | 4섹션 뱅크 JackUp(Front_L / Rear_L / Front_R / Rear_R) | 섹션마다 4포트 3위치 스풀. 화살표 붙은 솔레노이드(비례 전자 조작으로 보임) + 수동 레버. 중립에서 A·B 차단 |
| 섹션 압력 보상기 | 각 섹션 아래 스프링 밸브 + 점선 신호 | 로드 센싱(LS) 압력 보상형으로 보임 — 유량이 부하 압력과 무관하게 스풀 개도로 정해짐 (확인 필요) |
| LS 셔틀 | 각 섹션 점선 셔틀 체크 | 최고 부하 압력을 LS 라인으로 선택 |
| 릴리프 | 210 bar | 시스템(LS) 최고 압력 210 bar |
| 파일럿 공급 | 필터 + 감압 밸브, 상단 라인 | 비례 솔레노이드 파일럿 압력 공급 |
| 계기 | M 포트, 압력계 400 bar(눈금 범위), 압력 스위치/센서 | 400 bar는 게이지 눈금이며 설정 압력이 아님 |
| 실린더 | Jackup ×4, 로드측·헤드측 두 포트 | **복동 실린더** |
| 로크 밸브 ① | 실린더에 붙은 블록, 교차 파일럿 체크 2개 | **이중 파일럿 체크(dual PO check)를 실린더에 직결**. 중립에서 두 챔버 모두 잠김 |

## 시뮬레이션에 주는 의미

| 항목 | 값·판단 | 영향 |
|---|---|---|
| 실린더 형식 | 복동, 헤드측·로드측 모두 PO 체크로 잠김 | 이전 질문 F3 답. 잠긴 상태 강성에 로드측 기름이 직렬·병렬로 더해짐(로드측 환형 면적 8.84×10⁻⁴ m²로 작음) |
| 로크 밸브 위치 | 실린더 직결 | 이전 질문 F4 답. **호스 ②는 잠긴 체적 밖** → 레벨링 후 다리 강성 = 실린더 내부 기름 기둥(+블록 통로)만. 사체적 L0가 작다는 가정(0.05 m)을 지지 |
| 최대 압력 | 210 bar | 헤드측 최대 힘 21 MPa × 1.0387×10⁻² m² = **218 kN/다리** (정하중 최대 119 kN → 약 115 bar). 로드측(수축) 최대 힘은 18.6 kN |
| 신장 속도와 펌프 유량 | 22.67 mm/s × 헤드 면적 = 14.1 L/min/다리, 4개 동시 56.5 L/min | 펌프 60.2 L/min과 맞음 → "0→680 mm 30 s, 네 다리 동시"가 펌프 용량으로 뒷받침됨(여유 약 6 %) |
| 유량 제어 | 비례 + 압력 보상(추정) | 이동 중 속도는 부하와 무관하게 명령에 비례 → **L1(속도 제한 위치 모터)이 이동 구간을 잘 근사**. 다리별 독립 속도 명령 가능 |
| 잠긴 상태 | PO 체크 누설 수준 | 레벨링 후에는 실린더가 기름 스프링으로 동작(L2 강성 모델의 전제와 일치) |

## 압력 거동 (사용자 설명, 2026-10-19)

1. **이동 중**: 기름은 파일럿 체크 밸브를 지나 실린더를 UP/DOWN 한다. 실린더 압력은 부하만큼 오르며, MCV(메인 컨트롤 밸브) 릴리프 **210 bar**에는 실린더가 끝까지 신장·수축해 멈췄을 때만 도달한다. 중간 위치에서 멈추면 210 bar까지 오르지 않는다.
2. **잠긴 정지 상태**(장비가 들린 채 실린더가 움직이지 않음): 외력 진동, 굴착 동작 중 장비 뒤틀림 등으로 실린더 내부 압력이 변하며 **최대 350 bar**(실린더 최대 부하 시험 압력)까지 예상된다.
3. **350 bar를 넘을 경우** 제조사는 파일럿 체크 밸브를 **카운터 밸런스 밸브**로 바꿀 계획이다. 카운터 밸런스 밸브를 쓰면 내부 부하가 350 bar를 넘지 않는다. 다만 순간 뒤틀림·충격으로 생기는 과압은 막을 수 없다.
4. **압력 센서**는 ① 블록(실린더 직결 로크 밸브)에 있다. 로크 밸브가 기름을 가두므로 임의 위치에서 멈추면 센서는 그때의 부하 압력을 계속 받는다. 다시 움직이면 압력이 내려갔다가 부하만큼 다시 오른다.

| 상태 | 압력 상한 | 헤드측 힘 상한 (A = 1.0387×10⁻² m²) | 로드측 힘 상한 (A = 8.84×10⁻⁴ m²) |
|---|---|---|---|
| 이동 중 (MCV 릴리프) | 210 bar | 218 kN | 18.6 kN |
| 잠긴 정지 (시험 압력 / 카운터 밸런스 설정) | 350 bar | 364 kN | 30.9 kN |
| 정하중 (수평, 경우 C) | 약 70~115 bar | 71~119 kN | — |

시뮬레이션 해석:
- 이동 중 구동기 힘은 210 bar 상당(218 kN)에서 포화한다. 부하가 이를 넘으면 그 다리는 멈춘다(L1 모터 힘 제한으로 근사).
- 잠긴 상태의 압력 = 센서 값 = 실린더 힘/면적. 외란 시나리오에서 **350 bar 초과 여부**가 판정 지표다. 파일럿 체크 회로는 초과 시 제한이 없고(손상 위험), 카운터 밸런스 회로는 350 bar에서 릴리프처럼 다리가 밀린다(힘 포화 + 위치 이동).
