## 3. 잠긴 상태 실린더 모델

### 3.1 챔버 체적과 상태방정식

$$V_A(s)=V_{0A}+A_As,\qquad V_B(s)=V_{0B}+A_B(s_{l}-s)$$

챔버마다 **기름량** $m$(대기압에서의 액체 체적 [m³])을 상태로 둔다. 기름량 $m$이 체적 $V$를 채울 때 압력은 다음 식의 해다.

$$V=m\,e^{-(p-p_{atm})/\beta_L}+m\,r\left(\frac{p_{air}}{p}\right)^{1/n},\qquad r=\frac{x_{air}}{1-x_{air}}$$

공기가 없으면($x_{air}=0$) 닫힌 해 $p=p_{atm}+\beta_L\ln(m/V)$다. $p<p_{cav}$이면 캐비테이션으로 보고 $p=p_{cav}$로 둔다(빈 공간은 $V$가 줄면 자연히 메워진다). 연속 방정식은 $\dot m=Q\,m/V_f(p)$이고, $x_{air}=0$일 때 이것은 표준식 $\dot p=\frac{\beta}{V}(Q-\dot V)$의 **정확한 적분**이다. 잠긴 챔버($Q=0$)의 압력은 $s$만의 함수가 되어 스텝 오차가 없다.

| 기호 | 뜻 | 단위 |
|---|---|---|
| $m$ | 챔버 기름량(대기압 액체 체적) | m³ |
| $\beta_L$ | 액체·관 벽·잔여 유연성을 합친 덩어리 체적탄성계수 | Pa |
| $x_{air}$, $p_{air}$, $n$ | 자유 공기 체적비(기준 $p_{air}$ = 1 bar abs), 폴리트로프 지수 | -, Pa abs, - |
| $V_f(p)$ | 기름량 $m$의 압력 $p$에서 체적(액체 + 공기) | m³ |
| $\beta_e=V_f/(-\partial V_f/\partial p)$ | 유효 체적탄성계수 | Pa |

**β의 직렬 분해(설명용).** $\frac{1}{\beta_e}=\frac{1}{\beta_{oil}}+\frac{1}{K_{wall}}+\frac{V_g/V}{n\,p}+\frac{V_{hose}}{V\,K_{hose}}+\frac{1}{\beta_{res}}$.

| 성분 | 값 | 비고 |
|---|---|---|
| $\beta_{oil}$(HM46 등온 40 °C / 80 °C) | 1.58 / 1.33 GPa | 조사 |
| $K_{wall}$(Ø160/Ø115 Lamé) | 30.5 GPa | `actuator_L2_feasibility.md` 2절 |
| 공기 0.5 %(1 bar abs 기준) | 115 bar에서 3.7×10⁻¹² Pa⁻¹(무시), 5 bar abs에서 β_e ≈ 0.3~0.4 GPa, 2 bar abs에서 ≈ 0.08 GPa | **저압 챔버에서만 지배적** |
| 호스 | 잠김 상태에서는 0(POC가 실린더 직결). 이동 중 라인 A가 붙으면 등가 체적 $V_{hose}\beta_L/K_{hose}$ = 5.9×10⁻⁴ m³(가정, $V_A(e_{op})$의 +12.5 %) | `moving_extra_volume_head_m3` |
| 잔여 $\beta_{res}$ | 1.0 GPa를 맞추려면 3.0 GPa(온도·단열/등온·실·블록 등 미지분) | 사용자 결정 1.0 GPa가 보수적임을 보여 줌 |

기준 실행은 $\beta_L$ = 1.0 GPa, $x_{air}$ = 0이다(`dynamics_model.md`의 모든 기준값과 같은 전제). 공기는 저압 챔버(로드측, 들린 다리의 헤드측) 감도로만 쓴다.

### 3.2 로드측 챔버와 압력 센서

- 잠긴 로드측은 리턴 배압(가정 2 bar g)에서 갇힌다. 하중이 늘어 피스톤이 약 0.1 mm만 들어가도($\Delta s=V_Bp_{B0,abs}/(\beta A_B)$) 로드측이 팽창해 **0 bar abs로 캐비테이션**된다(S1, 두 도구 모두 $p_B$ = −1.0 bar g). 힘 영향은 $\le p_{B0}A_B$ = 0.27 kN이다.
- 하중이 줄면 피스톤이 나오며 로드측이 압축된다. 로드측 강성 $\beta A_B^2/V_B$ = 2.69×10⁶ N/m($e_{op}$)가 헤드에 병렬로 붙어 하중 변화의 약 10 %를 가져간다(한쪽 방향, `dynamics_model.md` 2.3절과 같은 결론). S5에서 −40 kN 감하중 때 헤드 판독이 실제보다 **4.3 kN 덜 내려간다**.
- **수축 뒤에는 로드측에 POC-A 파일럿 압력(가정 ≈ 31 bar g)이 갇힌다**(S2r). 그러면 같은 하중에서 헤드 압력이 113.1 → 116.0 bar로 올라 판독이 **+3.0 kN** 틀린다.
- 따라서 센서 모델은 $F_{sensor}=p_{A,g}A_A$(헤드만, 현 YAML)와 실제 로드 힘 $F=p_{A,g}A_A-p_{B,g}A_B-F_f-c_h\dot s$를 **따로 출력**한다. 로드측 센서가 있으면 $p_{A,g}A_A-p_{B,g}A_B$를 쓴다(Q-H2).

### 3.3 누설

$Q_{int}=C_{int}(p_A-p_B)$(피스톤 실, A → B), $Q_{ext,A}=C_{ext}\max(p_{A,g},0)$(POC 시트·글랜드 → 탱크). 기준값 0. 장시간 유지 시험에서만 2.2절 값을 쓴다(레벨링 수십 초에서는 무시 가능, `actuator_L2_feasibility.md` 3.4절).

### 3.4 실 마찰(LuGre, 기름 기둥과 병렬)

> 2026-10-25 주: S8 구현은 LuGre를 쓰지 않았다. 기름 스프링에만 병렬인 Coulomb 복귀 사상이고, 이유(파라미터 데이터 없음, 판정에 들어가는 것은 띠 폭 $2F_s$와 이력)는 [s8_seal_friction_counterbalance.md](s8_seal_friction_counterbalance.md) 2.1절에 있다. 이 절은 초판 참조 구현(`l2_cylinder.py`)의 기록이다.

$$g(v)=F_c+(F_s-F_c)\,e^{-(v/v_s)^2},\quad \dot z=v-\frac{\sigma_0|v|}{g(v)}z,\quad F_f=\sigma_0z+\sigma_1\dot z$$

| 기호 | 뜻 | 기본 |
|---|---|---|
| $F_s$, $F_c$ | 정지(이탈), Coulomb 마찰 | V15 모드: $F_c=F_s$ ∈ {0, 2, 5, 12 kN}(**초판 값**. S8 구현은 Coulomb 복귀 사상, {0, 2, 4, 8 kN}, s8 문서 2절) |
| $v_s$ | Stribeck 속도 | 5 mm/s |
| $\sigma_0$, $\sigma_1$ | 강모 강성, 강모 감쇠 | 아래 규칙 |
| $v$ | 피스톤 상대 속도 $\dot s_p$ | |

- 이산 갱신: 한 스텝 동안 $v$가 일정하면 $z$ 식은 선형이다. $\lambda=\sigma_0|v|/g$, $z_{ss}=g\,\mathrm{sign}(v)/\sigma_0$일 때 $z_{n+1}=z_{ss}+(z_n-z_{ss})e^{-\lambda\Delta t}$(**정확 지수 갱신**, 어떤 Δt에서도 $|\sigma_0z|\le g$ 유지).
- 압력 의존(선택): $F\leftarrow F\,(1+K_p(p_{A,g}-p_{ref}))$, Kühnlein $K_p$ ≈ 0.004 /bar. 기본은 끔.
- $\sigma_0$ 선택 규칙(5.5절 시험 근거):
  - **L2b-NSC(로드 질량이 접촉에 묶이고 $k_g$가 힘 법칙 안의 직렬 스프링)**: 마찰이 질량 없는 내부 절점에 있어 Chrono가 보는 강성은 $k_s$ 이하다. $\sigma_0$ = 1×10¹⁰(미끄럼 전 변위 1.2 µm @12 kN, V15의 "강체 잠김"과 같은 뜻)을 써도 Δt 1×10⁻⁴ s에서 안정이다.
  - **별도 로드 바디(L2-SMC, 들린 다리)**: 강모 모드 $\sqrt{\sigma_0/m_r}$이 그대로 보인다. $\sigma_0$ 1×10¹⁰은 9.7 kHz로 Δt 1×10⁻⁴ s에서 떨림(압력 고주파 잡음 2배)을 만든다. **$\sigma_0$ 2×10⁸ N/m, $\sigma_1$ 1.3×10⁵ N·s/m(강모 모드 ζ ≈ 0.3)** 을 쓴다. 미끄럼 전 변위는 60 µm @12 kN이다.
- 초기 $z$ = 0(정지 마찰 초기 상태 미정, `chrono_build_plan.md` S8 위험 ①).

### 3.5 감쇠 $c_h$의 위치

YAML $c_{ax}$는 축 스프링 전체($k_{ax}=k_{oil}\oplus k_g$)에 병렬인 대시포트로 heave ζ를 맞춘 값이다. 이 모델의 $c_h$는 **기름 기둥에만 병렬**(피스톤 상대 속도)이므로, 같은 모드 감쇠를 주려면

$$c_h=c_{ax}\left(1+\frac{k_{oil}(e_{op})}{k_g}\right)^2 \quad(\text{FL: } 1.2238\,c_{ax}=3.419\times10^4\ \text{N·s/m 잠김},\ 1.140\times10^5\ \text{이동})$$

으로 둔다(값은 다리별 상수). 단일 다리 해석 ζ 0.02788과 시뮬레이션 0.02787~0.02793이 맞는다(6.3절). 이동 중 $c_h$는 정속 신장에서 압력을 $c_h v/A_A$ = 2.5 bar 올린다(S2 뒤집음 위상 유지 구간 115.85 bar = 113.10 + 2.49(대시포트) + 0.26(로드측 2 → 5 bar g)). 실제 실·점성 손실과 같은 크기지만 근거 없는 가정이다.

## 4. 이동 중 모델

### 4.1 밸브 섹션 Level 1(Chrono 기본)

압력 보상 비례 섹션은 부하와 무관한 유량원으로 본다(`hydraulic_circuit.md`, L1 근거와 같음).

| 단계 | 식 |
|---|---|
| 명령 | $u$ [m/s, + 신장], $\lvert u\rvert\le v_{max}$ |
| 램프 | $u_v\leftarrow u_v+\mathrm{clip}(u-u_v,\pm a_r\Delta t)$, $a_r=v_{max}/T_r$ = 0.2267 m/s²($T_r$ 0.1 s) |
| 헤드 유량 | $Q_{A,in}=A_Au_v-Q_{relief}(p_A)$(신장: 미터인 보상, 수축: 미터아웃이 보상된다고 **가정**) |
| 로드측 | 이동 중($u_v\ne0$) POC-B가 열리고 라인에 연결: $Q_B=K_{s,B}\sqrt{p_{line}-p_B}$. 신장 때 $p_{line}$ = 탱크(0 bar g), 수축 때 $p_{line}=p_{A,g}/\varphi_{poc}+p_{cr}$(POC-A를 여는 파일럿 압력) |
| 잠김 | $u_v=0$이면 헤드 유량 0(POC-A 닫힘), 로드측 경로 닫힘, $c_h$ = 잠김 값 |
| 선택 | 라인 A 호스 체적(3.1절)을 이동 중에만 붙이고, 붙이고 뗄 때 그 압력의 기름량을 같이 옮긴다(압력 연속) |

수축 시험(S2r)은 같은 법칙으로 유지 구간 속도 −22.674 mm/s, 로드측 31.0 bar g, 정지 뒤 헤드 116.0 bar(로드측 잠김 압력 때문, 3.2절)를 낸다.

### 4.2 POC 개방 조건과 히스테리시스(Level 2, 진단·명세)

각 POC는 Hopsan `HydraulicPilotControlledCheckValve`와 같은 형식이다. 라인 쪽 압력 $p_\ell$, 실린더 쪽 $p_c$, 파일럿 $p_x$(반대 라인)일 때

$$\text{열림: } p_\ell+\varphi_{poc}\,p_x-p_c>p_{cr}\quad(\text{정방향 자유 흐름 또는 파일럿 개방}),\qquad \text{닫힘: } p_\ell+\varphi_{poc}p_x-p_c<p_{cr}-\Delta p_h$$

| 상황 | 필요 조건(가정 $\varphi$ 3.5, $p_{cr}$ 3 bar) | 의미 |
|---|---|---|
| 신장(라인 A 가압, POC-B 파일럿 개방) | $p_{line,A}\ge(p_B-p_{line,B}+p_{cr})/\varphi$ ≈ 수 bar | 쉽게 열린다 |
| 수축(라인 B 가압, POC-A 파일럿 개방) | $p_{line,B}\ge(p_{A}+p_{cr})/\varphi$: 정하중 68~114 bar에서 **20~34 bar** | 로드측 압력이 수축 힘을 $p_BA_B$ = 1.8~3.0 kN 줄이고, 멈추면 그 압력이 갇힌다 |
| 수축 중 과주행 | 미터아웃이 부하를 못 잡으면 $p_B$가 떨어져 POC-A가 닫히고 다시 열린다(채터) | Level 1은 이를 "미터아웃 보상" 가정으로 덮는다. 미터아웃 노치·파일럿 감쇠 오리피스가 필요(Q-H11) |

Level 2(라인 A·B 체적 + POC 2개 + 스풀 미터인/미터아웃 오리피스)는 수축 채터를 볼 때만 쓴다. 이번 기준 응답에는 넣지 않았다.

### 4.3 압력 밸브 법칙(210 bar 릴리프, CB 공통; Hopsan 2.24.4와 같음)

$$x_s=\frac{p_{in,g}-p_{set}+\varphi_{pv}\,p_{pilot,g}}{b},\quad b=C_s+C_f\,(p_{in}-p_{out}),\quad C_s=\frac{\sqrt{p_{nom}}}{k_{cs}},\ C_f=\frac{1}{k_{cf}\sqrt{p_{nom}}}$$

$x_s$에 폭 $\Delta p_h/b$의 유격(play) 히스테리시스를 걸고 1차 지연 τ를 거친 $x\in[0,\ q_{nom}/\sqrt{p_{nom}}]$가 유량 계수다. $Q=x\sqrt{|p_{in}-p_{out}|}$. $k_{cf}$는 "오버라이드 $\Delta p_{ov}$에서 유량 $q$"가 되게 역산한다(`l2_params.valve_kcf`). Hopsan은 $p_{in}$과 파일럿을 **절대압**으로 비교하므로 Hopsan 쪽 설정값은 $p_{set}+p_{atm}(1+\varphi_{pv})$로 옮겨 넣었다.

- 210 bar 릴리프: 섹션이 그 챔버를 먹이는 동안만 유효(MCV 릴리프는 POC 상류). 잠기면 $x$ = 0.
- 이동 중 포화를 "명령 차단"(`dynamics_model.md` 4.4, 218.1 kN에서 $u$ = 0)으로 쓸 수도 있다. 두 방식의 차이는 오버라이드 크기(가정 10 bar)뿐이다.

### 4.4 카운터 밸런스 옵션

헤드측에 CB(릴리프 기능 + 역방향 자유 흐름 체크)를 둔다. 여는 압력 $p_{open}=p_{set}-\varphi_{cb}\,p_{x}$($p_x$ = 라인 B 파일럿). 잠긴 상태에서 라인이 탱크로 열려 있으면($p_x$ = 0) 350 bar g에서 열려 헤드 기름을 내보내고 다리가 밀려 들어간다(되돌아오지 않음).

- **방향 밸브 중립 조건**: CB가 실제로 기름을 버리려면 중립에서 A·B → T가 열려 있어야 한다. 회로도처럼 A·B가 막혀 있으면 CB가 막힌 호스로만 내보내 압력을 거의 낮추지 못한다(Q-H4). 모델은 탱크로 버린다고 가정했다.
- **용량과 응답이 결과를 정한다(6.2.4절)**: 160 kN 계단에서 최대 압력은 가정 CB 400 bar, 대형(120 L/min@+20 bar, τ 5 ms) 376 bar, 이상적(600 L/min, τ 1 ms) 358 bar다. 이 크기의 계단은 피스톤 속도 약 0.3 m/s(헤드 유량 약 180 L/min)를 요구하기 때문이다. 제조사 설명("순간 뒤틀림·충격 과압은 막지 못함")과 같다.
- `dynamics_model.md` 4.4의 강소성 복귀 사상은 이상적 CB의 극한이다. 정적 하중·밀림량에는 쓸 수 있지만, **동적 최대 압력은 과소평가**한다. V17(CB 옵션)에는 4.3절 법칙과 Q-H4 자료를 쓴다.

초기화 `init_static(s, F0, p_B0)`: 잠긴 평형에서 $p_B=p_{atm}+p_{B0}$, $p_A$는 $F_0$을 만들도록 정하고 $m$을 상태방정식의 역으로 정한다. $z$ = 0.

### 5.2 한 스텝 절차(`dynamics_model.md` 4.6의 훅 순서 3단계 "구동기" 안)

1. 밸브 섹션: $u$ → $u_v$(램프), 이동/잠김 판정, 로드측 라인 압력.
2. 압력 밸브: 이전 스텝 압력으로 $x_{rel}$, $x_{cb}$ 갱신(4.3절, 명시적. τ ≥ 1 ms ≫ Δt).
3. 연속 방정식(챔버별, **선형 암시 오일러**):
$$\Delta m=\frac{\Delta t\,\frac{m}{V_f}\left(Q_n-G\,\beta_e\,\frac{\Delta V}{V_{new}}\right)}{1-\Delta t\,G\,\beta_e/V_f},\qquad G=\frac{\partial Q}{\partial p}\le0$$
   $\Delta V$는 피스톤 이동에 의한 체적 변화다. 분모 ≥ 1이므로 어떤 Δt에서도 안정이다. 오리피스 $G$는 $\sqrt{\cdot}$의 기울기(1 kPa 아래는 C¹ 3차 보간).
4. 상태방정식으로 $p_A$, $p_B$(공기 없으면 닫힌 해, 있으면 뉴턴 ≤ 60회, 보통 3~4회).
5. 마찰 $z$ 정확 지수 갱신과 $F_f$.
6. $F=(p_A-p_{ref})A_A-(p_B-p_{ref})A_B-F_f-c_h\dot s_p+F_{stop}$($p_{ref}=p_{atm}$. Hopsan 비교 때만 0).
7. **(지연 보정)** `ChLinkMotorLinearForce`를 쓰면, 확정한 상태에서 한 번 더 미리보기 평가를 해 $F(\hat s=s+\Delta t\,\dot s)$를 링크에 설정한다(`force_preview`, 상태를 바꾸지 않음).
8. 기록: 스텝 n의 상태와 그때 작용한 힘(이전 훅 값), 새로 설정한 힘은 $t_n+\Delta t$ 작용으로 따로.

### 5.6 직렬 절점(L2b-NSC에서 $k_s$를 힘 법칙에 합칠 때)

$k_s$ = 로드 ⊕ 프레임 ⊕ 콘크리트(L2b-NSC 강체 접촉) 또는 로드 ⊕ 프레임(SCM). 링크 신장 $s$가 주어지면 피스톤 위치 $s_p$를 푼다.

$$r(s_p)=F_{int}(s_p)-k_s(s_p-s)=0,\qquad F_{int}=F_h(m(s_p),s_p)-F_f\!\left(\tfrac{s_p-s_{p,n}}{\Delta t}\right)-c_h\tfrac{s_p-s_{p,n}}{\Delta t}$$

$r$은 $s_p$에 대해 단조 감소한다($\partial F_h/\partial s_p=-k_{oil}$, 마찰·대시포트도 감소, $-k_s$). 시작값 $s_{p,n}+(s-s_n)$에서 뉴턴 2~3회면 수렴한다. 해석 미분: $\partial r/\partial s_p=-k_{oil}-\left(\sigma_0\frac{\partial z_{n+1}}{\partial v}+\frac{\sigma_1}{\Delta t}\frac{\partial z_{n+1}}{\partial v}+c_h\right)\frac{1}{\Delta t}-k_s$. 링크 힘 $F=k_s(s_p-s)$. 참조 구현은 수치 미분을 쓴다(`_solve_series`).

## 7. 넘길 선형화 모델

`06_analysis/03_hydraulic/l2_linear_plant.json`(python-control 0.10.2). 모두 정적점 주위 편차, SI, 압력은 게이지다.

**다리 요소**(다리 여러 개를 묶는 선형 모델용, dynamics-expert 10자유도에 그대로 들어간다):

$$\dot p_A=\frac{\beta}{V_A(e)}\left(A_Au_v-A_A\dot s\right),\qquad F=A_Ap_A-c_h\dot s\quad\Longleftrightarrow\quad F=k_{oil}(e)(s_{ref}-s)+c_h(\dot s_{ref}-\dot s),\ s_{ref}=\textstyle\int u_v\,dt$$

| 기호 | 뜻 | 값(FL, $e_{op}$) |
|---|---|---|
| $k_{oil}(e)=\beta A_A/(L_0+e)$ | 잠긴 헤드 강성 | 2.0774×10⁸(e = 0) / 4.155×10⁷(0.2) / **2.3026×10⁷(0.4011)** / 1.598×10⁷(0.6) / 1.423×10⁷ N/m(0.68) |
| $k_{B}(e)=\beta A_B/(s_l-e+L_{0B})$ | 로드측(가압돼 있을 때만, 한쪽 방향) | 1.21×10⁶(e = 0) / 2.69×10⁶(0.4011) / 1.77×10⁷ N/m(0.68) |
| $c_h$ | 3.5절 | 3.419×10⁴(잠김) / 1.140×10⁵ N·s/m(이동) |
| $u_v$ | 램프 뒤 속도 명령, 앞단은 비선형 속도율 제한 0.2267 m/s² | |

**단일 다리 상태공간**(물리 위상, 상태 $[x_M,\dot x_M,x_r,\dot x_r,p_A]$, 입력 $[Q_A, F_{D2}]$, 출력 $[p_A, F_{sensor}, \Delta s, x_M, \Delta F_{ground}]$, 행렬은 JSON `B_single_leg / FL_top_locked / A,B,C,D`):

| 다리 | $M$ [kg] | 잠김 $f_h$ / ζ | 이동 $f_h$ / ζ | 로드 국부 |
|---|---|---|---|---|
| FL | 12,059 | 6.610 Hz / 0.0279 | 6.595 Hz / 0.093 | 237 Hz / 0.107 |
| FR | 11,855 | 6.667 / 0.0281 | 6.651 / 0.094 | 237 Hz |
| RL | 7,413 | 8.517 / 0.0356 | 8.486 / 0.119 | 237 Hz |
| RR | 7,228 | 8.625 / 0.0360 | 8.593 / 0.120 | 237 Hz |

- 단일 다리 값이다. 다리 4개가 결합한 상부체 모드(상하 7.39 Hz, 로킹 1.8 / 3.0 Hz)는 dynamics-expert 10자유도 모델이 낸다. 오거 단계는 정하중(x, y)을 바꾸지 않아 단일 다리 값이 같다.
- 정적 이득: $\partial p_A/\partial F_{D2}=1/A_A$ = 96.28 Pa/N, $\partial s/\partial F=-1/k_{oil}$ = −4.343×10⁻⁸ m/N, $\partial x_M/\partial F=-1/k_{ax}$ = −4.805×10⁻⁸ m/N. $Q_A$ → $s$는 적분기다. 정속 이동 중 압력 증가 = $c_h/A_A^2\cdot Q$(잠김 $c_h$ 기준 3.17×10⁸, 이동 $c_h$면 1.06×10⁹ Pa per m³/s).
- 주파수 응답 표본($F_{D2}\to p_A$, $Q_A\to p_A$, $Q_A\to\Delta s$; 0.05~20 Hz): $F_{D2}\to p_A$는 레벨링 대역(≤ 0.32 Hz)에서 96.3~96.5 Pa/N, 위상 ≥ −0.17°다. 압력 신호는 제어 대역에서 정적 응답과 같다.
- 지연 사상 표(5.3절)도 JSON `D_lag_map`에 있다.

## 9. 가정과 한계

- 모든 유압 값은 2.2절의 가정이다. 기준 응답의 수치 일치는 **모델 구현의 일치**이지 실기 일치가 아니다.
- 단일 다리 벤치는 상부체를 다리별 정하중 몫의 질량으로 줄였다. 로킹·하중 재분배는 다리 4개 결합 모델(Chrono, dynamics-expert)의 몫이다.
- Level 1 밸브는 수축도 유량이 보상된다고 가정했다(Q-H5, Q-H11).
- 비례 밸브 스풀 동역학·LS 펌프 동역학·라인 파동(배관 TLM)은 넣지 않았다. 레벨링 대역(≤ 0.3 Hz)과 다리 모드(6.6~8.6 Hz)보다 빠르다고 본다(확인 필요, Q-H5).
- 마찰 초기 상태 $z$ = 0, 공기 0(기준), 로드측 초기 2 bar g.
- `ForceFunctor` 경로(5.4절 A)는 클래스 생성까지만 확인했다. Chrono 안에서의 호출·성능은 S7 단위 시험 몫이다.
